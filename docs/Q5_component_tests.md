# 建钥优化的组件选择与验证入口

此前组件微基准、运行时长与预测耗时已删除。正式性能和原始日志以[复赛支撑数据](../data/README.md)为准；本文件保留代码写法与核查入口。

## 选定实现

- **线性层选列 M2**：预先准备各通道移位输入，再用立即数移位将待测位移到符号位，通过 `vblendvpd` 选列。
- **求逆加法链 V4**：沿用链 1,2,3,6,7,14,15,30,31,62,63；多次平方使用编译期常数或生成表，并以编译期断言与差分测试核对。
- **模约化 RED1**：第一次折叠用 CLMUL，第二次折叠用寄存器内 `pshufb` 表。
- 建钥路径由 `INV_CHAIN = 4`、`MAP_METHOD = 2` 固定；其他候选写法用于差分测试与微基准。
