## 1. 依据

作者版rFAEST论文（SHA见[作者声明复核](../%E5%8E%9F%E8%AF%AD%E4%BE%9D%E6%8D%AE%E5%A4%8D%E6%A0%B8_20261015/%E5%A3%B0%E6%98%8E/01_%E4%BD%9C%E8%80%85%E5%A3%B0%E6%98%8E%E4%B8%8E%E9%AA%8C%E6%94%B6%E5%BF%A0%E5%AE%9E%E6%80%A7%E5%A4%8D%E6%A0%B8.md) §6）给出的安全依据：

| 原文 | 内容 | 含义 |
|---|---|---|
| 定理4.3，978—1002行 | 经典ROM＋理想原语下，伪造优势≤若干项＋Adv_owf(B)＋Q_sig·Adv_prf(C)＋…，B、C仅为“存在的PPT” | 条件归约；B的具体资源未给，不能代入得具体位数 |
| 1003—1013行 | 新增VSC损失约N·Q/2^λ＋τ(k+2)Adv_prg | 损失明确保留；N为千级时Q约2^116该项即近1 |
| 脚注，1014行 | H3本身不是PRF，按加密钥前缀使用 | 非严格建模 |
| 667—676行 | 去掉理想原语时改为计算假设，界为negl(λ) | 无具体数值 |
| 1028—1041行 | “128-bit parameter sets”“at the 128-bit security level” | 档位声明；参数和密码分析沿用FAEST v2 |
| FAEST v2 109—113、3381—3392行 | 查询复杂度为粗粒度量尺，界“close to the bit security target”；穷举公钥约2^(λ−2)—2^(λ−1)次AES | 128档允许披露的小常数 |
| 1395—1399行 | QROM留待未来 | 经典层级 |

所以作者也没有证明具体128位，同层级标准不要求我方证明。
