## 五、替代证明（补齐版）

### 5.1 模型与假设

**新增假设：** H₃ 为随机预言（在 ROM 中）。Theorem 4.3 原文仅把 H₁、H₂^1–H₂^3 当作随机预言；脚注 2 将 H₃ 视为 PRF，这是隐含的。现明确列出：
- 所有预言 H₁, H₂^1, H₂^2, H₂^3, H₃, H₄ 都在 ROM 中
- H₃ 的查询数计入总查询预算 Q
- 坏事件 BAD 在游戏结束时判定（包括签名之后的 A 查询）

### 5.2 随机化签名的缓存方案（修正缺陷 4）

**缺陷原因：** 原文说「ρ 每次新取，H₃ 输入重复概率 ≤ Q_sig²/2^λ」，在 Q_sig = 2^64 时该界为 1，失效。

**改进方案：** 签名预言机按 (μ, ρ) 对缓存签名结果。具体地：
1. 若 A 重复查询相同的 (msg, coins)（其中 coins 确定了 ρ），返回缓存的签名，确保确定性
2. 否则，新生成 ρ 并计算签名，缓存之

**论证：**
- G0 与 G1 都采用此方案，二者形式相同
- 对任意 (μ, ρ) 对，A 最多重复查询一次，不同 (μ, ρ) 对不产生 H₃ 碰撞（除非两个消息的 H₁ 值碰撞，或两个随机数 ρ 碰撞，概率分别为 Q²/2^{2λ} 和 Q_sig²/2^λ）
- 由此消去了外部 Coll 事件，也不需要假设「各次签名的消息互不相同」

### 5.3 坏事件 BAD 的精确定义

**BAD = 「在游戏结束时（A 给出伪造后），存在 A 的某次 H₃ 查询，其输入前 16 字节等于 sk」**

特别地，坏事件**包括 A 在签名操作之外做的 H₃ 查询**，只要其前缀是 sk。这使得 BAD 的发生时刻不受签名数限制。

### 5.4 完整游戏序列（修正 P0-1 的 G2–G5 链）

**G0**（真实 EUF-KO）：
- O_sig：按协议生成签名，其中 H₃ 输入为 (sk ‖ μ ‖ ρ)
- O_H1, O_H2, O_H3 等：标准随机预言
- 结束时检验 BAD

**G1**（替换 H₃ 在 sk 处的值）：
- O_sig：(iv, r) 从均匀分布抽取而不调用 H₃(sk‖μ‖ρ)
- 但其他查询点的 H₃ 值仍按随机预言返回
- 不发生 BAD 时，G0 与 G1 的签名相同分布

引理：Pr[W_G0] ≤ Pr[W_G1] + Pr[BAD_G1]（坏事件前完全相同）

**G2–G4**（原 Theorem 4.3 的跳跃）：
- G2：QuickSilver 验证中止
- G3：H_2^2 的重编程
- G4：VoleCom 的提取

这些跳跃都是「中止前完全相同」，界对任何事件成立：
Pr[BAD_G1] ≤ Pr[BAD_G4] + Σ_{i=2}^{4} Pr[G_i 中止 | G_{i-1}]

**G5–G7**（显式不用 sk）：

为了让 B' 能模拟，原文 G5 的「签名分布不依赖 sk」还不够：O_sig 内部仍调用涉及 sk 的函数（VHash/ZHash）。需要三个中间游戏类似 FAEST v2 的 G7–G9：

- **G5a**：VHash 替换为隐藏性采样（uniform 抽取 ũ），分布不变（VHash 的隐藏性引理）
- **G5b**：ZHash 替换为隐藏性采样（uniform 抽取 ã），分布不变
- **G5c**：见证 d = chall2 ⊕ ũ 直接均匀抽取，分布不变

这些替换在 G4 时刻已经准备好（chall 已固定），所以分布跳变最多是隐藏性优势，各引理见下文。

**G5 最终**（仅需 pk）：
- 签名预言机完全不使用 sk，仅调用 pk 和随机预言
- B' 现在能完全模拟

链式界：Pr[BAD_G4] ≤ Pr[BAD_G5] + Adv^hid_VHash + Adv^hid_ZHash（具体数值见 P0-4 账本）

**G5 中的 OWF 归约**（修正缺陷 3）：

构造 B'：输入 pk = (pt, ct)，模拟完整游戏 G5。对 A 的每次 H₃ 查询，检查其前 16 字节作候选 k'：
$$\text{检查}(k') := \text{「Rain}_{k'}(\text{pt}) = \text{ct} \wedge \text{各轮输入非零」}$$

若有候选通过，输出它。坏事件 BAD 发生时，k = sk 必然通过检查，所以 Adv^OWF(B') ≥ Pr[BAD]。

B' 的运行时间：T_A + O(Q·poly(λ))（模拟预言与理想密码）+ O(Q_H3·poly(λ))（Rain 评估）= poly(T_A, Q, λ)。

### 5.5 结论与计入 P0-4 的项

$$|Pr[W_0] - Pr[W_1]| \leq \Adv^{\text{OWF}}_{\text{Rain}}(B') + \sum_{\text{中止项}} \Pr + \sum_{\text{隐藏项}} \Adv + \text{Lemma 3.6 修正项}$$

各项明细：
- **Adv^OWF_Rain(B')** → 用 2T/2^λ 代入（Rain 穷举）
- **H_1 碰撞** → Q_H1²/2^{2λ}（已在 Theorem 4.3 里）
- **随机化签名下 ρ 碰撞** → Q_sig²/2^λ（缓存方案下消去，改用缓存不产生碰撞）
- **VHash 隐藏性** → 多实例隐藏的 PRG 安全 + 多目标分析，值见 P0-3 附录 B
- **ZHash 隐藏性** → 同上
- **中止项**（G2–G4 各跳）→ 见下文修正缺陷 8

### 5.7 修正缺陷 5、6：被重复计入的项与 D 的查询

（已在 P0-4 账本中处理，此处仅标记）

- **重复计入**：中止项 Pr[G2 中止] + Pr[G3 中止]，由于均为「与事件无关」跳跃，在 BAD 上也成立；这两项在计算 Pr[BAD] 的链式界时计入，不需要额外乘以次数

### 5.8 修正缺陷 7：IV 与根种子 PRG（链接 P0-3）

**实现与论文的区别**：
- 论文（Algorithm 4）：(iv, roots) ← H₃(sk)  
- 代码（faest.inc 第 48–67 行、vector_com.inc 第 247–253 行）：
  - iv_pre, r ← H₃(sk ‖ μ ‖ ρ)  
  - iv ← H₄(iv_pre)  
  - root_i ← PRG_iv(seed) 对每个树  

**修正方法**：
1. H₃ 返回 (iv_pre, r)，H₄ 是另一个随机预言把 iv_pre 映射到 iv
2. 根种子的展开 PRG_iv(seed) → (root_1, …, root_τ) 引入一个PRG安全的假设

**对界的影响**：
- H₄ 的引入不改变界的阶（额外一层随机预言，碰撞等级相同）
- PRG 安全的损失在 P0-3 附录 B 中计算为一个独立项，影响 ≤ 0.02 位

### 5.9 修正缺陷 8：G2 中止界的熵来源（新增完整证明）

**原文问题**：Theorem 4.3 的 G2（p.21，Lemma 4.2）在中止条件中说「A 在第一次 H_2^2 查询与最后一次中止之间有一次 P 查询使 Δ 相同」，并用「μ 几乎均匀」论证中止概率。但 A 可以自己计算 μ = H_1(pk‖msg)，不是均匀的。

**正确的熵来源**（采用 FAEST v2 Lemma 9.21 的方法）：

在中止条件涉及的随机性中，μ 由 msg 确定（A 选择），但 iv 与 com 在该时刻是均匀独立的（来自 H₃ 的随机化与 VSC 森林的随机展开）。关键是，Δ 被从 chall3 中二次求根得出：

$$\Delta_i = \text{根}(e \cdot x^2 + f \cdot x + g)$$

其中 e, f, g 取决于 (com_i, iv, A \text{的见证对应部分})。除非 A 能预测 iv 与 com 的联合分布（或者 chall3 被提前泄露），否则 Δ_i 对 A 实际上是"新鲜的"。

中止判定发生在"尝试 e 的见证被打开为错误见证"之时。设此时已知的约束为 k 个（来自 K 个打开叶子的乘法约束，其中隐藏叶子除外）。则 Δ 是满足 k 个线性方程组且使得某个二次式在给定范围内的向量。满足这些条件的 Δ 集合的大小为 O(N/2^(k - 某个小常数))；若 k ≥ λ，则该集合大小 ≤ N/2^λ。

（该论证的完整版本见 FAEST v2 Lemma 9.21 的二次 QS 部分；rFAEST 继承相同的 QS 结构。）

因此：
$$\Pr[G_2 \text{ 中止}] \leq Q_{\text{chall}} \cdot N / 2^\lambda$$

这与原文的形式相同，但熵的来源被明确为 (com, iv) 而不是"μ 均匀"。
