# 底层双承诺绑定：实际支持记录上的自适应查询界

2026-10-15；C030-RFAEST128-EQUIV-TIGHT1；ledger_build。数学证明稿，独立反驳审查另存。本稿只读研究并新增文档，未运行密码实验。

**局部结论。** 对一个固定的原030参数集，令全部普通理想密码调用（含提取器私有读取及最终核验）至多为 $P$。在下述经典双向理想密码模型中，对于两个已被实际查询支持的底层父节点，其有序双承诺相同而有序 tape 对不同的事件，有

\[
 \epsilon_{\rm canon}
 \le \min\!\left\{1,\delta_{\rm all}(M,u)
       +\frac{P(P-1)u^2}{(M-P-1)(M-P-2)}\right\},\qquad 1\le u<M. \tag{1}
\]

这里 $M=2^\lambda$，仅在整数预算 $0\le P\le M-3$ 时使用该式；预算更大时取平凡上界1。这里要求两个分母因子均为正，避免在 $P$ 超过 $M$ 后把乘积再次为正误当成有效。可取

\[
 \delta_{\rm all}(M,u)
 =\min\!\left\{1,\frac{M\binom M{u+1}}{M^u}\right\}
 \le\min\!\left\{1,\frac{M^2}{(u+1)!}\right\}. \tag{2}
\]

式(1)是对一个更强的“有序双承诺碰撞”事件的上界，保留了无害的同 tape 情况，因而也覆盖真正的语义歧义。它允许正逆查询、自适应 IV、数值 seed 重合以及任意有限的普通私有完备化。关键前提是两名父节点在对应两个孩子输入中至少各有一格被实际查询过。角色 P 模板满足这个前提。

本稿同时给出固定 context 的独立引理，以及“已有半边父节点的最后一次匹配仅有一阶条件概率”的精确例子。上述局部定理尚未独立解决迟到直接叶、AU 候选数及完整 EUF-CMA 合成；完整128位等强结论继续以总报告为准。

## 1. 对象、模型与要排除的事件

固定一个参数集，令

\[
 \alpha=(1,0,0,0),\qquad \beta=(0,0,0,\tau).
\]

所有加减都是四个32位 lane 分别模加减。对 context $x$，记

\[
 x_0=x,\quad x_1=x\boxplus\alpha,\quad
 x_C=x\boxplus\beta,\quad C_x(s)=E_s(x_C),
\]

\[
 a_{p,x}=E_p(x_0),\quad b_{p,x}=E_p(x_1),\quad
 F_x(p)=\bigl(C_x(a_{p,x}),C_x(b_{p,x})\bigr). \tag{3}
\]

原030六组的 $\tau$ 均使 $x_0,x_1,x_C$ 两两不同。固定 $x$ 与合法树高 $k$ 后，叶 tape 是同一理想密码的确定函数

\[
 T_{x,k}(s)=\bigl(E_s(x_C\boxplus(c,0,0,\delta_k))\bigr)_{0\le c<r},
 \quad \delta_k=2^{31}-(k+1)\tau\pmod{2^{32}}, \tag{4}
\]

并按协议截取有意义的 $L$ 位。式(3)、(4)的地址来源与相对平移见[角色完备化稿](../%E5%85%B1%E4%BA%AB%E5%9C%B0%E5%9D%80/03_%E6%9D%A5%E6%BA%90%E8%AE%B0%E5%BD%95%E6%9C%89%E9%99%90%E8%A7%92%E8%89%B2%E5%AE%8C%E5%A4%87%E5%8C%96%E4%B8%8E%E6%9C%AA%E8%AF%81%E6%A1%A5.md)。绑定比较固定同一 $x,k$。跨树高比较同一 seed 的不同地址 tape，不属于这里的语义歧义。

理想密码模型如下。

1. 每个 $s\in\{0,1\}^\lambda$ 对应一份独立均匀随机置换 $E_s$，输入、输出和 key 空间大小均为 $M$。
2. 算法可自适应使用 $E_s(z)$ 与 $E_s^{-1}(y)$。一次调用返回一行规范记录 $(s,z,y)$。批量调用按其实际 AES 块数展开为标量调用。
3. 所有实际依赖 $E$ 的普通读取均计入 $P$，包括来源流程、提取器私有读取、完备化、模拟器公开重构及最终 Verify。其他初始随机性可任意，但不提前泄露未计费的 $E$ 信息。
4. 本稿研究的是一份真正的理想密码。若某 hybrid 以编程方式实现模拟，先由其独立耦合论证建立这一边缘分布，再使用本稿；本稿没有为任意外部编程表建立理想密码假设。

源码中的不同角色可数值上使用相同 key。只有数值 key 相同才是同一份置换；没有额外的角色独立性假设。

定义一份纯记账注册表 $\mathcal R_i$：初始为空，第 $i$ 次实际调用返回 $(s,z,y)$ 后，加入

\[
 (s,z),\qquad(s,z\boxminus\alpha). \tag{5}
\]

重复条目去重。因而

\[
 (p,x)\in\mathcal R_i
 \quad\Longleftrightarrow\quad
 E_p(x_0)\text{ 或 }E_p(x_1)\text{ 的记录已在前 }i\text{ 次调用中出现},
\]

\[
 |\mathcal R_i|\le2i. \tag{6}
\]

这是把每一实际行同时解释为“左孩子调用”及“右孩子调用”，没有发出任何新查询，也没有递归执行模板。

定义加强的事件

\[
 \mathsf{PairSup}=\{\exists x,\ p\ne q:
      (p,x),(q,x)\in\mathcal R_P,\ F_x(p)=F_x(q)\}. \tag{7}
\]

实际所需的语义歧义事件在式(7)之外，还要求某个固定合法 $k$ 满足

\[
 (T_{x,k}(a_{p,x}),T_{x,k}(b_{p,x}))
 \ne(T_{x,k}(a_{q,x}),T_{x,k}(b_{q,x})). \tag{8}
\]

所以它是 $\mathsf{PairSup}$ 的子事件。相同 $p,x,k$ 给出相同的两个 child seed 及 tape，故式(8)确实要求不同父 key；不同父 key 但同一 tape 对则是允许的重复。

事件(7)只要求父格被支持；它甚至容许某些承诺尚未被算法实际求值。这是一个方便分析的加强事件。它没有包含“从未查询其两个父格，只因 key 曾在其他地址出现，就任意指定的所有 context”。

## 2. 全列桶帽及尾项

对每个固定输入地址 $z$，随机变量 ${E_s(z):s\in\{0,1\}^\lambda}$ 相互独立且均匀。对固定输出值 $c$，若有至少 $u+1$ 个 key 命中 $c$，存在一个大小为 $u+1$ 的 key 子集全部命中。因此，对一列先对输出值并合，得

\[
 \Pr\bigl[\max_c|\{s:E_s(z)=c\}|>u\bigr]
 \le \frac{\binom M{u+1}}{M^u}
 \le \frac{M}{(u+1)!}. \tag{9}
\]

对全部 $M$ 个输入地址再并合，得式(2)。记

\[
 G_z=\{\max_c|\{s:E_s(z)=c\}|\le u\},\qquad
 G_{\rm all}=\bigcap_zG_z. \tag{10}
\]

不同列之间无需独立。重要的是：**后面的逐查询概率计算只条件于当前选定的一列，整体证明仅使用 $G_{\rm all}\subseteq G_z$ 的集合包含。** 全域事件依赖所有置换位置，直接条件于 $G_{\rm all}$ 后宣称其他行仍按普通残余置换分布抽样，会缺少依据。

## 3. 局部揭示引理：固定一条旧记录后再看一名新父节点

令 $H$ 是一次实际 IC 调用之前的完整普通历史，含所有 Full 行、相关算法随机性和当前请求。条件于 $H$，自适应查询选择已经固定，各 key 未定义的部分仍为各自剩余输入与输出之间独立的均匀双射。

固定一个历史可测的 context $x$ 和不同数值 key $p\ne q$，且 $q$ 在 $x_0,x_1$ 的两个位置都尚未出现。为分析该一个候选比较，执行以下免费揭示：

1. 揭示当前完整承诺列 $C_x(s)=E_s(x_C)$，遍历全部 key $s$。这可以是指数大小；它只用于信息论上界，不是提取器操作，也不是声称实际算法免费得到整列。
2. 揭示 $p$ 的两个父输出 $E_p(x_0),E_p(x_1)$ 中尚未知的部分。由完整 $C_x$，其目标 $F_x(p)=(A,B)$ 随之固定。

只揭示同一列，随后只补 $p$ 的父格。由于 $p\ne q$，后一步没有读取 $q$ 的剩余置换。即使 $p$ 的 child seed 等于 $q$，所需承诺 $C_x(q)$ 也早已属于第一步的完整列；它不会额外揭示 $q$ 的父格。

对任何与 $H$ 相容的整列实现，给定上述揭示后，$q$ 的两个父输出依旧是其残余输出集合 $R_q$ 中均匀的有序不同元素。令 $m=|R_q|$。每个 key 的先前普通行至多 $P$ 条，整列只可能给该 key 多固定一条，所以保守地有

\[
 m\ge M-P-1,\qquad
 m(m-1)\ge D_P:=(M-P-1)(M-P-2). \tag{11}
\]

这里使用了较松的统一分母。针对第 $i$ 次调用前的精确历史，还可用该 key 的真实剩余输出数。

### 3.1 正向查询所需的双桶计数

令 $K_A=C_x^{-1}(A)\cap R_q$、$K_B=C_x^{-1}(B)\cap R_q$。写

\[
 a=|K_A|,\quad b=|K_B|,\quad c=|K_A\cap K_B|.
\]

那么

\[
 \Pr[F_x(q)=(A,B)\mid H,C_x,\text{已补的 }p\text{ 父格}]
 =\frac{ab-c}{m(m-1)}. \tag{12}
\]

减去 $c$ 是因为同一置换的两条不同输入不会有相同输出。在当前列满足 $G_{x_C}$ 时，式(12)至多为 $u^2/D_P$。这个公式对 $A=B$、child seed 与任意历史 key 数值重合，以及 $q$ 在其他地址已经有许多普通行，均成立。

### 3.2 逆向查询保留“返回父地址”的成本

设当前请求是 $E_q^{-1}(y)$，输出值 $y$ 已在请求前固定。要在本次响应后为这个 $x$ 新增 $(q,x)$，其响应输入必须为 $x_0$ 或 $x_1$。因此要界的是联合事件

\[
 E_q^{-1}(y)\in\{x_0,x_1\}\quad\text{且}\quad F_x(q)=(A,B). \tag{13}
\]

若 $y\notin R_q$，它在先前历史或整列揭示中已经被占用。因两个父格仍未定义，式(13)的概率为0。

若 $y\in R_q$，满足式(13)的有序父输出数精确为

\[
 \mathbf1[C_x(y)=A]\bigl(|K_B|-\mathbf1[y\in K_B]\bigr)
 +\mathbf1[C_x(y)=B]\bigl(|K_A|-\mathbf1[y\in K_A]\bigr). \tag{14}
\]

第一项是 $a_{q,x}=y$，第二项是 $b_{q,x}=y$；这两类在有序不同输出对中互斥。在 $G_{x_C}$ 上，式(14)至多 $2u$，所以

\[
 \Pr[(13)\mid H,C_x,\text{已补的 }p\text{ 父格}]
 \le\frac{2u}{D_P}. \tag{15}
\]

这一步没有先条件化于“逆向查询已返回某个有利父地址”。该返回地址本身也是应付费的随机约束。即使 $y$ 被挑成某个旧目标桶中的 seed，式(14)仍保留另一父输出及返回地址的两个约束。

### 3.3 条件化的使用范围

式(12)、(15)先对每个固定的整列和旧父格实现成立，再对它们积分。因此，在任意普通历史 $H$ 下，分别得到

\[
 \Pr[\text{相应局部事件}\ \wedge G_{x_C}\mid H]
 \le u^2/D_P\quad\text{或}\quad2u/D_P. \tag{16}
\]

列地址 $x_C$ 可以在 $H$ 中自适应决定。证明没有预先共同揭示所有将来被挑选的列。不同候选比较分别使用各自的分析揭示；它们无需也没有被拼成一份同时免费透露多列的算法。

## 4. 自适应 context 的全局二次查询界

假定事件 $\mathsf{PairSup}$ 发生。取其中任意一对不同父 key，比较它们对应注册条目的首次插入时间。同一次普通调用只使用一个 key，故这两个首次时间不同。同一行虽可产生两个新 context，它们使用同一个父 key 且 context 不同，不会构成式(7)要求的同 context、不同父 key 的碰撞。设较晚插入的是 $(q,x)$，发生于第 $i$ 次调用；较早的 $(p,x)$ 已属于 $\mathcal R_{i-1}$。

由首次插入的定义，在第 $i$ 次请求前，$q$ 的 $x_0,x_1$ 两格都还没有 Full 记录。这一事实包括所有角色、所有 IV 和所有私有普通读取，而非仅指某个 Source 索引未登记。

条件于当前请求前的普通历史，$\mathcal R_{i-1}$ 及其最多 $2(i-1)$ 条条目均固定。逐条检查旧的 $(p,x)$，只保留 $p\ne q$ 且 $(q,x)\notin\mathcal R_{i-1}$ 的候选。

### 4.1 当前调用为正向

请求为 $E_q(z)$，$z$ 在回答前已固定。新注册条目仅可能具有 context $z$ 或 $z\boxminus\alpha$。其他旧 context 在本次比较中贡献0。对其余每条旧记录，局部引理给出

\[
 \Pr[\text{此次新支持的 }q\text{ 与这条旧记录发生 }F\text{ 碰撞}
       \ \wedge G_{x_C}\mid H_i]
 \le u^2/D_P. \tag{17}
\]

### 4.2 当前调用为逆向

请求为 $E_q^{-1}(y)$，$y$ 在回答前已固定；其响应 $z$ 可以自适应地产生新的 context。但每一条候选旧记录 $(p,x)$ 在回答前已经存在，所以对它的比较恰是式(13)：要同时有 $z\in\{x,x\boxplus\alpha\}$ 及双承诺匹配。

因而每条旧记录的联合概率至多 $2u/D_P$。无需把响应后选择的 context 误当作事先固定，也无需为每一个可能返回的 $z$ 再作一次全域并合。

### 4.3 对实际注册记录并合

令 $E_{i,\rho}$ 表示上述第 $i$ 次调用相对旧条目 $\rho$ 的局部事件。由每个碰撞必有较晚首次插入，得

\[
 \mathsf{PairSup}\cap G_{\rm all}
 \subseteq\bigcup_{i,\rho\in\mathcal R_{i-1}}
                  (E_{i,\rho}\cap G_{x_C(\rho)}). \tag{18}
\]

这是事件包含，并未在局部采样时条件于 $G_{\rm all}$。每个查询前的候选条目数是可预测的，且由式(6)至多为 $2(i-1)$。

还可统一正逆两方向：对每条旧记录而言，“本次新注册且双承诺匹配”本身就是“新父节点的潜在双块落入两个目标桶”的子事件。旧 context 在当前回答前固定，且新父节点的两父格均未读，所以可直接引用式(12)的 $u^2/D_P$，无需先条件化本次响应。式(14)另给逆向的更细计数；它与式(12)同时成立，逆向可取两者的最小值。这样统一的 $u^2$ 系数对全部 $u\ge1$ 成立。

利用该包含关系及式(16)、(17)，积分并求和得

\[
 \Pr[\mathsf{PairSup}]
 \le\delta_{\rm all}(M,u)
 +\frac{u^2}{D_P}\sum_{i=1}^P2(i-1)
 =\delta_{\rm all}(M,u)
 +\frac{P(P-1)u^2}{D_P}. \tag{19}
\]

这就是式(1)，对全部整数 $1\le u<M$ 成立。查询数随机且至多 $P$、查询方向自适应及算法提前停止，均已由确定上限 $P$ 覆盖。若保留精确历史计数，可在正向步骤只数输入匹配的旧 context，并分别保留 $u^2$ 与 $2u$ 系数。

**为何没有额外 context 数因子：** 总共只有至多 $2P$ 次“父 key＋context”的注册。每个碰撞比较记到较晚注册发生的实际调用，并对当时已存在的注册记录计数；这些记录已经带着 context。把每个 context 另乘所有触达 key 的平方，会重复放大计数。式(19)直接对已支持的记录收费。

## 5. 固定 context 的独立加强引理

若三个地址 $x_0,x_1,x_C$ 在实验之前固定，可以证明另一条更强的事件界：在最多 $P$ 个被任何方向、任何地址实际触达的不同 key 中，出现 $F_x(p)=F_x(q)$、$p\ne q$ 的概率至多

\[
 \epsilon_{\rm fixed}
 \le\min\!\left\{1,\delta_{\rm col}(M,u)
 +\binom P2\frac{u^2}{(M-1)(M-2)}\right\}, \tag{20}
\]

其中 $\delta_{\rm col}(M,u)\le\binom M{u+1}/M^u\le M/(u+1)!$。

证明：实验开始时在分析中免费给出整列 $C_x$。在算法首次选中一个此前从未触达的 key $p$、执行该实际请求之前，免费给出其两父输出。给定 $C_x(p)$，这对输出是在排除 $C_x(p)$ 后的 $M-1$ 个值中均匀取出的有序不同对。不同尚未触达 key 的其余置换独立。

当前新 key 可以依赖全部已经揭示的信息选择，也可以数值上等于旧输出；只要它此前未被触达，其剩余置换仍有上述分布。在桶帽下，新 key 的 $F_x$ 命中每个先前固定的 $F_x$ 值至多 $u^2/[(M-1)(M-2)]$。最多 $P$ 次首次 key 触达给出 $\binom P2$ 个比较，再加该列桶帽尾项即得式(20)。

这里的免费信息仅是一种加强对手视图的分析装置，不计作现实提取器的资源优化。该引理允许“key只在其他地址被触达”，所以事件比式(7)在固定 context 上更强。反过来，自适应选择 context 时，本稿使用第4节的实际父格支持条件，而没有把式(20)的事先固定前提默默移走。事先固定的有限 context 族可对式(20)逐项并合；其列帽尾项也可由一个全域事件统一支付。

## 6. 半边已旧、半边新：最后一次查询的一阶条件例子

局部二次界并不意味着在任意既有历史上，最后补一名父节点都要再匹配两个新值。以下例子甚至有一名完整旧父节点，并且要求真实有序 tape 差异。

固定同一 $x,k$，选不同的 $p,q,a,b,b'$。考虑与理想密码相容的普通历史：

\[
 E_p(x_0)=a,\qquad E_p(x_1)=b,\qquad E_q(x_0)=a,
\]

\[
 C_x(a)=A,\qquad C_x(b)=C_x(b')=B. \tag{21}
\]

在该历史中，key $q$ 仅有 $x_0\mapsto a$ 一行，$x_1$ 仍未定义。并固定相容的 tape 行，使 $T_{x,k}(b)\ne T_{x,k}(b')$。在原030地址分离下，可选择符合各 key 置换一致性的此类有限历史。

随后请求 $E_q(x_1)$。由于 $b'\ne a$，有精确条件概率

\[
 \Pr[E_q(x_1)=b'\mid\text{式(21)及上述历史}]=\frac1{M-1}. \tag{22}
\]

命中时 $F_x(p)=F_x(q)=(A,B)$，且由第二片 tape 不同而产生真正的语义歧义。逆向请求 $E_q^{-1}(b')=x_1$ 给出同一个 $1/(M-1)$。

式(22)只是给定可实现历史后的精确条件例子，未给出以低成本建立整段历史的方法，也不是完整签名伪造。它否定了“最后补父节点天然再付 $M^{-2}$”的逐步推理。

它与式(19)相容：第4节将该对父节点的比较计在 $q$ **首次**获得对应支持的调用，即 $E_q(x_0)$，而非已知半边之后的最后查询。整段历史的概率在那里被计入。

以每个 Source 半边为根执行一次 P 完备化，会使本例的 $q$ 在旧快照中完整确定，从而消除它的“迟到未覆盖”身份。该完备化并没有把任意事后历史下的一阶条件概率自动变为二阶；全局证明仍应使用第4节的收费时刻，或使用有独立前提的迟到父节点引理。

## 7. 与 Source 根、有限角色完备化的接口

[有限角色完备化稿](../%E5%85%B1%E4%BA%AB%E5%9C%B0%E5%9D%80/03_%E6%9D%A5%E6%BA%90%E8%AE%B0%E5%BD%95%E6%9C%89%E9%99%90%E8%A7%92%E8%89%B2%E5%AE%8C%E5%A4%87%E5%8C%96%E4%B8%8E%E6%9C%AA%E8%AF%81%E6%A1%A5.md)中，每一 P 模板父描述符都由一条实际 Source 行的左/右解释产生，所以它的 $(p,x)$ 必然在本稿注册表中。为它补另一孩子、两个承诺以及各树高 tape 的调用，都属于普通 Full 调用。

因此，在同一 $(x_C,k)$ 中，若冻结池内同一有序承诺对有两个不同的有序 tape 对，必有式(8)，进而触发式(7)。式(1)直接给出这一 canonical 语义歧义的界；不要求父 seed 唯一，也无需另对树高作并合，因为加强事件 $F_x(p)=F_x(q)$ 本身与 $k$ 无关。

记来源调用上限为 $q_0$，参与有限完备化的来源根数为 $q_{\rm anchor}$。三个角色模板的既定资源界为

\[
 P\le\bar P:=q_0+c_{\rm role}q_{\rm anchor},\qquad
 c_{\rm role}=d_Hr^2+5d_Hr+6. \tag{23}
\]

六组参数各有 $d_H=2$：Rain-3 的 $r=6,c_{\rm role}=138$，Rain-4 的 $r=7,c_{\rm role}=174$。于是可以将 $\bar P$ 代入式(1)得到保守的先验界。直接使用实际更小的确定调用上限也可以。

惰性实现时，若证明中的某个冻结候选尚未求值，可以在来源流程结束后按固定模板补完所有需要的普通读取；这些读取保持无反馈，其总数仍由式(23)约束。已经实际支持的父格不因延迟求值而失去式(7)的覆盖。按完整资源证明需要计费的求值，继续计入归约时间和调用预算。

这里使用 **Full 预算 $P$**。本稿没有把包含私有模板候选的语义歧义事件当成 Source 可测事件，也没有把 $P$ 换成 $q_0$。[来源隔离稿](01_%E6%9D%A5%E6%BA%90%E9%9A%94%E7%A6%BB%E7%BC%93%E5%AD%98%E4%B8%8E%E6%83%B0%E6%80%A7%E6%8F%90%E5%8F%96%E8%B5%84%E6%BA%90.md)的 Source 边缘论证另供其适用事件使用。

每一冻结参数的安全游戏分别应用本稿。若另行定义允许在多个不同 $\tau$ 之间选择参数的联合游戏，须在该游戏中对不同 $\tau$ 的事件计数；本稿未把单参数公式自动宣称为这种联合游戏的公式。

## 8. 已证明范围与剩余接口

| 项目 | 本稿处理 |
|---|---|
| 同一 context、不同父 key、有序双承诺相等 | 实际父格支持模型下，式(19)给完整逐查询界 |
| 同承诺对但同 tape 的重复 | 允许；式(19)为了上界将其一起保守计入 |
| 正向和逆向查询混合 | 式(12)及式(14)分别计数，查询方向可以自适应 |
| 自适应 IV/context | 正向在请求前固定；逆向联合计“返回既有 context 父地址” |
| seed 数值与历史 key 重合 | 只按数值 key 分置换；完整列先揭使别名不增加隐含父格读取 |
| 半边旧、半边新 | 按首次支持收费；式(22)限定事后条件概率的范围 |
| Source 一步有限完备化 | 式(23)给 Full 成本，P 描述符满足本稿支持前提 |
| 多列共同条件化 | 未使用；每一局部比较只分析一列，整体仅用事件包含 |
| 迟到匹配父节点 | 另需切口前/后覆盖定理；本稿只处理不同父节点的语义冲突 |
| 新直接叶影响、候选 AU 计数、QS/CMA 合成 | 保留各自证明义务，未由绑定定理代替 |
| 原030完整128位等强 | 需合成全部损失和归约资源后裁决，当前局部结论不单独认证 |

式(1)消除了在此局部事件中把所有单叶承诺碰撞一律按 $P^2/M$ 收费的必要性。它给出的是 $O(P^2u^2/M^2)$ 加全域桶帽尾项，实际常数、完备化成本、AU 族大小及其他事件仍需留在最终比较中。本稿未运行新增实验；一般结论来自以上计数与普通理想密码残余置换论证。

## 9. 保留的较松推导：context 出生时刻并合

这一节保留一条先前考虑的较松上界，便于追溯分析。主定理已经使用第4节的成对注册收费，本节不参与它的证明。

定义一个更强事件：某 context 由一条实际行按式(5)首次产生，此后只要求两名不同父 key 在任意地址被实际触达，即比较它们的潜在 $F_x$ 值；二者不必都有父格支持。全程至多 $2P$ 个首次出现的 context。

对一个 context 的出生后普通历史作条件化。此前整个 Full 表在它的 $x_0,x_1$ 两个全局地址上没有任何行，否则该 context 早已按式(5)出生。当前出生行因此只会使一个特殊 key 的一个父格已知。即使该行来自逆向调用，条件化于这份出生后完整历史，未定义的置换仍按其普通残余分布。

在这一份分析中免费揭当前完整列 $C_x$，再把特殊 key 的另一父格补出，把它的 $F_x$ 当作任意第一目标。对出生时已经触达的其他 key 依次揭父双块；它们两个父格均未出现，给定此列后每对都是独立残余置换中的有序不同输出。此后每当实际算法第一次触达一个新 key，也免费揭其父双块。总计至多 $P$ 名实际触达 key。对每名非特殊 key 与先前目标的每一次比较，桶帽下可付 $u^2/D_P$。

因此，在任意出生后历史下，该 context 的加强碰撞事件与当前列桶帽同时发生的概率至多

\[
 \binom P2\,u^2/D_P. \tag{24}
\]

免费给予整列及这些父输出只是分析中的加强信息；实际 key 触达总数仍受 $P$ 限制。已有 key 的其他地址行只影响其残余输出集合大小；尚未实际触达的新 key，其剩余置换与已经揭示的其他 key 残余置换独立。

对至多 $2P$ 个出生停止时刻分别使用式(24)，再以 $G_{\rm all}\subseteq G_{x_C}$ 放大局部事件而非条件化未来全域好事件，可得

\[
 \Pr[\mathsf{BornTouchedCollision}]
 \le\min\!\left\{1,\delta_{\rm all}(M,u)
       +2P\binom P2\,u^2/D_P\right\}. \tag{25}
\]

式(25)也只在 $0\le P\le M-3$ 内使用。它分析的事件强于实际 P 模板需要的父格支持事件，并为每个 context 免费比较全部触达 key，因而留下额外 $P$ 因子。第4节回到实际已支持的父记录，消除了这一额外计数。两条推导均避免在预揭全部自适应列后继续宣称父格独立。
