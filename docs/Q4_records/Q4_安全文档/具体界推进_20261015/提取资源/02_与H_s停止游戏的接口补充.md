# 来源隔离提取与H_s停止游戏的接口

2026-10-15。根据cma_tightening交叉核读补充一处组合口径。主稿 `01_来源隔离缓存与惰性提取资源.md` 保持受审SHA256 `717d842cb6312985ebf734e4ffe9c44f6105644822e3f11e243cdc6375d4ef6a`，本补充与之共同使用。

最直接的组合实现采用两种有明确可测性差别的成功路径：

1. **H_s公开HitKey。**攻击者首次H_s输入的密钥前缀通过公开Rain关系检查时，立即输出该原像并终止。这个停止谓词仅依来源输入、公钥和公开计算，对来源过滤族可测，故保留主稿R2/R3的来源边缘及逐步概率证明。CMA视图比较正是正式03和新CMA稿的首次HitKey停止游戏。
2. **Ext私有成功。**从私有带读取及H₂快照得到合法Rain原像时，仅保存第一个成功key；继续原定来源过程，在A及最终Verify结束后输出。其发生不改变模拟器随机币、编程点、缓存、grinding、A的查询机会或其他来源行为。R2的无反馈条件要求的是这条私有路径。

若为实现统一而也让H_s成功仅记录，则CMA真实/模拟视图的等价只断言到**首次HitKey的停止前缀**。该时刻以后归约已经持有并核验合法原像，可运行任意符合预算的内部延续；这段延续不再被声称与真实签名游戏等分布。主稿R2仍适用于这一明确定义的来源算法，但最终EUF-CMA与OWF组合仅用停止前缀。不得要求秘密H_s输入首次被询问以后仍沿用之前“真实派生输入尚未被查询”的隐式采样理由。

两种实现的实际外部IC、RO与时间均按运行过的完整路径计费，上界R1、R7–R9继续成立。推荐第一种实现，因为与既有停止游戏直接一致；这项澄清不改变地址恒等式、缓存次数或惰性快照的挑战前固定性。
