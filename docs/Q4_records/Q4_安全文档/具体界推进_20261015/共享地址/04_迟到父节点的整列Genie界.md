# 迟到父节点的整列Genie界

2026-10-15；C030-RFAEST128-EQUIV-TIGHT1。root提出候选，equality_adversarial_review独立逐项反驳检查并给出下述证明。本稿新增分析结论，保留第03稿原版本，不覆盖其已记录的研究边界。

**结论：在下面明确的独立辅助理想密码、来源无反馈、有限查询预算及P模板覆盖前提下，root提出的迟到父节点界成立。** 它避开私有候选桶K的可测性问题，改用单次固定切口的完整承诺列。该结论只解决“切口前两边都没有Source记录的父节点，后来匹配旧目标”的事件；规范父节点歧义和池外新叶仍各有独立证明任务。

本分工未运行密码实验或新计算。证明属于概率论推导；genie只给分析器额外信息，不由归约实际枚举整列。

## 1. 模型和事件必须这样定义

所有key、block均为λ位，M=2^λ。每把key的E_p是独立均匀置换。本稿使用原030模型中的辅助IC独立性：公开Rain挑战、外部随机币及RO不另向来源泄漏该辅助IC的未查询关系。若其他方案的公钥自身包含与同一IC相关的隐式条件，需另行证明此处条件分布，不能直接移用。

Source包含攻击者、pk-only模拟器公开重构和最终Verify的所有正逆IC调用。总调用数有预先确定上限q_0，重复调用也计入。普通H₁首次查询数上限为a₁；即使只有部分输入可解析，也用这个较大上限。

Full中的提取器私有读取没有可见反馈：不改变来源回答、RO编程、签名缓存决定、source停止规则或公开调度。私有成功只记录，来源执行按既定有限游戏继续。这个前提与[来源隔离资源稿](../%E6%8F%90%E5%8F%96%E8%B5%84%E6%BA%90/01_%E6%9D%A5%E6%BA%90%E9%9A%94%E7%A6%BB%E7%BC%93%E5%AD%98%E4%B8%8E%E6%83%B0%E6%80%A7%E6%8F%90%E5%8F%96%E8%B5%84%E6%BA%90.md)相同。

固定一份合规H₁查询i的响应前切口及一棵树t。其IV和叶承诺向量已经由来源历史固定；缺失或有歧义的哈希链另由原哈希链事件处理。定义：

~~~text
x_0 = X_iv(0,k_t τ+t)，
x_1 = x_0⊞(1,0,0,0)，
x_C = x_0⊞(0,0,0,τ)，
T_i,t = {(com_2j,com_2j+1):0≤j<N_t/2}，按有序值对去重。
~~~

真实六组中x_0、x_1、x_C两两不同。令l_i,t=|T_i,t|≤N_t/2。

在该切口定义资格集合：

~~~text
P_i,t^0 = {p :
           (p,x_0)和(p,x_1)都没有切口前Source记录}。
~~~

“没有Source记录”同时覆盖正向、逆向规范化后的同一映射；并非只检查正向接口是否出现过。

对任意p定义潜在有序承诺对：

~~~text
F_i,t(p) = ( E_{E_p(x_0)}(x_C), E_{E_p(x_1)}(x_C) )。
~~~

事件L_i,t是：存在p∈P_i,t^0，在切口后的实际Source调用中至少被当作key触达一次，并且F_i,t(p)∈T_i,t。

这里的“触达”包括任意地址、正向或逆向、重复旧行、模拟器及最终Verify；不是只等到父节点扩展地址第一次被问到。F可以仍是潜在值，所以L_i,t比实际验签中用到的迟到父节点事件更大。

由[第03稿RC1(c)](03_%E6%9D%A5%E6%BA%90%E8%AE%B0%E5%BD%95%E6%9C%89%E9%99%90%E8%A7%92%E8%89%B2%E5%AE%8C%E5%A4%87%E5%8C%96%E4%B8%8E%E6%9C%AA%E8%AF%81%E6%A1%A5.md)，只要切口前父节点任一边已经Source触达，P模板就在旧快照覆盖该父节点。因此实际有效开示中未被P模板覆盖的父节点必属于P_i,t^0；验签展开它又必触达其key。故真实迟到父节点事件包含在∪_{i,t}L_i,t中。

上述事件不引用私有K、私有canonical选择或私有成功标志。它只由Source轨迹及同一底层E确定。删除全部私有读取时，逐随机对象耦合保持Source轨迹和E相同，所以事件本身也逐点保持。无需把这个潜在事件误称为只依有限可见Source记录的事件。

## 2. 定理及适用范围

令G_u表示整张IC的全域桶条件：

~~~text
对全部block x、值y，
|{s:E_s(x)=y}|≤u。
~~~

设已由独立论证得到Pr[¬G_u]≤δ_global(u)。当q_0≤M−3时，令：

~~~text
den = (M−q_0−1)(M−q_0−2)。
~~~

则：

~~~text
Pr[∪_{i,t} L_i,t]
 ≤ min(1, δ_global(u)
          + a₁ N q_0 u² / (2 den))，N=Σ_t N_t。          (LP)
~~~

q_0≥M−2时本稿对该项取平凡上界1，不继续使用非正分母。所有参数固定于一个游戏；多参数运行分别计费。

若使用实际去重目标数，可以把a₁N/2替换为各合规切口与树的l_i,t之和的先验上界。每个切口还可以按其剩余来源预算和各key已曝光行数细化，但式(LP)是容易核验的统一界。

没有在式(LP)里额外乘a₂，也没有因Full私有预读次数增加q_0。新增实际私有IC调用仍进入归约资源P_full，这是事件概率账与运行资源账的区别。

## 3. 固定切口后的整列条件分布

先条件于切口前完整来源历史H_src。它包含已经发生的RO和来源随机选择所需信息，但不含提取器私有结果。x_0、x_1、x_C、T_i,t及P_i,t^0此时均固定。

由于来源访问只有普通自适应正逆IC查询，条件于具体历史后，每把key在其已曝光映射之外仍是均匀剩余置换，各key的剩余部分独立。历史中自适应选择IV并不会额外约束未查询表项：所选地址已是该历史的确定函数。若某个候选父输入因所选IV恰与旧Source行重合，该key按定义离开P_i,t^0。

只为分析这一份(i,t)，免费揭示完整列：

~~~text
C(s)=E_s(x_C)，对所有s∈{0,1}^λ。
~~~

x_C与父输入x_0、x_1不同。整列揭示在每把key下最多增加一个已知输入/输出对；如果该行已在Source，则没有新增约束。条件于H_src和具体C之后，各key仍各自服从满足已有行及该C行的均匀剩余置换，且剩余部分仍跨key独立。

对p∈P_i,t^0，记R_p是其尚可用于父输入的输出集合，m_p=|R_p|。切口前该key的Source行数至多q_0，所以：

~~~text
m_p ≥ M−q_0−1。
~~~

两个不同父输入的有序输出均匀分布在R_p的m_p(m_p−1)个不同值对上。

令完整列的seed桶为：

~~~text
B_C(c) = {s:C(s)=c}。
~~~

它是当前已揭示C的确定集合，与私有K不同。对一个目标(c_0,c_1)，令：

~~~text
a=|B_C(c_0)∩R_p|，b=|B_C(c_1)∩R_p|，
c=|B_C(c_0)∩B_C(c_1)∩R_p|。
~~~

因此：

~~~text
Pr[F_i,t(p)=(c_0,c_1) | H_src,C]
  = (ab−c)/(m_p(m_p−1))。                               (16)
~~~

若当前列所有桶宽≤u，则式(16)≤u²/den，对l_i,t个目标并合至多l_i,t u²/den。重合桶、相同com与置换输出不同的约束只会降低该上界。

## 4. 自适应key选择和逆向调用

只有式(16)还不足以直接把p换成事后挑中的key。为此给同一固定(i,t)建立增广分析过滤族：

1. 初始拥有H_src与整列C。
2. 每当实际Source将要发出切口后的IC调用，其key p已经被确定。
3. 若p∈P_i,t^0且此前尚未在本切口的post-Source调用中触达过，分析器立刻揭示E_p(x_0)、E_p(x_1)。这些值不返回给真实来源算法；原调用随后按正常Oracle规则进行。
4. 已被这样揭示过的key，不再计作新的候选key。

在第3步之前，对于这个被选中的p，切口后还没有任何Source调用查询过key p；整列C之外，也没有本分析器对它的父行揭示。其他已揭示key的父行及全部后续来源调用，只约束其他key的剩余置换。所有下一步选择均对增广历史可测，故跨key乘积条件分布保证：这次p的两个父输出仍是第3节中的均匀有序对。

即使p在切口前已有其他地址的Source记录，它们都已经计入R_p；即使下一调用重复一条旧Source行，仍先揭示这把key的父二块。因此来源不能通过先在别的地址观察同key再挑p来避开这次计费。

逆向调用也一样。其方向、给定输出以及key都在新逆向答案之前固定。本证明直接界定预先存在的父二块匹配事件，再让逆向查询揭露同一置换中的一个位置；没有把逆向调用给定的输出冒充随机输出。若逆向响应恰落到父输入，它只是揭露了已被genie计费的值。

逐次新的key数至多切口后实际Source调用数，因此至多q_0。每次条件概率≤l_i,t u²/den，使用自适应并合界得到：对任何符合当前列桶帽的具体C，

~~~text
Pr[L_i,t | H_src,C] ≤ min(1,q_0 l_i,t u²/den)。            (17)
~~~

本证明不要求不同key的“命中事件”在最后对手轨迹中独立。只需每次揭示前对尚未揭示key的局部条件界。

也可把genie描述为给强对手额外信息，但必须在选择key时先消耗一个来源调用槽，避免免费试看无数key后撤回调用。采用本稿analysis-only过滤族，没有这个计数歧义。

## 5. 数值seed别名不破坏证明

这里没有要求key p、其两个孩子、任一com值彼此作为λ位字符串互异，除了同一置换两个不同输入的输出应不同。

- C(p)与p相同或不同，都只改变R_p中被排除的一个数值。
- p可以恰好属于某个B_C(c)，父节点可以指向自身key；式(16)仍按R_p与桶的交集计数。
- 其他父节点的输出可以成为下一被触达的key。条件于完整C之后，已揭示key的剩余置换与尚未揭示key的剩余置换独立；这种数值引用只改变选择策略。
- 若某数值引用回已经揭示的key，则复用其既有结果，不新增一次成功概率机会。

这是揭示完整C列的作用：孩子作为key再调用C时，相关映射已是确定表查找；不再与当次父输出采样形成待分析的隐式递归依赖。

## 6. 全域桶事件和自适应IV的正确合成

这里特意没有条件化于G_u。G_u还限制x_0、x_1及其他列；若把它加入剩余置换的条件，式(16)的均匀性会改变。

记CGood_i,t为当前选定x_C列桶宽≤u。由定义G_u⊆CGood_i,t。对固定切口的来源历史，先揭示C并只在CGood_i,t的具体列值上使用式(17)，可得：

~~~text
Pr[L_i,t ∩ G_u]
 ≤ Pr[L_i,t ∩ CGood_i,t]
 ≤ q_0 l_i,t u²/den。                                   (18)
~~~

这是包含关系和对当前C的点态条件界；不是在全局未来好事件条件下声称独立。

每个实际H₁切口的IV可以依赖全部此前来源历史。第3节先条件于这个具体历史，再揭示已经确定地址的一列，已覆盖这种自适应性。随后对普通H₁序号i与树t并合：

~~~text
Pr[∪L_i,t]
 ≤ Pr[¬G_u] + Σ_i,t Pr[L_i,t∩G_u]
 ≤ δ_global(u) + q_0 u²/den · Σ_i,t l_i,t
 ≤ δ_global(u) + a₁ N q_0 u²/(2den)。
~~~

**每个(i,t)分别建立一个分析genie。** 这些是同一原游戏事件的不同边际分析，最后只作并合；没有在同一执行中先免费揭示全部自适应选中的C列。若连续揭露很多列，某个后续父输入可能早已被其他列完全揭示，不能再直接套本稿的单列条件分布。

如果某个普通H₁序号实际不存在或格式不可解析，对应事件取空。故a₁仍是合法先验上界，不需要以最终成功查询数替代。

## 7. 与Full预读及P模板的接口

上述证明可以先用无反馈耦合删除全部Ext私有读取，再作事件分析。删除后完整E仍是同一个随机对象，Source轨迹逐点相同，L_i,t的定义也逐点相同。Full是否提前知道父二块在这里不构成事件条件。

这一步的限度是明确的：若改成“父二块命中私有K中的两个seed集合”，K一般依赖被删除的私有值，第3节的整列替代尚未自动成立。本稿的目标是实际完整叶承诺对，因而可以使用B_C(c)而不使用K。

P模板用于前后的逻辑衔接：旧Source半边已经被旧快照覆盖，剩余父节点才落入P_i,t^0。无需要求所有Full半边都被枚举覆盖。本稿也没有将“P未覆盖”的私有标签本身加入概率条件；使用的是更大的、纯Source资格集合。
