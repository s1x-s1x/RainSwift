# 有限候选族与仿射提取替代引理

2026-10-15；候选 C030-RFAEST128-EQUIV-TIGHT1；数学研究稿。对象为原版030六组参数及其继承的共享 AES 地址结构。作者分工：equality_adversarial_review。

**结论分类：有条件定理，给出完整代数证明与挑战前有限族的概率界。** 在下述底层兄弟对覆盖前提下，叶承诺可以有多个已登记原像，相同的洞兄弟误差也可以在多个位置重复。提取器仍可在线获得覆盖全部合格开示的公共仿射 VOLE。这里无需单独排除“两个相同误差异或为零”的4-XOR事件。

本稿扩展了[协议组件报告第4.1节](../../%E7%B1%BB%E5%88%AB1%E6%A0%B8%E9%AA%8C_20261015/%E5%8D%8F%E8%AE%AE%E5%88%86%E6%9E%90/%E5%8D%8F%E8%AE%AE%E7%BB%84%E4%BB%B6_%E5%8F%8D%E4%BE%8B%E4%BF%AE%E8%AE%A2%E4%B8%8E%E5%AE%A1%E6%9F%A5%E6%8A%A5%E5%91%8A.md)已有的单树观察：新增挑战前候选族、跨树一致性、可执行提取规则及 AU 计数。底层兄弟对覆盖的具体损失尚须单独证明；本稿没有据此宣告128位完整界已经闭合。

## 1. 对象和时间切口

固定一份首次普通 H₁ 查询及其已经解析的 IV、各树叶承诺向量、修正串 c_t。切口取在该输入第一次任意长度响应之前，零长度查询和后续 XOF 补长沿用[原01](../../Q4_%E9%87%8D%E5%81%9A_01_P01_%E5%9C%A8%E7%BA%BFPPT%E6%8F%90%E5%8F%96%E5%99%A8%E4%B8%8E%E6%AD%A3%E7%A1%AE%E6%80%A7.md)的时序规则。签名模拟器编程的 H₁ 行另由新消息链隔离处理。

树 t 有 N_t=2^{k_t} 个叶位置，位置从0编号。每份有效 copath 只直接暴露洞 β 的兄弟 β⊕1；其他可见叶由完整可见子树展开。这两个位置恰在最低索引位不同。列采用源码自然的二进制位编号 h=0,…,k_t−1。

每个 tape 为 L 位有意义数据，包含 QuickSilver 数据行及 VHash 掩码行；存储填充位不属于本引理的向量。记：

~~~text
H = VH_χ : F₂^L → F₂^{λ+b}，χ 为本次新 H₁ 的回答
M_t,j ∈ F₂^L                     冻结的基线 tape
U_t = ⊕_j M_t,j
A_t = U_t ⊕ c_t
V_t,h = ⊕_{j: j_h=1} M_t,j
~~~

c_t 可由对手恶意选择；不假设诚实的修正关系。代码约定 c_0=0 时直接取零。

对每个位置 j，冻结一个有限的候选 seed 集 K_t,j，其成员在对应完整叶承诺地址确实给出 com_t,j。它可由受控的 oracle 记录索引构建；本稿只要求集合及其成员 tape 在 χ 产生前已确定，资源和覆盖由另外的引理提供。允许同一 seed 在多个位置复用。上界 u 是切口前确定的统一候选数上限，而非看到 χ 后挑选的参数。

对洞 β 定义：

~~~text
E_t,β = { m_t(s) ⊕ M_t,β⊕1 : s∈K_t,β⊕1 }
E_t   = ∪_β E_t,β                 按误差值去重
~~~

同一候选 seed 的 tape 完备化可以私有读取，但应在响应 χ 前结束；既有快照随后保持不可变。E_t,β 按 tape 误差去重，多个 seed 给同一 tape 不增加候选 q。

## 2. 结构覆盖前提 G

本定理的 G 是关于固定快照及其后兼容开示的前提，不是已经得出的概率结论。它包含：

1. 对每个完全可见的底层兄弟对，其开示所得有序 tape 对等于冻结基线 (M_t,2i,M_t,2i+1)。需要的是有序 tape 一致；seed 唯一并非必要条件。
2. 洞兄弟的直接暴露 seed 属于对应 K_t,β⊕1。
3. 原哈希链论证已使这些开示对应同一 IV、同一承诺向量及同一修正串；哈希链、格式、编程行隔离各按其自己的事件付费。

条件1可由“挑战前登记的全部匹配父节点有相同有序 tape 对，且随后没有未覆盖的匹配父节点”推出。但该充分条件本身的概率尚未在本稿证明。单个叶承诺生日碰撞既不等于条件1失败，也不自动证明条件1成立。

若切口前某个底层对没有可用基线父节点，可以给该对任取基线 tape（例如全零），同时把“任何完全可见的底层对都已经被登记覆盖”作为 G 的部分。于是合法洞必须落在这个缺失对中；若有两个不同缺失对，任何单洞开示都会留下至少一个完全可见的未覆盖对，故 G 下没有兼容开示。该分支未把一个缺失对误作两个缺失叶。

在 G 下，每份洞为 β 的开示只在 β⊕1 处可能偏离 M；洞 tape 在每个 q 列中的系数为零。因此对它对应的某个 e∈E_t,β，逐列有：

~~~text
q_t,h(β,e) = V_t,h ⊕ β_h A_t ⊕ [h=0] e.                 (1)
~~~

证明：重构列为 ⊕_{j:(j⊕β)_h=1} m_j ⊕ β_h c_t。换成基线后先得到 V_t,h⊕β_h A_t。洞的系数为0；兄弟与洞仅最低位不同，所以替换兄弟 tape 的修正项只在 h=0 出现。没有使用 H、独立性或碰撞假设。

此后对所有 (β,e∈E_t,β) 分析，即分析合法开示的一个超集。即使某候选不对应完整合法上层 copath，也不影响覆盖结论。

## 3. 单树仿射定理

在 χ 已产生之后，对手任意选择 H₂ 输入中的 ũ、各列 Ṽ_t,h 和 d。允许这些值依赖 χ。暂省略 t，定义：

~~~text
B   = ũ ⊕ H(A)
D_h = Ṽ_h ⊕ H(V_h)
~~~

候选 (β,e) 通过叶级 VHash 检查，当且仅当：

~~~text
D_h = β_h B                       对 h>0
H(e) = D_0 ⊕ β_0 B.                                      (2)
~~~

令 S 为通过式(2)的候选集合。定义事件 BadE 为 E 中存在不同误差 e≠e′，但 H(e)=H(e′)。以下排除 BadE。

### 3.1 同一个洞只有一个 q

固定 β 后式(2)给 H(e)唯一目标值。H 在不同 E 元素上单射，所以至多一个误差 e通过。多个 seed 给这个相同 e 对应完全相同 q，可合并。因此 S 的大小等于通过洞数。

### 3.2 通过洞跨越两个底层兄弟对

若通过洞 β、γ 满足 β>>1 ≠ γ>>1，至少一个高位 h>0 不同。二者的高位式(2)相减，得 B=0。因此全部通过误差具有同一哈希值 D_0；排除 BadE 后全部等于一个 e*。

取：

~~~text
u* = A
v*_h = V_h ⊕ [h=0] e*.
~~~

代入式(1)即对全部 S 成立：

~~~text
q_h = v*_h ⊕ β_h u*，
H(u*)=ũ，H(v*_h)=Ṽ_h.                                  (3)
~~~

任取两个不同通过洞，某一列的 β 位不同，该列的 q 差直接确定 u*。所以只要通过洞至少两个，公共 u*唯一。

共享地址产生的相同误差在此只改变公共最低列 v*_0。它无须被命名为坏事件，也无须具有很小发生概率。

### 3.3 全部通过洞在同一个底层兄弟对

至多有偶数洞 α 和奇数洞 α+1。若两者均通过，分别记误差 e_0、e_1，取：

~~~text
u* = A ⊕ e_0 ⊕ e_1
v*_h = q_h(α,e_0) ⊕ α_h u*.                              (4)
~~~

两洞高位相同、式(1)的高列 q 也相同；低列之差正是式(4)的 u*。故式(3)对两个洞成立。由式(2)：

~~~text
H(e_0) ⊕ H(e_1) = B，
H(u*) = H(A) ⊕ B = ũ。
~~~

再把任一通过点的哈希等式代入 v*定义，得到 H(v*_h)=Ṽ_h。k=1 自动落在这一分支。

若只有一个通过洞，给定任意满足 H(u*)=ũ 的外部 u*，均可取 v*_h=q_h⊕β_h u* 使式(3)成立。此时本树自身没有确定 u*。若没有通过洞，兼容合法开示不存在。

## 4. 挑战前有限的 u 候选族

每棵树在 H₁ 回答前定义：

~~~text
F_t = {A_t} ∪ ⋃_{i=0}^{N_t/2−1}
      { A_t ⊕ e_0 ⊕ e_1 :
        e_0∈E_t,2i，e_1∈E_t,2i+1 }.                       (5)
~~~

F_t 可以隐式存储；无需预先枚举所有森林开示。第3节说明，只要本树有至少两个通过洞，其唯一 u_t*必属于 F_t，并满足 H(u_t*)=ũ。

精确计数和通用上界为：

~~~text
|E_t| ≤ Σ_β |E_t,β| ≤ Σ_j |K_t,j| ≤ N_t u，
|F_t| ≤ 1 + Σ_i |E_t,2i| |E_t,2i+1|
      ≤ 1 + (N_t/2)u².                                  (6)
~~~

这些是上界；重复值应去重。若全部候选只能给基线 tape，那么 E_t={0}、F_t={A_t}，无须沿用 N_t u 的松上界。特别是在基线确实由唯一候选组成的普通完整树中，本结论退化成原01的单一完整向量分析。

### 4.1 按不同承诺值和不同有序承诺对去重

这一节是确定性计数改进，不为桶宽增加任何随机性假设。所有集合仍须在χ前固定。

设同一树中每个不同承诺值c对应冻结桶K_c，κ_c=|K_c|，各位置的K_t,j均包含在对应K_com(j)中。再假设基线M_j是该桶中某个seed的tape。由于同树同一叶承诺地址和tape地址在各位置相同，每个候选误差都是同桶两个tape之差。因此：

~~~text
E_t ⊆ {0} ∪ ⋃_{c出现于本树}
      {m(s)⊕m(s′): s,s′∈K_c，s≠s′}，
|E_t| ≤ 1 + Σ_c C(κ_c,2)。                              (6a)
~~~

重复叶位置不再重复计费；不同seed恰有同一tape也只减小集合。若有任意基线位置（例如缺失底层对用零基线），这些位置不自动满足基线来自K的条件。令J为此类位置，把式(6a)右边再加 Σ_{j∈J}|K_com(j)| 即是一个通用上界；或者仍对这些位置使用式(6)。

对每个不同有序承诺对(a,b)，设其全部出现位置采用同一个规范有序tape对T_ab=(M_even,M_odd)。这是“同一有序com对的完全可见父节点tape一致”的额外确定性条件；若规范规则仍按位置变化，应保留位置区分。令：

~~~text
D_t = {(com_2i,com_2i+1):0≤i<N_t/2}，去重；
S_c = {m(s):s∈K_c}；
P_ab = M_even⊕M_odd；
G_ab = {P_ab⊕x⊕y : x∈S_a，y∈S_b}。
~~~

式(5)每个底层对的贡献恰落在 A_t⊕G_ab；重复有序com对的贡献相同。若规范两片tape都属于对应S，则0∈G_ab，于是：

~~~text
F_t ⊆ {A_t} ∪ ⋃_{(a,b)∈D_t}(A_t⊕G_ab)，
|F_t| ≤ 1 + Σ_{(a,b)∈D_t} (|G_ab|−1)，                 (6b)
|G_ab| ≤ κ_a κ_b                         若a≠b，
|G_aa| ≤ 1+C(κ_a,2)                      若a=b。
~~~

等号是否成立取决于位置候选是否使用整个桶；作为上界无需位置集合相等。对a=b，x⊕y的相同值对只给0，不同值对无序计数，所以得到更小的对角界。各G_ab之间还可以再次去重。

另外，不要求上述桶条件，直接从E_t的定义就有：

~~~text
F_t ⊆ A_t ⊕ ({0}∪{e⊕e′:e,e′∈E_t，e≠e′})，
|F_t| ≤ 1+C(|E_t|,2)。                                   (6c)
~~~

使用时取式(6)、(6a)、(6b)、(6c)中适用上界的最小值，并优先保留精确集合大小。若全部基线来自唯一候选，则每个E_t={0}、G_ab={0}，从而F_t={A_t}；树内BadE消失，跨树计数回到至多C(τ,2)，无需付N或u的虚构损失。

本节的K_c可以包含受控私有完备化的seed，前提是它们以明确有限规则在χ前冻结；若只取Source桶而基线seed来自私有父节点展开，须先证明基线成员条件，或把这些seed加入并重新计费。由全部理想密码的全域桶帽得到一个最大u，并不等于其最坏u⁴代价已经满足具体等强目标。

## 5. 森林的一致性和在线提取

定义 BadF：存在树 t≠s、值 f∈F_t、g∈F_s，满足 f≠g 且 H(f)=H(g)。

排除所有 BadE 和 BadF。先在每棵树上按式(2)找到 S_t：

- 若某 S_t 为空，本次 H₂ 输入不兼容。
- 若至少一树有两个或更多通过洞，取最小此树的唯一 u_t*作为全局 u*。
- 任意另一棵具有两个或更多通过洞的树也有 H(u_s*)=ũ。若 u_s*≠u*，就触发 BadF；故它们全部相同。
- 对每个只有一个通过洞的树，以这个全局 u*定义 v*_t,h=q_t,h⊕β_t,h u*。
- 非活跃列置零，检查真实格式的尾部要求；取 w*=d⊕u*[0:ell]。

于是同一 H₂ 记录的全部兼容后续真实开示，都逐行逐列满足：

~~~text
Q = V* ⊕ u* Δᵀ，
VH(u*)=ũ，VH(v*_t,h)=Ṽ_t,h。                              (7)
~~~

这正是原01第6节将 QuickSilver 的最高次系数固定在 H₂ 回答之前所需的接口；之后的 QS/ZHash、根数与 Rain 原像抽取仍使用各自独立证明。

若每棵树都只有一个通过洞，则拼成唯一 Δ*，包括冻结的 grinding 零位。提取器返回 fixed/⊥ 并缓存 Δ*；未声称任意 u*已被提取。每次普通原始 H_Δ 查询命中这一个 λ 位值的概率为2^−λ，沿用原02的原始查询计数，无需按已经成功 grinding 的分布重计。

可执行规则：

~~~text
BeforeFirstOrdinaryH1:
    冻结结构索引、基线、K及全部候选tape
    计算A,V、E；F按(5)隐式确定
    保存不可变快照；然后回答χ

BeforeFirstH2:
    查对应快照；计算候选误差的VH值，按(2)求各S_t
    发现同一β不同通过误差时，返回BadE
    空集返回incompatible
    至少一树有≥2洞时，按(3)/(4)确定其u_t*
    不同多洞树的u_t*不同时返回BadF
    若全部单洞，返回fixed并记录Δ*
    否则填充V*和w*；先缓存结果，再回答H₂
~~~

重复 H₂ 输入复用首次缓存。算法只枚举每树的 β 及其有限 E_t,β，未枚举2^{Σk_t}个森林洞组合。已有候选 tape 后，一次 H₂ 检查可用误差哈希索引，时间为 O(Σ_t(N_t k_t + Σ_β|E_t,β|)) 次定长向量/哈希操作；朴素实现再多一项 k_t 因子仍为多项式。H、VHash 的位运算成本按 L、λ另计。F_t只作分析时的隐式族，实际算法无须物化 u²个组合。候选 tape 完备化的新增 IC 次数由资源稿另记，未在此抹去。

## 6. AU 界与自适应性

实际 VH 对每个在 χ 产生前固定的非零差分 z 满足：

~~~text
Prχ[ VH_χ(z)=0 ] ≤ εV
εV = 2^{−(λ+b)} + (n−1)(2n−1)·2^{−(λ+64)}，
n=R+1，λ=128，b=48。
~~~

这是[原02式B5](../../Q4_%E9%87%8D%E5%81%9A_02_P01_%E5%9D%8F%E4%BA%8B%E4%BB%B6%E4%B8%8E%E8%87%AA%E9%80%82%E5%BA%94%E5%88%86%E6%9E%90.md)已给出的 AU 性质。Rain-3为 2^−176+21·2^−192，Rain-4为 2^−176+36·2^−192。

条件于本次首次普通 H₁ 响应之前的历史，包括已经完成的私有 tape 读取，E_t与F_t都是固定有限集合；新χ仍独立。对下列非零差分作并合：

~~~text
树内：  e⊕e′，e,e′∈E_t，e≠e′；
跨树：  f⊕g，f∈F_t，g∈F_s，t<s，f≠g。
~~~

得到单次界：

~~~text
Pr[BadE ∪ BadF | H₁前历史]
 ≤ εV · [ Σ_t C(|E_t|,2) + Σ_{t<s}|F_t||F_s| ]。          (8)
~~~

若候选数有确定上限u，则全部a₁次首次普通H₁上的界为：

~~~text
ε_affine
 ≤ min(1, a₁ εV · {
      Σ_t C(N_t u,2)
      + Σ_{t<s}(1+N_t u²/2)(1+N_s u²/2)
   })。                                                  (9)
~~~

实际使用精确去重集合可以更小。如果只在某个候选大小好事件上保证u，则必须另外支付该事件的失败概率，或直接用实际集合规模的期望并合界。u的概率来源尚未由式(9)证明。

**时序要点：**

1. 式(8)先在固定快照上定义坏事件，不条件化于未来结构覆盖G成立；G可能依赖χ。最终使用的是“G且没有这些AU事件，则式(7)成立”，再对 G 的补集与 AU 事件分别并合。这样避免在未来好事件条件下擅自维持χ均匀的错误。
2. ũ、Ṽ、d及通过洞集合可以自适应选择；所有可能出现的有害相等已经列在挑战前有限族中。因此同一χ后的多个H₂目标无需再乘a₂。
3. 相同误差异或为零没有列入任何AU项。其概率可以为1；第3.2节直接吸收其公共偏移。
4. 随后才发现的新seed或新tape须由覆盖事件单独处理；将其补进旧E、F后，式(8)的挑战前固定性前提已变。
5. Source过滤族中的迟到匹配界与这里包含私有读取的H₁前过滤族不同。各自正确的边际界可以并合；两种过滤族之间的独立性未被假设。
