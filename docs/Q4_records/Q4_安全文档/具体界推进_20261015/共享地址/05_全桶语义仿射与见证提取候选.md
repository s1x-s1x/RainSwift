## 2. 当前森林地址与可见支持池

对当前H₁森林，设树t高度k_t：

~~~text
x_C,t = iv ⊞ (0,0,0,(k_t+1)τ+t)
x_0,t = iv ⊞ (0,0,0,k_t τ+t)
x_1,t = x_0,t ⊞ (1,0,0,0)
T_t,c = iv ⊞ (c,0,0,2^31+t),  0≤c<r
m_t(s) = prefix_L(E_s(T_t,0) || ... || E_s(T_t,r−1))
C_t(s) = E_s(x_C,t)
~~~

四个lane各自模2^32加法。[00b第4节](../../Q4_%E9%87%8D%E5%81%9A_00b_%E5%85%AD%E7%BB%84%E5%8F%82%E6%95%B0%E8%A1%A5%E5%85%85%E6%98%A0%E5%B0%84.md)已按源码列出这些偏移。六组的所有结构tweak小于2^31，tape的高lane偏移为2^31+t；固定IV的模加为双射。因此：

1. 当前森林的全部x_C、x_0、x_1与全部T_t,c互异；
2. 不同树的tape输入集合互不相交；同树各c的输入互异；
3. 这里只对同一当前森林成立；跨IV、历史Full角色或重复调用另论。

在一次首次普通H₂切口（回复χ₂之前），对树t定义有限支持集合K_vis,t：

- 若Source前缀有key为s、input为x_C,t或任一T_t,c的行，则s属于K_vis,t；
- 若Source前缀有父key p、input为x_0,t或x_1,t的行，则其真实两片child seed都属于K_vis,t；
- 只按以上Source根生成，不递归使用私有派生行。

对承诺值z，取K_vis,t(z)={s∈K_vis,t:C_t(s)=z}。这恰可由[03的C/T/P有限模板](03_%E6%9D%A5%E6%BA%90%E8%AE%B0%E5%BD%95%E6%9C%89%E9%99%90%E8%A7%92%E8%89%B2%E5%AE%8C%E5%A4%87%E5%8C%96%E4%B8%8E%E6%9C%AA%E8%AF%81%E6%A1%A5.md)在当前(x_C,t,k_t)上下文实现；也可直接扫描当前森林的Source索引。实际算法使用这个池就足够。若另行使用更大的受控有限池，下文概率事件仍可取K_vis这个子池，以免把任意Full成员性带入条件分布。

**可见支持引理。** 给定H₂的Source历史，再揭示当前森林的全体父节点两列与com列后，K_vis及所有H₁ canonical seed的选择完全确定，且无须揭示任何当前tape值。任意s∉K_vis,t满足：

~~~text
Source从未触达 (s,T_t,c)，全部c；
s不是当前树任意canonical seed。
~~~

证明：前一条为K_vis第一项的逆否命题；若s为canonical seed，其所选父节点在H₁已有Source一侧，由第二项s∈K_vis,t。canonical的选择只依第1节列出的非tape信息。历史Source可能查询过其他IV解释的地址；若其实际(key,input)等于当前(s,T_t,c)，仍直接触发第一项，故没有遗漏。

## 3. H₁前固定的全桶候选族

仅在分析中定义完整理想密码承诺桶：

~~~text
B_t(z) = { s∈{0,1}^λ : C_t(s)=z }
E_t,β^all = { m_t(s) XOR M_t,β⊕1 : s∈B_t(com_t,β⊕1) }
E_t^all = union_β E_t,β^all，按值去重
~~~

桶和tape都是预选完整E与H₁快照的确定函数；即使某seed后来才被Source发现，它从一开始已在上述语义全集中。B不枚举2^λ个key，也不获得整张E。

对底层对i及a∈B_t(com_t,2i)、b′∈B_t(com_t,2i+1)，定义：

~~~text
U_t,i(a,b′) = A_t XOR M_t,2i XOR M_t,2i+1
                  XOR m_t(a) XOR m_t(b′)
D_t,i = A_t XOR M_t,2i XOR M_t,2i+1
F_t^+ = {A_t}
      union 所有U_t,i(a,b′)
      union {D_t,i : com_t,2i=com_t,2i+1}
~~~

D项在两个com相等时显式加入，即使该全桶为空也加入。这一点使实际可计算的零XOR候选始终属于挑战前语义族。若桶非空，选a=b′已经产生D；若桶空，新补项只有一个。

在当前com列的全桶上限u≥1成立时：

~~~text
|E_t^all| ≤ N_t u
|F_t^+| ≤ 1+(N_t/2)u².                                  (16)
~~~

证明：每个非同com底层对至多u²种seed组合；同com且非空时D已包含在组合中；空桶时补一个D≤u²。按值去重只减少数量。已有01 §4.1的去重技巧在其前提满足处仍可用；这里保留简单统一上界。

令F^+=union_t F_t^+。定义两个AU坏事件：

~~~text
BadE: 某t的E_t^all内存在e≠e′且VH_χ1(e)=VH_χ1(e′)
BadU: F^+内存在f≠g且VH_χ1(f)=VH_χ1(g)
~~~

BadU包括同一树内部不同u，不只包括跨树。已知候选可能与实际多洞树来自同一个F_t，因此这是见证提取新规则所必需的费用。

条件于H₁前的全部E、历史RO及Source输入，以上集合已固定，新普通χ₁仍独立均匀。实际VHash的AU常数为：

~~~text
εV = 2^−176 + R(2R+1)·2^−192
~~~

每次首次普通H₁的条件界：

~~~text
Pr[BadE union BadU]
 ≤ εV [ Σ_t binom(|E_t^all|,2) + binom(|F^+|,2) ].       (17)
~~~

若G_cap是全域桶帽≤u，则对全部a₁次普通首次H₁：

~~~text
Pr[(BadE union BadU) ∩ G_cap]
 ≤ a₁ εV [
       Σ_t binom(N_t u,2)
       + binom(Σ_t(1+N_t u²/2),2)
   ].                                                    (18)
~~~

全域桶帽失败δ_cap由独立桶界支付，合成时只支付一次。这里使用G_cap是E的事件以及逐H₁新χ₁的独立性；没有条件化未来有效伪造、通过的洞或其最终开示。

H₂实际池可随χ₁后Source增长，原因是它只找到了F_t^+中原有的一部分元素；这不允许重新选择H₁ canonical或向全族加入依χ₁新定义的其它值。

## 4. 全语义开示的仿射性

固定普通首次H₂输入X₂，其中ũ、全部Ṽ_t,h和d已给定；χ₂尚未采样或透露。记H=VH_χ1：

~~~text
B_t = ũ XOR H(A_t)
D_t,h = Ṽ_t,h XOR H(V_t,h)
S_t = { (β,e):
        e∈E_t,β^all，
        D_t,h = β_h B_t (h>0)，
        H(e) = D_t,0 XOR β_0 B_t }
~~~

S_t中的同误差多seed合并。排除BadE后，每个β至多一个通过的e；01的代数证明直接适用，因为该证明只要求有限集合，未要求集合由B枚举。

在G_pair下，任何后续实际合格开示属于S_t，并有：

~~~text
q_t,h = V_t,h XOR β_h A_t XOR [h=0]e.                    (19)
~~~

若S_t具有至少两个不同洞，存在唯一u_t∈F_t^+，H(u_t)=ũ，且该树全部S_t满足q_t,h=v_t,h+β_h u_t。若S_t只有一个洞，对任意H(u)=ũ都可调整v_t,h使式成立。若S_t为空，没有兼容开示。

若再排除BadU，所有多洞树给出的u_t相等。此结论及S_t完全由E、H₁快照、χ₁和X₂确定，尚未使用χ₂或最终Δ。

## 5. 可执行的见证提取器：只算有限已知u

B在H₂响应前用Source水位执行C/T/P有限完备化，读取K_vis成员需要的真实tape，再枚举：

~~~text
KnownU =
    {全部A_t}
    union {D_t,i : 两个com相同}
    union {
      U_t,i(a,b′) :
      a∈K_vis,t(com_t,2i)，b′∈K_vis,t(com_t,2i+1)
    }.
~~~

KnownU⊆F^+。即使同com桶空，D也已由第3节纳入语义族。实际算法无需显式物化全部二次组合：H是GF(2)线性的，可以用两侧哈希表查找异或补值。u是预先固定的桶限额；先按seed去重，某个目标com桶超过u时只私下标记cap-overflow并跳过本次提取。该事件包含于全域桶帽失败，Source依然正常回答χ₂。

~~~text
BeforeFirstOrdinaryH2(X2):
    解析所指普通H1的历史快照及H1固定canonical
    若哈希链/格式尚无接口，存对应失败分类
    以当前Source水位构建有限K_vis
    若某目标com桶有>u个不同seed：
        私下标记cap-overflow并跳至正常χ2响应
    普通读取所需tape，缓存每个H(m_t(s))
    按固定顺序检查全部A_t和同com对D_t,i是否H值为ũ
    若尚无匹配，按固定(t,i)顺序：
        h_target = ũ XOR H(A_t XOR M_t,2i XOR M_t,2i+1)
        左桶按H(m_t(a))建字典，每个值保存固定顺序首个a
        按固定顺序扫描右桶b′，查找h_target XOR H(m_t(b′))
        首次命中即算f=U_t,i(a,b′)，停止本次搜索
    若找到匹配f：
        保存f及W=d XOR f[0:ell]
        将W首λ位转到真实Rain密钥基，检验公开关系
        若有效且未保存过成功密钥，只作私有缓存
        本次H2标记known
    否则本次H2标记unknown
    保存本次缓存，然后正常采样/响应χ2
~~~

字典使用平衡树即可，不假定攻击者输入下散列表均摊复杂度。相同左哈希值只留一个seed不影响“存在匹配”的完备性：线性H使任何一个同值代表都与相同右seed产生合格f。找到的f实际计算为完整L位向量，始终属于KnownU。不同匹配f中取算法规定的第一个即可，无须取全族的最小数值。全族的u²规模只用于AU计费；实际搜索不枚举u²个组合。

重复输入复用第一次H₂的结果，不以随后新增Source行追改过去的分支。提取成功也继续来源流程。

**见证提取子结论。** 在G_pair、非BadE、非BadU下，若known分支找到f且各S_t非空，则可在χ₂前定义语义矩阵V*，使所有兼容的后续开示同时满足：

~~~text
Q = V* XOR f Δ^T，W=d XOR f[0:ell]。                      (20)
~~~

证明：每个多洞树的u_t∈F^+与f∈F^+具有相同VH值，BadU补集使u_t=f。单洞树按唯一(β,e)定义v*=q+βf。每棵多洞树按其全部S_t中的字典序首点定义v*=q+βf；01定理保证此选择同时覆盖该树全部点。空S_t时标记无兼容开示。inactive列按冻结格式置零；实际Δ的grinding位为零。

关键是B已经计算f和W；V*只用于证明。B没有执行全桶搜索，也没有借用指数算法寻找见证。矩阵V*的定义在χ₂前仅依E、历史输入和χ₁，足以固定下一节多项式。

即使所有树都为单洞，只要KnownU匹配，该定义仍成立。没有理由仅因未知的最低列偏移e而把这次提取记成失败。

## 6. 为什么Rain归约不需要实际计算V*

只读核对原030源码：

- [owf_proof.inc:731](../../../../../src/owf_proof.inc#L734)的rain_combine对标签作固定GF(2)线性组合；
- [owf_proof.inc:760](../../../../../src/owf_proof.inc#L763)至772按W形成密钥、各轮逆元输入/输出与公开常数；
- [quicksilver.hpp:545](../../../../../src/quicksilver.hpp#L545)至549实际加入x*y+1；
- [quicksilver.hpp:584](../../../../../src/quicksilver.hpp#L584)的掩码和proof项最高只贡献一次项。

把Δ换为形式变量X，每一约束为：

~~~text
f_i(X)=a_i,0+a_i,1 X+e_i(W)X²
e_i(W)=x_i(W)y_i(W)+1。                                 (21)
~~~

低次系数可依赖语义V*；最高次系数只依赖B已计算的W与公开Rain参数。其源码依据同[原01第6节](../../Q4_%E9%87%8D%E5%81%9A_01_P01_%E5%9C%A8%E7%BA%BFPPT%E6%8F%90%E5%8F%96%E5%99%A8%E4%B8%8E%E6%AD%A3%E7%A1%AE%E6%80%A7.md)。

若候选密钥没有通过真实Rain公开关系，则e(W)≠0：反之所有逆约束成立就推出正确Rain原像。χ₂尚新鲜，故旧ZHash非零向量消失界仍可对已固定e(W)收费；B无需算V*才能使用该界。排除E=ZH_χ2(e)=0后，实际QS等式为最高系数E≠0的二次式，任意已固定HΔ输入下最多两个Δ根。

无反馈实现允许B检查见证、私下缓存成功后继续A。全E只向分析器揭示；它不是B收到的辅助输入，也不从OWF运行预算删除实际求值成本。

## 7. 无匹配已知u时的确定性二点分支

若本次没有cap-overflow，且unknown分支完整搜索后没有任何KnownU匹配，则特别地H(A_t)≠ũ，对全部t有B_t≠0。由01的高列方程，S_t的全部通过洞只能位于同一个底层对，故每树至多两个洞。

如果各S_t非空且至多一棵树有两个洞，整个森林的洞向量组合至多两个；加上固定的grinding零位，兼容的λ位Δ集合仍至多两个。该集合是χ₂前已由E、χ₁与X₂固定的语义集合，不要求B显式求出。

如果至少两棵树各有两个洞，则它们给出同一个u（非BadU），并各自存在某一底层对i及seed a,b′：

~~~text
u = U_t,i(a,b′)，H(u)=ũ。
~~~

该pair具有两条性质：

1. a与b′不同。若相同，它们的两个com也相同，U_t,i(a,a)=D_t,i∈KnownU；H(u)=ũ与unknown相矛盾。
2. a、b′至少一个不在K_vis,t。若都在池中，B已枚举该组合，同样矛盾。

因此“unknown且至少两棵双洞树”的事件，归入第8节定义的跨树完整tape等式。这里没有把LateLeaf和VHash成功概率相乘。

## 8. 新桥：跨树未知完整tape等式的界

### 8.1 精确事件与计数

对每一个实际首次普通H₂切口及其H₁森林，定义事件TwinUnknown：存在不同树t<s、底层对i,j、full桶seed四元组(a,b′,c,d)，满足

~~~text
a∈B_t(com_t,2i)， b′∈B_t(com_t,2i+1)
c∈B_s(com_s,2j)， d∈B_s(com_s,2j+1)
a≠b′，至少一个a/b′不在K_vis,t
U_t,i(a,b′)=U_s,j(c,d)。                                  (22)
~~~

此事件无需额外要求VH通过，也不要求右边两seed都未知或不同。它是第7节剩余分支的一个超集：那里两树都具有该性质，故取索引较小者作t即可。

在当前com全桶≤u时，逐H₂可供并合的有标签四元组数至多：

~~~text
C_pair(u)=u⁴ Σ_{t<s}(N_t/2)(N_s/2)。                     (23)
~~~

重复值、重复承诺对或同一个等式可以多计；此处取简单先验上界。

令q₀为整个Source过程的全部普通正/逆IC调用数上界，并定义

~~~text
d₀ = q₀ + 3τ + r(τ−1)
ρ_tape =
    min(1, (M/2^b) / product_{j=0}^{r−1}(M−d₀−j))，
    若d₀+r−1≥M则取1。                                   (24)
~~~

ρ_tape约为2^−L；实际使用式(24)保留剩余置换分母。

**新桥候选定理。** 在第1节Source无反馈、canonical规则、真实固定森林地址和有限K_vis定义下：

~~~text
Pr[TwinUnknown在任一普通H₂发生 ∩ G_cap]
 ≤ a₂ C_pair(u) ρ_tape。                                 (25)
~~~

因此去掉G_cap时另加δ_cap。以下是逐步条件证明，等待独立反驳审查。

### 8.2 先删私有读取，再只揭当前森林非tape列

固定某个首次普通H₂切口的Source历史、该查询输入及其H₁快照。由无反馈耦合，用相同E和相同来源随机币逐步删除全部PrivateIC，Source轨迹和式(22)涉及的E函数值不变。这里式(22)仅使用Source、当前canonical定义及同一个E，所以该点态删除适用；不删除真实归约中的资源费用。

在这个仅有Source的边际实验中，固定其历史，未曝光置换部分在已知映射之外均匀。分析器额外揭示当前森林的整列：

~~~text
{ E_z(x_C,t), E_z(x_0,t), E_z(x_1,t) :
  所有key z，全部树t }。
~~~

每把key至多新增3τ个输入点。揭示的都是与当前所有tape输入不同的地址。这一步可能代价指数，仅属于分析；B不执行。

这使全部full桶、当前列桶帽、K_vis成员性、H₁ canonical选择及所有候选四元组名单固定。旧Source在其他IV触达的相关实际点已经包含在历史中；旧Full的跨角色重叠不作为这里的条件信息。

### 8.3 每个四元组在看未知tape前选最后揭示seed

固定该非tape信息确定的某一个有资格四元组。若a∉K_vis,t，选p=a；否则选p=b′。选择按固定次序，不看任何尚未揭示的tape；由资格条件p一定存在，且本树另一seed不同于p。

依可见支持引理，全部(s=p,T_t,c)未被Source触达，且p不是树t的任意canonical seed。

再揭示所有当前canonical tape，以及式(22)右边需要的两条candidate tape、树t另一seed的tape。也允许揭示所有K_vis成员的tape。所选p的本树tape始终没有被触及：

- 本树canonical与K_vis都没有seed p；
- 本树另一candidate seed与p不同；
- 其它树的tape输入与T_t互不相交。

就置换E_p而言，先前Source至多占q₀个输入，当前非tape列至多3τ个，其他τ−1棵树全部tape输入最多r(τ−1)个。无论p在别树有多少次canonical/candidate/known引用，输入集合每树只有r个。因此在最后一步前，E_p已曝光的不同输入数不超过d₀。

揭其他key的tape可能输出数值p，这不会变成一次key p的oracle调用；理想密码不同key的置换独立。seed、parent和输出别名允许存在，已曝光行和同key输出排除由剩余置换统一处理。

### 8.4 逐块计数：必须命中整个L位tape

在上述条件下，式(22)恰对未知m_t(p)指定一个确定的L位目标：

~~~text
m_t(p) = 已揭示的基线、修正串和其余至多三条candidate tape的XOR。
~~~

没有对VH输出计数，也没有把一个叶匹配概率乘一个独立哈希概率。

同一E_p在r个新的互异输入处，输出按均匀剩余置换无放回采样。目标固定前r−1个完整λ位块和最后块前b位。若前r−1个目标重复、已用或导致冲突，概率为0；否则前三种限制至多降低概率。最后部分块至多M/2^b个完整输出补全。因此精确可行补全数不超过M/2^b，而有序剩余r元组数至少

~~~text
product_{j=0}^{r−1}(M−d₀−j)。
~~~

得到式(24)。这里的80个填充位已通过分子M/2^b计入，未把L位关系错误当作rλ位关系。

### 8.5 当前列帽与逐切口并合

当前列帽由8.2已揭示的com列确定。因此可在该条件下，以至多C_pair(u)个四元组并合。整个全域桶帽会涉及未来/其它tape单元，不在8.3剩余置换分布中条件化它；只使用包含关系

~~~text
TwinUnknown ∩ G_cap
  ⊆ TwinUnknown ∩ 当前com列帽。
~~~

分别为每一个H₂切口构造上述边际genie，然后对至多a₂个切口并合。前一切口免费揭示的整列不传给下一切口，也不反馈给Source；这里求和的是各自的边际概率。

所有选择都在其当时Source历史与当前非tape列下确定。A可自适应选择IV、com、H₂时刻或后来开示；它最终选择的四元组属于已并合的名单。这得到式(25)。

## 9. 与原始HΔ挑战收费的接口

本稿不重写原XOF/哈希链规则。对每个能由历史记录解析的普通HΔ输入，先在新响应前，由E和过去RO语义确定对应H₂的已缓存known/unknown分支：

- known且W未给Rain原像：由固定W定义约束e；非ZHash失败时语义QS检查为非零二次式，至多两个根；
- unknown且其虚拟兼容洞集合至多两个：取那至多两个λ位值；
- cap-overflow、解析失败、虚拟集合大于二或QS最高系数为零：概率分析中的目标集合置空，分别由桶帽、哈希链、TwinUnknown/AU或ZHash异常覆盖最后有效伪造。

这使每个普通新HΔ响应之前定义的语义目标集合，在所有历史上都至多二，不是先条件于整个未来好事件再称响应均匀。原稿对首次触达（含零长度）、XOF补长不重采样、旧HΔ行、新消息与签名编程行隔离、末次无记录输入的处理仍逐项保留。

在另一分工确认该接口后，可以使用“每次预定分支最多二”而非把known/unknown两种终态损失机械相加。确切总系数由挑战专门审查统一；本稿只提供它所需的前置固定性和每分支二点性质。

## 10. 实际多项式资源与本稿新增代价

全桶、整列genie与语义S_t/V*只用于证明。B只对有限Source根执行C/T/P并枚举KnownU。

沿用03的每Source根有限完备化粗界：

~~~text
c_role=d_H r²+5d_H r+6
P_full≤q₀+c_role q_anchor
Rain-3: c_role=138；Rain-4: c_role=174；d_H=2。
~~~

H₂时扩充来源水位不会让同一根再次重复全部角色；用不可变根描述符、(x_C,k,seed)及Full缓存复用。私有生成行没有自动递归入根。B也可按当前森林临时只求真正需要的条目，上式仍是保守总IC界。

令s_t,z=|K_vis,t(z)|，一次H₂的KnownU候选数至多

~~~text
τ + #{同com底层对} + Σ_t Σ_i s_t,com_even · s_t,com_odd。
~~~

这是KnownU作为数学集合的粗计数，实际使用第5节的线性哈希双向匹配。对于非overflow的每个目标桶，最多保存u个seed；对某个超限桶在第u+1个不同seed时即可标记并跳过本次提取，跳过仅影响私有状态。扫描Source/模板描述符及维护桶的费用按真实条目另计，未因私下截断消失。

预先保存各相关seed的H(m_t(s))和canonical hash；同一个(χ₁记录,x_C,k,seed)可以复用。每个底层对建一侧字典并扫描另一侧，操作数O(u log(u+1))；每个hash键为λ+b位。保守的每H₂搜索费用可以写成

~~~text
O( (Nu+τ) C_VH(L)
   + Nu(λ+b) log(u+1)
   + L + C_Rain )，
~~~

另加Source/descriptor索引查询、H₁ canonical求值及基线聚合的成本。H(A_t XOR M_even XOR M_odd)也可用三份已缓存hash异或，不必重复对该L位串做VHash。一次H₂最多真正构造一个匹配f并作一次Rain核验。字典按当前pair使用时额外临时空间O(u(λ+b+λ))位，跨pair缓存的真实空间另在总账计入。

该搜索在所有历史上都具有确定的有限界，桶帽失败时并未展开指数原像表。即使不采用帽截断，有限Source池也受O(d_H(r+5)q_anchor)描述符界约束；截断的作用是改善明确的最坏费用，不是赋予算法原本缺失的可计算性。显式参数族沿用原01 §7的N=poly(λ)、r=O(1)，固定128六实例不被冒称完整无限参数设计。

本稿改善的是LateLeaf事件定义，不将这些CPU、内存、私有IC读取省略，也不把B的OWF运行预算当成A的原始预算。MITM建议来自root；它保持本稿全桶AU和TwinUnknown事件不变。

## 11. 可合成的局部新损失及尚存边界

若父节点覆盖、canonical语义绑定及哈希链各有自己的合格界，则在对应结构好事件上，可用以下新局部项替换旧“全部迟到叶匹配”一阶项：

~~~text
δ_cap
+ a₁ εV [ Σ_t binom(N_t u,2)
           + binom(Σ_t(1+N_t u²/2),2) ]
+ a₂ u⁴ Σ_{t<s}(N_t/2)(N_s/2) · ρ_tape
+ 对应的ZHash与每普通HΔ至多二点项。                    (26)
~~~

共享同一G_cap时δ_cap合并一次；底层绑定和LateParent也用该帽时无需每份稿再复制帽尾。原有哈希链与CMA等其他坏事件仍并合，OWF优势保留实际B资源。

式(26)不是完整EUF-CMA安全定理，也没有数值断言“128位已够”：全桶AU的u⁴计数、父节点项、a₁/a₂/q₀在相同预算下的大小、签名模拟损失、Rain单向性及实际归约资源都仍需要统一评估。共享地址另一实现的参数只能在各自真实地址和tape长度下代入，不能直接由本稿断言rFAEST安全等级。

本候选没有修改Sign/Verify、参数、全密钥空间或B=6；NIST类别1与QROM未被加入用户当前验收门槛。
