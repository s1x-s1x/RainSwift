这允许先对无Ext的来源边缘证明CMA距离，再安装无反馈私有读取。概率用Source的地方均需逐路径删除私有读取；它不意味着实际B免付这些查询或计算。受审02实际费用仍使用：

## 3. 完全可见底层对的覆盖

对最终有效伪造的一个完全可见底层兄弟对，按其真实父key分类：

1. 若H₁前该父在任一真实父输入已有Source行，P模板覆盖它；canonical在同context、匹配有序com对的旧Source支持父中固定选择。
2. 若真实父没有这种旧支持，其后公开Verify必触达它的父格。这属于迟到父节点整列界覆盖的匹配事件，支付epsParent。
3. 第1类中，若真实有序tape不同于canonical，父key必不同；二者均有Source父格支持，且有序com相同，因此触发PairSrc，支付epsCanon。
4. 父key相同则相同地址的置换输出和tape确定相同，不形成漏掉的歧义。缺canonical的情况归入第2类，未凭空假定存在旧基线。

只有隐藏洞所在的底层对允许任意满足目标com的直接兄弟叶；所有这类种子都在完整桶中，由语义族覆盖。B没有声称所有叶子在H₁前都可见。

“半边已旧、另一半迟到”在第1类已经被P模板补齐，因此不存在将最后一步一阶条件概率错误计为两次独立猜测的空隙。

### Source Canon收紧的特定前提

PairSrc存在量化的是所有Source支持父对。canonical虽然依赖私有求得的com值来选择，却总是这些父之一；最终Verify的真实父也属于该集合。因此目标坏结构逐路径包含于PairSrc，不要求canonical结果本身对Source可计算。

删除无反馈私有读取后，PairSrc真假不变。将注册支持定理应用于这个来源算法，其全查询表就是原Source，故：

~~~text
epsCanon = q₀(q₀−1)u²/[(M−q₀−1)(M−q₀−2)]。
~~~

这是提取资源05§10新增的窄事件推论。更早的任意Full支持定理继续使用自己的Full预算，历史审查中禁止任意P换q₀的提醒仍然正确。真实资源Pbar也继续保留。

## 4. AU、见证与未知分支

### H₁前语义族

canonical按(parent key, Source root id)排序，只看Source支持及有序com，选择不看tape。在分析中条件于完整IC与H₁前历史，全桶、基线、E_t和F_t^+均已固定，而首次普通χ₁仍独立均匀。以指数集合进行概率分析不等于让实际B枚举它。

BadE覆盖每树内不同误差，BadU覆盖整个∪F_t^+内不同u，包括同树。共计：


相同com的diagonal项对空桶也补入；非空时同seed组合已经产生该向量。故每底层对仍至多u²个值，u≥1时无需额外添加N_t/2项。实际KnownU为该语义族子集。

### H₂前实际见证

有限K_vis包含当前Source在真实com/tape处触达的种子，以及Source支持父的两个孩子。B按承诺分桶、按seed去重，以线性VH的MITM查找确定代表。两个不同seed的hash相同时保留首个代表仍完整保留“是否存在匹配”，不需要真枚举u²对。

第一次合规H₂回答前只固定一次known、unknown、overflow或格式失败。known立即得到W=d⊕f[0:ell]并核验真实Rain关系；旧H₂补长或重询不重选分支。overflow蕴含全域桶帽失败，不等同于“完整搜索但没有候选”。

known情况下，BadU补集迫使多洞树的共同斜率等于选中f；单洞树也可定义相容V*。V*在H₂回答前通过完整语义集合固定，B无需显式知道它。QS最高系数e_i(W)=x_i(W)y_i(W)+1只依实际已知W，故保留a₂ epsZ与随后二次根界。

### Unknown跨树桥

unknown时所有A_t均已检查；在BadE补集每树至多有同一底层对的两个洞。若两树都双洞，其共同u产生完整tape异或等式。同seed抵消已由diagonal候选覆盖，两seed都已知则MITM应成功，所以每个相关双洞对至少有一个不同于另一seed的K_vis外种子。

逐H₂切口删除私有读取，先揭当前森林父/com列，固定桶、canonical和候选四元组，再保留该未知种子的本树tape最后采样。当前森林其他树的tape地址与它互异；canonical来自Source支持父，若它是基线种子就已经在K_vis，故未知种子不被同树基线读取。取：

~~~text
d0 = q₀+3τ+r(τ−1)
rho = (M/2^48)/Π_{j=0}^{r−1}(M−d0−j)
epsTwin = a₂ u⁴ Σ_{t<s}(N_t/2)(N_s/2) rho。
~~~

分子保留末AES块80个未用位。该桥约束整个L位tape关系；没有“迟到匹配概率×VHash概率”的独立性假设。跨IV重叠通过Source删除和实际历史计费处理，未假定不同签名的所有地址全局互异。各切口分别使用genie，不累积之前切口的免费整列。

这些未知tape条件已由提取资源05独立逐条审查通过。排除epsTwin后，unknown森林至多一树双洞，因此总挑战支持至多两点。

## 5. Caller、XOF与统一挑战收费

a₁、a₂仅计A最终输出前首次普通完整输入。签名程序行及最终Verify新H₁/H₂照常预留RO但不运行钩子；Verify新Source根也不做私有完备化。所有公开调用仍计入q₀和h_j。

按签名模拟04，在所有响应前历史上定义大小至多2的分析目标集。known使用非零QS二次式的根，unknown使用大小≤2的语义支持；缺链、overflow、残差消失或更大支持时取空集，并将最终成功交给已列坏事件。这样普通新HΔ在其响应前仍均匀，无需条件于未来有效伪造或未来好事件。

因此两个分支合用2a_Δ/M，而非两次各收2a_Δ/M。最终首次HΔ因签名已固定一个具体Δ，只加1/M。旧HΔ回溯首次预留；后到H₂/H₁补链由epsChain支付；签名程序行由新消息链隔离。

零长度和短前缀第一次触达同样内部预留足够响应、建立所需旧记录；后续补长不重采样。grinding使用所有原始HΔ输入计数，不条件于成功后继续把输出当作全域均匀。G在模拟、程序冲突及真实运行成本中继续存在。

## 6. 共同桶事件、并合与分母域

全域桶帽尾delta_u在ST中只加一次。Canon、LateParent和Twin各自先界局部坏事件与该帽的交集，利用全域帽包含于当前已揭列帽；没有在条件化整个未来桶帽后再宣称IC未揭值均匀。

~~~text

       +epsSim+epsChain+delta_u
       +epsCanon+epsParent+a₁ epsV C_U
~~~
