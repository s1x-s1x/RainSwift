# 三洞非仿射与半查询父节点反例

2026-10-15；候选 C030-RFAEST128-EQUIV-TIGHT1；equality_adversarial_review。反例用于限定新安全论证的范围，并非原128位参数的完整签名攻击。

## 1. 三份合法位置开示都过VHash，仍可能缺少公共仿射解

这个例子针对“只要底层父节点唯一，所有叶碰撞都无害”的过强命题。固定四叶树、唯一的两个规范底层父节点及其有序 tape 对，容许一个直接暴露的洞兄弟 seed 有同承诺的另一原像。

一般构造取非零 z∈ker H：

~~~text
洞β=0：兄弟误差e_0=0，另一个底层对按规范父节点展开；
洞β=1：兄弟误差e_1=0，另一个底层对按规范父节点展开；
洞β=2：兄弟误差e_2=z，底层对(0,1)按规范父节点展开。
~~~

第三份只改变直接暴露的叶3的 seed。假定两个 seed 具有相同叶承诺，其 tape 差是z；完全可见的底层对从未改变。选择 ũ=H(A)、Ṽ_h=H(V_h)。由洞兄弟误差的单列恒等式，三份全部通过。

前两份相邻洞的低列差迫使 u*=A，洞0同时确定 V*=V。洞2的最低索引位是0，因此公共仿射式预言 q_2,0=V_0；实际 q_2,0=V_0⊕z。z≠0给出矛盾。

这说明需要排除不同误差之间的VHash碰撞。共享输入产生的相同误差可被吸收，与“任意不同误差也无害”是两种命题。

### 1.1 已核对的具体小向量

取F₂³向量，以整数0至7表示，H(x)=x的最低两位：

~~~text
M=(3,5,6,1)，c=7，A=(⊕M)⊕c=6；
V=(M_1⊕M_3, M_2⊕M_3)=(4,7)；
z=4，H(z)=0；
ũ=2，Ṽ=(0,3)。
~~~

| 洞β | 误差e | 重构(q_0,q_1) | 哈希后的列 | Ṽ_h⊕β_hũ |
|---:|---:|---:|---:|---:|
| 0 | 0 | (4,7) | (0,3) | (0,3) |
| 1 | 0 | (2,7) | (2,3) | (2,3) |
| 2 | 4 | (0,1) | (0,1) | (0,1) |

洞0给 v*=(4,7)，洞1给 u*=4⊕2=6。洞2的低列应该是4，实际是0，公共仿射解不存在。

root已在[本阶段有限脚本](../%E8%84%9A%E6%9C%AC/%E9%AA%8C%E8%AF%81%E4%BB%BF%E5%B0%84%E5%BC%95%E7%90%86%E4%B8%8E%E5%9C%B0%E5%9D%80%E7%BC%93%E5%AD%98.py)和[原始JSON](../%E5%8E%9F%E5%A7%8B%E6%95%B0%E6%8D%AE/R1_affine_cache/result.json)核对。其范围是遵守合法copath暴露位置的条件tape模型，没有实际搜索128位AES碰撞，也没有生成QS或Fiat–Shamir伪造。非零z若在新H前已经固定，其H(z)=0仍可以由AU界收费；反例不削弱这一收费的正确性。

## 2. 只剩一个未读孩子的父节点，并无双块目标概率

原030在固定树t、树高k及IV下，底层父节点p的两个孩子地址和叶承诺地址满足：

~~~text
x_0 = X_iv(0,kτ+t)
x_1 = x_0 ⊞ (1,0,0,0)
x_C = x_0 ⊞ (0,0,0,τ)
a = E_p(x_0)，b = E_p(x_1)
C(s)=E_s(x_C)。
~~~

⊞是各32位lane独立模加。设M=2^λ，x_0≠x_1，密钥p的其他位置没有被读取。构造时序：

1. 在H₁之前已查询 E_p(x_0)=a。
2. 选已知 seed b≠a，且a、b与p不同，读取C(a)、C(b)。这两个承诺查询不增加密钥p的已定义映射。
3. 将目标底层承诺对固定为(C(a),C(b))，发出H₁查询。此时E_p(x_1)仍未读。
4. 在H₁之后读取E_p(x_1)。

条件于上述历史，p的剩余输出是除a之外的M−1个值，恰一个等于b，所以：

~~~text
Pr[ E_p(x_1)=b | 上述H₁前历史 ] = 1/(M−1)。              (10)
~~~

事件发生时，p成为目标有序承诺对的匹配父节点；两片叶的承诺原像早已出现。这是“每个迟到匹配父节点都须支付两个新λ位目标”的反例。对承诺对匹配事件，式(10)给出一个成功子事件的精确概率；若还有别的seed与b同承诺，匹配父节点的总概率还可能更大。

λ=128时，该步骤只有一个约2^−128的剩余匹配，不是2^−256。这里没有把它描述成完整伪造；它只反驳逐父节点直接平方的概率推理。root对M=4、8、16、32的1,300个部分状态核对了1/(M−1)。

### 2.1 对结构修补的实际含义

若提取器在H₁响应前，为每个已见的父节点单边记录私有补齐另一孩子并查询其两个叶承诺，则本例的父节点会在χ产生前完整确定。随后若目标对匹配，它已属于快照；若不匹配，后来同一oracle不会改变答案。这样的预补齐正好消除本反例的“迟到”性质。

但这需要明确的新算法与成本，且至少要分别处理：

- 一条source记录既可能是左孩子调用，也可能是右孩子调用；
- 其他IV或角色的私有预读可能早已定义当前输入；
- 私有预读不应递归生成无限新增anchor；
- Source新揭露与Full首次采样是两个不同时间概念；
- 完整父节点索引必须在χ前固定，且不得因χ或未来开示而补写旧快照。

这些是提取资源稿的覆盖接口；本反例没有否定可以设计这样的算法。

## 3. 真正两个未揭露输出的精确条件公式

以下小引理可作未来双块计费的基础，但其前提须在实际事件中逐项建立。

固定一个key、两个不同且尚未揭露的输入x_0、x_1。条件于允许的历史后，其剩余输出集合为R₀，大小m。两个目标seed集合K_0、K_1也在该切口固定。令：

~~~text
a=|K_0∩R₀|，b=|K_1∩R₀|，c=|K_0∩K_1∩R₀|。
~~~

两个有序输出在R₀的m(m−1)个不同值对上均匀，故：

~~~text
Pr[ E_p(x_0)∈K_0 且 E_p(x_1)∈K_1 ]
 = (ab−c)/(m(m−1))
 ≤ u²/(m(m−1))，若a,b≤u。                               (11)
~~~

减去c是因同一置换两个不同输入的输出应不同。当只剩一个未揭露输出时应使用单块公式，式(11)的前提消失。

对于source/Full分离，式(11)可以在严格证明的Source边际过滤族上使用；即使Full私有表已有答案，Source未见的两位置仍可能具有这个边际分布。但若条件已经包含那些私有答案，就没有“两个均匀未知输出”可用。前后使用的过滤族须明确一致。

同样，式(11)针对切口处固定的key、地址、目标集。事后挑选key/IV/承诺，或从大量已揭露对中寻找匹配，需要另付相应自适应搜索、目标数与查询预算。仅引用式(11)不会自动得到全局 O(q²/2^{2λ}) 界。

## 4. 从空桶LateHit推广到LateAlternative

旧原02的LateHit只登记H₁前没有匹配seed的叶目标。新引理允许一个非空桶含多个候选seed，因此需要的覆盖事件更广：

~~~text
LateAlternative：
对某个H₁前已固定叶目标(x_C,com)，
其后实际开示使用的seed不在该快照K内，
且source揭露/验签使该seed成为该目标的新匹配原像。
~~~

即使K早已有s_0，也可能出现s_1≠s_0。旧空桶事件不会记录它，而原先全局PairCollision在新方案中又准备被削减；所以这条路径应显式补回。

如果source行在相关过滤族下仍按剩余置换分布揭露，那么对全部已登记目标而非仅空桶，仍至多有a₁N个带标签目标。数值目标计数未必增加，事件定义则必须变广。该数值界的分母、Source/Full非干预性与Verify成本由资源稿单独给出，本稿不重复自认证。

迟到匹配发生后，再条件化其tape的某个VHash事件来额外乘2^{−(λ+b)}，需要新的联合概率论证。旧OldTape/NewCom反例已经表明，tape和VHash可能早已选定，最后只剩一个承诺匹配。把每个已有source tape行提前补相应承诺地址，是一种可能堵住该时序的算法改进；改进后还要证明所有相关角色解释都被有限覆盖。

## 5. 研究结论

| 命题 | 本稿结论 |
|---|---|
| 相同兄弟误差重复出现必然破坏提取 | 第01稿证明在其覆盖条件下可并入公共V偏移 |
| 底层父节点唯一即可忽略所有叶碰撞 | 三洞反例否定；不同误差的AU事件仍必要 |
| 每个迟到父节点都自动有2λ位目标代价 | 半查询父节点反例否定 |
| 两个真正未揭露输出命中固定seed集合 | 式(11)成立，须建立其过滤族与固定性前提 |
| 仅空桶LateHit足以覆盖多原像提取器 | 应扩大为LateAlternative并支付对应具体界 |
| 已给出低于rFAEST所称128位的完整伪造 | 本稿没有这个结果 |

这些反例界定证明中可采用的命题；它们与完整签名的安全强度判定分开记录。原协议源码、历史正式证明及旧原始数据均保持原字节。
