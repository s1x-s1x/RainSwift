# 原030：已闭合的保守具体归约

2026-10-15；C030-RFAEST128-EQUIV-TIGHT1；root。**本稿给出可直接组合的经典条件 EUF-CMA 归约。它采用来源隔离的旧唯一叶提取器，已支付实际归约成本，仍保留宽 Pair/Late 项；因此本稿自身不认证128位具体等强。** 新的碰撞容忍引理另作分支，避免把两个提取器的优势项和费用拼成一个不存在的算法。

对象为原030六组之一、单公钥、经典前缀一致随机预言及普通双向128位理想密码。Rain挑战与辅助理想密码独立。固定原030源码、KeyGen拒零规则、完整秘密域和原协议字节不变；192/256、NIST类别1、完整QROM不属于本稿增加的门槛。

## 2. 统一查询口径

取 M=2^128，R=3或4，b=48，ell=128R，L=ell+256+b，r=ceil(L/128)，N=ΣN_t，D=128−g，d_H=2。Q为签名请求上界。a_IC同时计攻击者正逆IC调用；a_c、a_mu、a_s、a_4、a_1、a_2、a_Delta计各RO域的首次完整输入，包含不合规输入及零长度首次预留。重复调用、输出补长与输入总位数另进时间账。原始grinding失败、预计算及x4额外行不省略。

模拟器和最终Verify产生的上界为：

~~~text
AV = (r+3)(N−tau)−2D+tau
q0 = a_IC+(Q+1)AV
q_anchor = a_IC+Q AV
hc = a_c+(Q+1)(tau+1)
hmu = a_mu+Q+1
h4 = a_4+Q+1
h1 = a_1+Q+1
h2 = a_2+Q+1
hDelta = a_Delta+QG+1.
~~~

AV末项保留零key洞承诺死读取。提取钩子只在A最终输出前，由A首次触达的合规普通H1/H2输入上建立或物化。签名模拟器编程行及最终Verify执行期间的首次H1/H2正常预留/回应，但不建立新提取快照，也不执行私有完备化；最终Verify结束后没有新的Source工作。Verify的公开IC读（含Full缓存命中的Source提升）仍全部计入q0，只有A输出前的Source根计入q_anchor。最终新哈希链由epsChain隔离，首次最终HDelta由1/M覆盖；已存在且可用于有效伪造的HDelta链回溯到A输出前的H1/H2。若改变这一调度，必须相应重记提取次数与q_anchor。G是预先固定的正4倍数且G≤2^32，尾项使用真实G，未把grinding当作免费成功采样。

## 3. 同一个实际归约B

B接收Rain公钥挑战；它没有sk，也没有IC编程权。

1. 运行pk-only签名模拟，按IC单元共同耦合规定正常读取H4旧点，仅在新H1/H2/HDelta点编程。
2. 所有来源调用使用Source接口。Full另缓存提取器私有普通IC读取；私有行随后被来源触达时仍作为新的Source曝光登记。
3. 在第2节限定的A调用者钩子上，首次普通H1回答之前保存不可变输入、RO水位、Source水位。第一次被H2引用时，仅依历史前缀解析叶目标和唯一来源原像，按真实地址读取带；不把H1以后新发现的key添入旧快照。
4. 在相同A调用者钩子上，首次普通H2回答之前执行正式01的完整/缺叶树分类，固定u、V、W。若提取出合法Rain原像，只私下保存，不改变来源流程。
5. H_s输入的密钥前缀若通过公开Rain关系核验，则立即成功停止；这是来源可测的公开停止事件。它与第4项的私有成功分别处理。
6. 否则继续到攻击者及最终Verify结束，再输出已经核验的原像。

上述算法的Source边缘与删除全部私有读取后的来源流程逐点相同。签名视图距离先在不安装Ext的来源流程证明，再加这种无反馈提取器；没有把Ext读过的隐藏单元计成攻击者猜中。

## 4. 完整误差项

定义固定非零差分/残差界：

~~~text
epsV = 2^−176 + R(2R+1) 2^−192
epsZ = 2^−128 + (R−1)^2 2^−192

epsChain =
 [C(hc,2)+C(hmu,2)+(tau+1)a_1 hc] / 2^256
 +[C(h1,2)+a_2 h1] / 2^704
 +[C(h2,2)+a_Delta h2] / 2^448.
~~~

当q0<M时取：

~~~text
epsPair = min(1, q0(q0−1)/(2(M−q0)))
epsLate = min(1, a_1 N q0/(M−q0)).
~~~

当q0≥M时这两项取1。这里付的是Source首次曝光的碰撞与迟到目标；证明通过来源无反馈耦合删去私有读取后使用普通剩余置换。Full缓存旧行的首次Source提升也被计入。

模拟部分令：

~~~text
S=1+D+tau
J=2D+(r+2)tau
E=D+tau
F=D+(r+1)tau
v0=C(tau,2)+D+tau C(r+1,2)
V=Q v0.
~~~

取分析阈值kappa,u_x,u_y≥1；Q>0时：

~~~text
delta4 = C(h4,kappa+1)/M^kappa
deltax = C(Q,u_x+1) J^(u_x+1) ((kappa+1)/M)^u_x
deltay = C(QF,u_y+1)/M^u_y

epsHide = min(1,
 ((u_x+u_y)q0+V)/M
 +[q0 Q E +(kappa+1)C(Q,2)J^2+C(QJ,2)]/M^2
 +delta4+deltax+deltay)

epsProgram = Q[h1/2^(L(tau−1))+h2/2^704+hDelta/2^448]
epsTail = Q(1−2^−g)^G
epsSim = min(1,epsHide+epsProgram+epsTail).
~~~

Q=0时epsSim=0。阈值不是协议参数或新的秘密空间限制。H1编程熵只在虚拟模拟中计费；IC和RO使用同一个首次坏事件耦合，未循环假设真实修正串已经均匀。

**定理C。** 存在第3节的实际归约B，使：

~~~text
Adv_030^EUF-CMA(A)
 ≤ min(1, Adv_Rain^(OWF,IC)(B)
          + epsSim + epsChain
          + epsPair + epsLate
          + a_1 C(tau,2) epsV
          + a_2 epsZ
          + (2a_Delta+1)/M).                          (C)
~~~

证明衔接如下。在真实与模拟停止前缀之间付epsSim；H_s命中已给OWF成功。其余路径使用普通模拟游戏。排除epsChain及Source Pair/Late后，最终有效新消息伪造的全部打开叶由H1旧快照唯一覆盖。不同完整树差分在H1前已由历史与同一E确定，付a_1 C(tau,2)epsV。H2前W已经实际计算；若其key不满足Rain关系，完整约束残差非零，付a_2 epsZ后QS最高系数非零。

在每次首次普通HDelta响应前，分支已经固定：全fixed只有一个挑战目标，已提取无效W至多两个根。因此统一每次最多2/M，无需把两分支再相加成3/M。旧HDelta点追到首次预留时计费；最终Verify第一次请求的挑战还须精确等于签名已确定值，另加1/M。未在未来成功或所有好事件上条件化后重用均匀性。

所有剩余项只并合，不使用“迟到匹配概率×VHash概率”。算法在无效查询上经常返回空值是允许的；定理只要求覆盖最终有效伪造。

## 5. 实际资源及其用途

令e为真正由H2引用的不同快照数，e≤min(a_1,a_2)。每条Source承诺行的带地址只依其完整输入和树高，所以有：

~~~text
Tprivate ≤ min(r N e, 2r q_anchor)
Pfull ≤ q0+Tprivate.
~~~

| 参数 | 每份快照的旧最多IC | 每个来源根的新最多IC |
|---|---:|---:|
| Rain-3 快 | 7488 | 12 |
| Rain-3 均衡 | 14592 | 12 |
| Rain-3 短 | 104448 | 12 |
| Rain-4 快 | 14336 | 14 |
| Rain-4 均衡 | 13440 | 14 |
| Rain-4 短 | 121856 | 14 |

两列乘数分别是快照数和来源根数，数字比不构成实测加速比。最坏情况下仍需eN k_max L的聚合工作，以及每次H2的VHash、转置和Rain核验。

完整时间采用[资源稿R8](%E6%8F%90%E5%8F%96%E8%B5%84%E6%BA%90/01_%E6%9D%A5%E6%BA%90%E9%9A%94%E7%A6%BB%E7%BC%93%E5%AD%98%E4%B8%8E%E6%83%B0%E6%80%A7%E6%8F%90%E5%8F%96%E8%B5%84%E6%BA%90.md)：

~~~text
T_B ≤ T_src + Pfull c_IC
 + O(B_IO log(Pfull+H_call+2)
     +(q0+H_call+eN+Tprivate) w log(Pfull+H_call+2)
     +eN k_max L
     +a_2[(D+tau)C_VH(L)+128L]
     +(a_s+a_2)C_Rain).
~~~

这里B_IO涵盖长输入、输出补长及内部预留总位数；w=max(128,ceil(log2(Pfull+H_call+2)))。T_src包含A、实际签名模拟grinding、公开重构与最终Verify的其他工作。使用确定最坏多项式时间的字典实现，资源稿R9给出完整存储上界。重复预算作为上界可保留，实际测量不得重复计收益。

定理中的OWF项是同一个B的真实成功优势；给定数值Rain假设时，必须在T_B、Pfull、存储和辅助oracle模型下代入。这里没有将它设为0，也没有把B和A视为等成本。

## 6. 本稿完成了什么

它把三项已经独立检查的改进合成一条可审查的完整条件界：来源概率与Full成本分开、缓存和惰性求值、CMA单元耦合及挑战分支并合。以不同证明过滤族得到的合法边际界可以相加，不需要它们互相独立。

它仍保留q0²/M和a_1 N q0/M，尚不足以完成用户要求的具体等强验收。后续碰撞容忍分支如通过，应给出其自己的实际算法、完整覆盖及费用，再与(C)并列；两条归约的OWF项属于各自B，不能跨分支逐项取最小。
