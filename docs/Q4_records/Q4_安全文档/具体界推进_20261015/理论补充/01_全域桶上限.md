# 理想密码全域承诺桶上限与仿射界的适用范围

2026-10-15；root；C030-RFAEST128-EQUIV-TIGHT1。结论为一个已证明的理想模型计数引理，以及它与有条件仿射定理的组合。此处没有证明所有合法开示都已被提取器覆盖，也没有把概率上界的负对数称为算法实际安全位数。

## 1. 全域桶上限

取 M=2^128。普通理想密码由 M 个独立均匀置换 E_K 组成，每个置换作用于 M 个分组。定义完整数学桶

~~~text
B(x,y) = {K : E_K(x)=y}。
~~~

这里的桶遍历完整密钥域，仅用于概率分析；提取算法从来源记录和有限角色模板建立有限候选池，并不枚举 M 个密钥。

对实验前固定的 x,y，不同 K 对应的 E_K(x) 相互独立且均匀。若 |B(x,y)|>u，则某 u+1 个不同密钥都映到 y。对这些密钥子集及全部 M² 个 (x,y) 并合，得到：

~~~text
δ_bucket(u) = Pr[∃x,y : |B(x,y)|>u]
 ≤ min{1, M² C(M,u+1)/M^(u+1)}
 ≤ min{1, M²/(u+1)!}。                                  (U1)
~~~

各个 x 对应的桶之间可以相关；并合不要求它们独立。这个事件对全部输入、输出同时成立，所以随后自适应选择 IV、树号、承诺目标或正逆查询，仍落在同一个全域事件内。U1仅在普通理想密码模型中是定理，实际AES满足相同性质并非本稿所证明的命题。

若 x 在实验前固定且只需这一列，少并合一重输入，得到：

~~~text
Pr[∃y : |B(x,y)|>u] ≤ min{1, C(M,u+1)/M^u}
                       ≤ min{1, M/(u+1)!}。              (U2)
~~~

U2中的“预先固定”是实质条件。从已经看过的密码记录中选择 x 后，直接套用单列尾界会遗漏选择代价；U1避免了这项问题，但其余需要新鲜置换回答的论证仍须分别检查。

## 2. 与挑战前候选族的组合

引用[有条件仿射引理](../%E5%85%B1%E4%BA%AB%E5%9C%B0%E5%9D%80/01_%E6%9C%89%E9%99%90%E5%80%99%E9%80%89%E6%97%8F%E4%B8%8E%E4%BB%BF%E5%B0%84%E6%8F%90%E5%8F%96%E6%9B%BF%E4%BB%A3%E5%BC%95%E7%90%86.md)。每个 K_t,j 的成员都是真正的叶承诺原像，因而在全域桶事件的补集上，|K_t,j|≤u，即使候选来自[有限角色完备化](../%E5%85%B1%E4%BA%AB%E5%9C%B0%E5%9D%80/03_%E6%9D%A5%E6%BA%90%E8%AE%B0%E5%BD%95%E6%9C%89%E9%99%90%E8%A7%92%E8%89%B2%E5%AE%8C%E5%A4%87%E5%8C%96%E4%B8%8E%E6%9C%AA%E8%AF%81%E6%A1%A5.md)的私有读取，也有此大小上限。

令 N_t 是第t棵树的叶数，ε_V是对应实际VHash的固定非零差分上界。只计BadE/BadF，而尚未加入结构覆盖失败，得到可直接证明的组合：

~~~text
Pr[BadE ∪ BadF]
 ≤ min{1, δ_bucket(u) + a₁ ε_V C_aff(u)}，

C_aff(u) = Σ_t C(N_t u,2)
         + Σ_{t<s}(1+N_t u²/2)(1+N_s u²/2)。             (U3)
~~~

证明方式是先固定最初抽取的整个E，再按每个首次普通H₁响应前的历史定义候选。E确定全部候选tape和桶大小；新的普通RO挑战χ仍独立，所以在桶好事件下每份候选族至多有C_aff(u)个待收费非零差分。先对这些差分、再对a₁个H₁并合，最后加一次δ_bucket。这里的全域桶好事件仅依E，不需要对未来“所有开示被覆盖”的事件作条件化。

该论证不表示“给定整个Full表后，尚未Source曝光的IC单元仍新鲜”。新鲜的是独立的H₁随机预言回答。结构事件若需要新的密码输出，必须另选正确过滤族和条件分布。U1本身也没有使提取器成为全预像搜索算法。

实际使用应优先采用去重后的 |E_t|、|F_t|。U3只是统一而较宽的上界；当每个基线来自唯一候选时，误差族为{0}、每树u族为单点，计数回到C(τ,2)，无需人为付N或u⁴。

## 4. 本引理解决及未解决的接口

已经解决的是：无需把最大承诺桶宽u继续作为完全未定假设。U1给出可同时覆盖自适应地址的显式失败概率，而且不增加提取器指数级搜索成本。

尚待证明的是：候选池对全部有效开示的覆盖、同一有序底层承诺对是否给唯一语义tape对、池外新parent/new leaf的有害影响。U1没有为这些事件提供独立性或双块目标代价。有限角色模板只能先消除旧tape漏登记与旧半parent漏补齐；剩余概率接口仍按原文保留。

此稿与完整提取费用、CMA单元耦合、QS及Rain原像困难性共同构成研究接口；Q4完整等强关卡继续OPEN。
