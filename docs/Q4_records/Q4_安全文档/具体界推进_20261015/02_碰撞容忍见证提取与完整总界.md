# 原030：碰撞容忍的见证提取与完整具体总界

2026-10-15；C030-RFAEST128-EQUIV-TIGHT1；root。**本稿组合一条新的经典条件EUF-CMA归约：用底层有序双承诺绑定取代单叶全局生日失败，用全桶语义族和可执行见证提取取代“迟到叶一律失败”。归约算法及其真实成本在同一稿中固定。** 适用范围是原030单公钥、固定六组之一、经典ROM及普通双向理想密码，Rain公钥挑战与该辅助理想密码独立。

本稿与[保守总界](01_%E5%B7%B2%E9%97%AD%E5%90%88%E7%9A%84%E4%BF%9D%E5%AE%88%E6%80%BB%E7%95%8C.md)是不同归约，分别支付各自B的OWF资源。内部交叉审查与固定版本由本轮审查清单记录；有条件数学定理、具体128位验收、工程测试和外部同行评审分别表述。

## 1. 本轮改变的是分析算法

原030的Sign/Verify、六组参数、B=6、完整秘密域、拒零KeyGen及协议字节均保持原样。为分析实际共享AES输入，引入以下工具：

| 问题 | 本稿使用的结论 |
|---|---|
| 单叶com碰撞未必有害 | 对实际支持父节点证明有序双承诺绑定 |
| H1前父节点只查了一边 | Source根的P模板普通读取补齐另一边 |
| H1后才出现的全新父节点 | 固定切口整列genie的双块匹配界 |
| H1后才发现的新叶 | H1前以全E定义语义全集，H2前有限池寻找见证 |
| B不知道共同最低列偏移 | B只须计算W，V仅在分析中提前固定 |
| B找不到已知u | 除跨树完整tape等式外，兼容Δ至多两个 |
| 完备化开销 | Full调用和所有CPU/内存单列，未写成免费 |

“genie”只指概率分析额外揭示随机表值，不是B拥有免费指数查询或IC编程权。

## 2. 记号和共同模拟

沿用保守总界第2、4节的M、R、L、r、N_t、N、tau、D、a_1、a_2、a_Delta、q0、q_anchor、h_c/h_mu/h_1/h_2/h_Delta，以及epsSim、epsChain、epsV、epsZ。这里：

~~~text
M=2^128
L=(r−1)128+b，b=48
c_role=2r²+10r+6
Pbar=q0+c_role q_anchor.
~~~

Rain-3为r=6、c_role=138；Rain-4为r=7、c_role=174。Pbar包含全部来源调用、有限C/T/P私有补齐及最终Verify。它与保守提取器的每根12/14调用界不同，禁止混用。

模拟器仍先在无Ext的来源游戏中比较签名分布，使用IC单元耦合、正常读取H4旧点、全修正串的H1编程熵和真实grinding尾项。安装新B的私有读取后，来源流程不受反馈；H_s公开HitKey立即成功停止，私有提取成功只缓存。

## 3. 可执行的同一个B

B有Full双向IC缓存、Source首次曝光索引、前缀一致RO表。A、模拟器公开重构和Verify触达的行均登记为Source（Full缓存命中也执行首次Source提升）；私有派生行不递归成为新根。只有A最终输出前的Source行可作私有C/T/P完备化根，其数量计入q_anchor。仅在A输出前由A首次触达的合规普通H1/H2上建立/物化提取钩子；模拟器编程行及最终Verify首次H1/H2只正常预留/回应，不新建提取记录或运行私有模板。Verify的公开工作全部计入q0，结束后无新Source工作。最终新链由epsChain覆盖，最终新HDelta由1/M覆盖；好链上的旧HDelta则回溯到A输出前的快照。

**H1之前。** 保存不可变输入及Source/RO水位。对每个底层上下文，canonical父节点只从H1前已有Source父格支持者中选择：以固定的(parent key, Source root id)顺序选匹配有序com对的第一个，选择不依tape。另一父格、孩子com和tape由有限P模板普通读取确定；可惰性到H2求值。没有匹配父节点时该对基线取零。后来Source增长不改变旧canonical。

**H2之前。** 按当前Source水位执行有限C/T/P，得到该森林的K_vis。它包含真实com或任一tape输入已经Source触达的seed，以及Source父格支持者的两个孩子。按承诺值过滤并去重。若已知某桶已有u+1个不同seed，私下记录cap-overflow并跳过这次提取，来源照常继续；该异常包含在全域桶坏事件中。

令A_t=⊕_j M_t,j⊕c_t，D_t,i=A_t⊕M_t,2i⊕M_t,2i+1。B按固定次序找VH(f)=ũ的已知候选：

~~~text
f=A_t；
f=D_t,i（当两个com相同，空桶也尝试）；
f=D_t,i⊕m_t(a)⊕m_t(b′)，
  a、b′分别来自该底层对的两个当前K_vis桶。
~~~

第三类用VH线性查找：一侧按VH(tape)建立确定性字典，扫描另一侧查异或补值，找到任一个候选即可；同hash多seed保留固定代表。不会枚举u²个组合后才知道是否存在匹配。

若找到f，立即固定W=d⊕f[0:ell]，执行真实Rain关系核验，记录known分支及至多一个W。否则记录unknown。然后才响应首次H2挑战；重复输入复用旧结果。以后发现的新叶不升级已缓存的H2分支。

B从不枚举全密钥域，也不计算下文全桶S_t或语义V。它实际输出的Rain原像来自自己在H2之前算出的W，或来自公开H_s检测器。

## 4. 全桶语义族与挑战前固定性

在分析中固定最初抽取的整张E。每个H1森林的完整叶桶、tape及上述canonical都是该H1历史与E的确定函数。令：

~~~text
B_t(z)={s:E_s(x_C,t)=z}
E_t,beta={m_t(s)⊕M_t,beta⊕1 : s∈B_t(com_t,beta⊕1)}
E_t=各beta误差的并集

F_t^+={A_t}
 ∪ {D_t,i⊕m_t(a)⊕m_t(b′)：全桶中的全部有序seed组合}
 ∪ {D_t,i：两个com相等}.
~~~

相同com但空桶的D补项保证B每个可计算候选也在语义族中。若桶非空，该D已由a=b′给出；桶空时只补一个，因此全域桶宽≤u、u≥1时仍有：

~~~text
|E_t|≤N_t u
|F_t^+|≤1+N_t u²/2.
~~~

排除树内不同误差的VH碰撞，以及整个∪F_t^+内不同u的VH碰撞（含同一树）。令：

~~~text
C_U(u)=Σ_t C(N_t u,2)+C(Σ_t(1+N_t u²/2),2).
~~~

对应全部普通H1的损失为a_1 epsV C_U(u)，另付全域桶尾。RO新鲜性在固定E与H1前历史后仍成立；没有以未来有效伪造或结构好事件作条件。H2后的候选发现只揭示早已属于全族的值，不改变该族。

在父节点结构覆盖下，任何洞beta的开示满足：

~~~text
q_t,h=V_t,h ⊕ beta_h A_t ⊕ [h=0]e.
~~~

[仿射引理](%E5%85%B1%E4%BA%AB%E5%9C%B0%E5%9D%80/01_%E6%9C%89%E9%99%90%E5%80%99%E9%80%89%E6%97%8F%E4%B8%8E%E4%BB%BF%E5%B0%84%E6%8F%90%E5%8F%96%E6%9B%BF%E4%BB%A3%E5%BC%95%E7%90%86.md)逐列推出：每个洞至多一个合格q；一树有至少两个洞时给出唯一u_t∈F_t^+；所有多洞树的u_t相同。未知的共同误差允许存在，它只改变V的最低列，不必直接作为证明失败。

## 5. 已知见证与两点挑战分支

在known分支，所选f与每个多洞树的u_t具有同一VH值；全族无不同u碰撞使它们相等。单洞树可按这个f定义V；多洞树以语义合格集合的字典序首点定义V。于是同一语义矩阵在H2回应前固定，并对全部相容开示满足：

~~~text
Q=V*⊕f Delta^T，W=d⊕f[0:ell].
~~~

B实际知道W，足以核验并输出Rain原像。真实Rain约束的QS最高次系数是e_i(W)=x_i(W)y_i(W)+1，只依W；V*影响低次系数。因此即使B未计算V*，在H2之前已知非零e(W)仍可用epsZ，随后非零二次式至多两个根。相关源码及论证见[见证提取稿第6节](%E5%85%B1%E4%BA%AB%E5%9C%B0%E5%9D%80/05_%E5%85%A8%E6%A1%B6%E8%AF%AD%E4%B9%89%E4%BB%BF%E5%B0%84%E4%B8%8E%E8%A7%81%E8%AF%81%E6%8F%90%E5%8F%96%E5%80%99%E9%80%89.md)。

在unknown分支，全部A_t都不匹配ũ，所以每树合格洞至多为同一底层对的两个洞。同seed抵消时给出B已尝试的D；两个seed都已知时也应被线性查找找到。因此若至少两树各有两个洞，它们的同一u导致一个跨树完整tape等式，其中至少一条不自消的tape在该H2 Source切口从未触达。该事件下一节单独计费。排除它后，最多一树为双洞，整个森林至多两个Delta。

每次首次普通HDelta回答之前，在全部历史上定义至多两个分析目标：known为二次根，unknown为至多两个兼容Delta；无此条件时目标置空，把最终有效伪造交给已列坏事件。旧HDelta追到首次预留，短/零XOF不重采样，程序行按新消息链隔离。故两分支统一仍为(2a_Delta+1)/M，末项1/M是最终Verify首次查询的精确挑战匹配。

## 6. 三个结构界

取全域事件G_u：任意输入x和输出y的承诺原像桶至多u。可用：

~~~text
delta_u=min(1,M²/(u+1)!).
~~~

所有使用它的局部界都可先界事件∩G_u，最后只加一次delta_u。需要新鲜IC的证明只条件于各自选定的列，利用G_u包含于当前列帽，未条件于整个未来G_u后重用剩余置换均匀性。

**有序双承诺绑定。** [注册支持记录定理](%E6%8F%90%E5%8F%96%E8%B5%84%E6%BA%90/03_%E5%BA%95%E5%B1%82%E5%8F%8C%E6%89%BF%E8%AF%BA%E7%BB%91%E5%AE%9A%E6%8E%A2%E7%B4%A2.md)给出在G_u内：

~~~text
epsCanon = q0(q0−1)u²/[(M−q0−1)(M−q0−2)].
~~~

旧注册定理对任意Full支持父节点成立，此处使用一个更窄的Source支持事件：canonical父节点在H1前已有Source父格；最终完全可见对的真实父节点在Verify公开展开时也有Source父格。不同有序tape的歧义必然给出两名不同Source支持父节点，且有序com对相同。因此所需事件包含于PairSrc。PairSrc只依Source轨迹与同一E，删除无反馈私有读取后逐点不变；在该边缘过程中将旧定理的P取q0，得到上式。canonical的选取本身可以依私有求得的E值，事件包含关系已足够，不要求该选择只由Source回答计算。缺少旧父支持的情形由下一项支付。这个推论经过提取资源分工独立核对；完整审查路径与固定版本在审查清单列出。Full的Pbar及138/174系数仍完整保留于真实OWF时间/查询账，未将其改成q0。

**迟到父节点。** [整列genie定理](%E5%85%B1%E4%BA%AB%E5%9C%B0%E5%9D%80/04_%E8%BF%9F%E5%88%B0%E7%88%B6%E8%8A%82%E7%82%B9%E7%9A%84%E6%95%B4%E5%88%97Genie%E7%95%8C.md)给出：

~~~text
epsParent = a_1 N q0 u²/[2(M−q0−1)(M−q0−2)].
~~~

旧Source任一父格已被P模板覆盖。其余父节点的两个父格都未Source触达，给每个H1切口分别揭完整com列，并在切口后首次任意key触达之前计双块命中。私有Full读取因无反馈可删除，概率用q0，真实资源仍付Pbar。

**跨树未知tape。** [新桥定理第8节](%E5%85%B1%E4%BA%AB%E5%9C%B0%E5%9D%80/05_%E5%85%A8%E6%A1%B6%E8%AF%AD%E4%B9%89%E4%BB%BF%E5%B0%84%E4%B8%8E%E8%A7%81%E8%AF%81%E6%8F%90%E5%8F%96%E5%80%99%E9%80%89.md)在每个H2切口分别揭该森林全部父格/com列，使完整桶、K_vis及canonical选择固定。再揭其余tape，保留一个本树未知seed的L位tape作最后均匀剩余置换采样。其他树地址互异，同树另一seed不同，自消已由D覆盖。

~~~text
C_X(u)=u⁴ Σ_{t<s}(N_t/2)(N_s/2)
d0=q0+3tau+r(tau−1)
rho=(M/2^b)/Π_{j=0}^{r−1}(M−d0−j)
epsTwin=a_2 C_X(u)rho.
~~~

分子M/2^b保留最后AES块的80个未用位；约为2^−L，未错误按2^−128r计。它约束完整tape异或等式，未假定“迟到叶×VHash”独立。自适应选择的四元组已包含在全桶计数中。

## 7. 完整合成定理ST

取整数1≤u<M及预先确定的有限攻击预算。结构分母适用域为q0≤M−3、d0+r−1<M；越界的对应分项取1。各分项可截到1，最后总界再截到1。

~~~text
Adv_030^EUF-CMA(A)
 ≤ min(1, Adv_Rain^(OWF,IC)(B)
       + epsSim + epsChain + delta_u
       + epsCanon + epsParent
       + a_1 epsV C_U(u)
       + epsTwin
       + a_2 epsZ
       + (2a_Delta+1)/M).                               (ST)
~~~

B恰为第3节的有限算法；没有另假设池外新叶永不出现或单叶承诺无碰撞。

完整覆盖顺序是：先付CMA模拟；H_s或私有提取成功已给Rain原像；否则新消息伪造的哈希链指向正确旧H1/H2。完全可见父对若不是H1来源支持者便触发epsParent；若支持者的tape与canonical不同便触发epsCanon。剩余开示被全桶语义族覆盖。AU之后，known进入固定W的QS，unknown通过epsTwin进入两点挑战集合。最后合并RO挑战事件。桶好事件共同失败只付一次，所有其他坏事件相加而非相乘。

旧的q0²/M单叶Pair与a_1 N q0/M全迟到叶项在(ST)中均不需要；它们保留于另一个保守定理(C)。这是一项已明示全部代价的证明改进，不是算法抗攻击强度的直接数值测量。

## 8. B的实际时间与存储

令e≤min(a_1,a_2)，H_call为全部来源RO请求数，B_IO为输入、输出及内部XOF预留总位数，w=max(128,ceil(log2(Pbar+H_call+2)))，S=Pbar+H_call+2。确定性有序索引保存Source水位和父描述符；C/T/P每根只求值一次，各高度tape与Full双向映射缓存复用。对每个(x_C,com_even,com_odd)只追加canonical最小父发生变化的(source_time,parent)记录，H1按历史水位二分查询；变化记录总数至多2q_anchor，不使用会增加对数空间的通用路径复制树。叶桶按seed去重并记录首次Source支持时间，按H2水位取前缀；溢出桶提前标记。VH查找字典按当前pair释放，长期保存原始tape及所需基线；不另物化所有H2的Nu份hash缓存。

令C_VH(L)、C_Rain、c_IC分别为一次实际VHash、Rain关系核验和外部IC调用的真实费用，不把不同操作当同价。可实现的保守时间账为：

~~~text
T_B ≤ T_src + Pbar c_IC
 + O(B_IO log S
     +(q0+c_role q_anchor+H_call+eN+a_2 N)w log S
     +eN k_max L
     +a_2[(Nu+tau)C_VH(L)
           +Nu(128+b+w)log(u+1)+L+C_Rain]
     +a_s C_Rain).
~~~

这里保留了基线匹配、聚合、有限池检索及每次H2的搜索。固定长度hash可用trie把log(u+1)项换为确定性逐位访问；上式采用更宽的有序字典界。桶溢出时私有跳过，保证算法在所有轨迹上的搜索量上限；这项分支已由delta_u支付。

令S_src为A、签名模拟及Verify原有状态的峰值空间；以下加上它给出B的完整保守存储上界：

~~~text
S_B ≤ S_src + O(B_IO
  +Pbar(128+w)
  +2(r+5)q_anchor(L+w)
  +eN(L+w)
  +a_2(ell+w)+a_1 w
  +u(128+b+w)+L).
~~~

可用引用及流式处理减少复制，此处未提前记作已实现收益。语义全桶、整列及V*不由B物化，也未被塞入实际内存账。

因此(ST)的OWF项应写为这个B，或在T_B、Pbar和完整存储预算处评价一个明示的Rain计算假设。现有文献的攻击上界不是该优势函数的普遍上界；本稿没有给它填0。实际AES/SHAKE的模型替代与侧信道亦未由理想模型定理自动证明。

## 9. 相对于rFAEST目标的含义

本稿为原030提供了一条覆盖共享AES地址、有效伪造和有限提取成本的新完整条件界。它解决本轮提出的三个数学工作项中的主要证明衔接。它不直接断言rFAEST的EM关系也满足“独立辅助IC”前提：参考OWF使用公开AES密钥的AES_a(k)⊕k，与同一IC有相关性。

八组可公平比较的组件计数和同条件系数在精确账本单列；完整EM归约需要处理其自己的OWF/IC条件分布。两份上界之间的大小也不是真实攻击复杂度排序。

最终是否足以按用户目标验收128位，须综合本轮数值、实际B费用和明示Rain困难性口径。相同名义参数、完整经典条件定理、未发现廉价完整伪造，三者都应如实报告，不能替代这个具体判断。
