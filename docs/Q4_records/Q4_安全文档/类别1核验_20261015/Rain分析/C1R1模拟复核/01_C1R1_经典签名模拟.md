# C1R1：经典无私钥签名模拟的独立复核

2026-10-15，修订 2。经典模拟部分已完成内部 AI 独立反驳复核，依据与范围见 §9。对象是 C1R1 六个 Rain-128 参数，固定单参数、单公钥、经典查询。本文给出候选专用的签名视图耦合；完整 EUF-CMA 合并和 NIST 类别 1 判定另行完成。原阶段 00b–05 与冻结源码保留原证据身份。

## 1. 与前代证明的接口

前代 [阶段 03 v4](../../../Q4_%E9%87%8D%E5%81%9A_03_P02_H3_ROM%E4%B8%8E%E6%97%A0%E7%A7%81%E9%92%A5%E6%A8%A1%E6%8B%9F.md) 的 H_s 检测器、首成功 grinding、缓存和三角掩码结构仍有对应接口。其隐藏耦合式 C5 不直接沿用：C1R1 将原始叶种子 s 与 tape 密钥 K 分成两枚 128 位随机标签，并新增 SHAKE256 随机预言查询。

模型是一个双向 ideal cipher E（每个 128 位 key 对应独立随机置换），一个 SHAKE128 角色共用的随机位串预言，以及独立的 SHAKE256 随机位串预言 H_L。独立性是理想化模型假设，未由具体 SHAKE 实现自动推出。

取 M=2^128、λ=128、D=128−g、N=Σ_t 2^{k_t}、Σ_t k_t=D。Rain-3/4 的逻辑 tape 长 L=688/816 位，r=ceil(L/128)=6/7；前代 u 的见证、QS 掩码和 VHash 掩码三段长度 ℓ、128、176 保持原值。补齐至 r 个 AES 块的多余位也纳入隐藏耦合。

本模型只覆盖签名 oracle 原子执行、调用之间允许经典自适应查询的 CMA 接口。签名随机化分别处理：deterministic 省略 ρ；randomized 每次先独立取 16 字节 ρ，再按 (μ,ρ) 查缓存。

## 2. 从候选源码核定的新接口

候选目录：C1R1（内部记录，未随仓库公开）。

`vector_com.inc:1167` 实际计算

\[
\begin{aligned}
ctx_{t,j}={}&\operatorname{ASCII}(\texttt{RAIN-C1-LEAF-v1})
\Vert LE32(128)\Vert LE32((k_t+1)\tau+t)\\
&\Vert LE32(t)\Vert LE64(j)\Vert iv,\\
H_L(ctx_{t,j}\Vert s_{t,j})[0:384]={}&K_{t,j}\Vert C_{t,j},
\end{aligned}
\]

其中输入 67 字节、K 为 128 位、C 为 256 位。`state.init(secpar::s256)` 选择 SHAKE256。`write_leaves:159` 的 j 是原树叶位置；异或 Δ 只调整输出地址，`small_tweak` 实际传树号。

`vector_com.inc:524` 将洞原始种子设成零，仍调用 H_L，再在 `:540` 将洞 tape key 覆盖成零、将洞承诺覆盖成 opening 中的 C。`small_vole.inc:134` 的 receiver 从 `keys[1]` 起算，因此洞没有 tape AES 调用。**H_L 零种子响应留在普通 RO 表里**，只覆盖调用方缓冲区，绝不覆盖 RO 记录。

μ 的实际编码是

\[
H_\mu(\operatorname{ASCII}(\texttt{RAIN-C1-SIG-v1})
\Vert LE32(\lambda,R,\tau,g,B_{bytes})\Vert pk\Vert msg\Vert\mathtt{c0})[0:256].
\]

这是 `c1_domain.hpp:18` 与 `faest.inc:41,201` 的事实；尾字节是 c0。B_bytes=6，b_bits=48。设计草稿中的“原角色后缀”应以此源码为准。其余 SHAKE128 挑战编码与维度保持前代；不同角色尾字节分开，H_L 属于独立 SHAKE256 域。

首次触达任一完整 H_L 输入即内部预留 384 位，包含返回零位或短前缀的查询；长输出按同一前缀延长。重复/补长不重采样，也不逃避首次触达计数。

## 3. 逐项调用数

每份新缓存项的隐藏标签是：master 种子 1 枚、隐藏路径内部节点 D 枚、原始洞叶种子 τ 枚、洞派生 tape 密钥 τ 枚。因此

\[
S=1+D+2\tau. \tag{S1}
\]

隐藏 AES 植入需求是 master 的 τ 个树根、D 个内部节点各两孩子、τ 个派生 tape key 各 r 块；原始洞叶种子不再作为 AES 叶承诺 key：

\[
J=\tau+2D+r\tau=2D+(r+1)\tau. \tag{S2}
\]

真实 Sign 的 AES 调用和一次公共重构的 AES 调用分别是

\[
\begin{aligned}
A'_S&=\tau+2(N-\tau)+rN=(r+2)N-\tau,\\
A'_V&=2(N-\tau-D)+r(N-\tau)=(r+2)(N-\tau)-2D,\\
A'_V+J&=A'_S. \tag{S3}
\end{aligned}
\]

这些是单块 IC 查询数，非 SIMD 指令数。`avx2/constants_impl.hpp` 的 VOLE_BLOCK_SHIFT=0，使候选 r=6/7 与实际每叶 AES 输出块数一致。

| 运算 | 普通 H_L 调用 | 潜伏 H_L 行 | AES 调用 |
|---|---:|---:|---:|
| 真实 commit/sign 的叶与 tape 部分 | N | 0 | A'_S |
| pk-only 公共重构一次 | N（含 τ 个 dummy） | 0 | A'_V |
| 数学隐藏路径补全 | 0 | τ | J |
| 公共重构加隐藏补全 | N | τ | A'_S |

最后一行的 H_L 总数 N+τ 比真实 Sign 多 τ。多出的就是 dummy ghost 查询：在分析中的真实 Sign 加做洞位置 H_L(ctx∥0) 查询，不用其结果。预先定义的随机函数不受这种内部查询影响，攻击者视图保持同分布；它们仍计入查询预算。

设 Q 为签名调用上界，a_IC 为攻击者正逆 IC 调用总上界，a_L 为攻击者 H_L 不同完整输入上界；最终 Verify 至多完整执行一次。令

\[
\begin{aligned}
H&=QS,\quad P_0=a_{IC}+(Q+1)A'_V,\\
L_0&=a_L+(Q+1)N,\\
C_0&=1+P_0+2L_0. \tag{S4}
\end{aligned}
\]

L_0 是实际 pk-only 游戏的普通 H_L 首触达上界；潜伏视图的总行数上界另为 L_0+Qτ。缓存命中使实际新项数 n≤Q，只减少上述计数。额外测试验签、接口暴露更多 oracle 或其他内部 H_L 查询，均须加入对应预算。

## 4. 完全虚拟隐藏游戏与两类 oracle 的补全

先比较未安装 Ext 的游戏。Ext 的内部完整表读取与补 tape 操作稍后加入；它们不是攻击者猜中隐藏标签的事件。

对每个新缓存项，先选择 IV、Δ 和 opening。D 个公开兄弟种子、τ 个洞承诺以及各洞 r 个完整 tape 块在虚拟游戏中独立均匀，公开子树始终使用真实普通 IC/H_L。S 枚隐藏标签互相独立，并与这些可见数值独立：它们只给出待植入行的私有索引，从未用于普通 oracle 的计算。

原始洞叶 s 和派生 K 是两枚独立标签；其潜伏行是

\[
(ctx_{t,hole}\Vert s)\mapsto(K,C_{t,hole}). \tag{S5}
\]

在公布 C 之前，(K,C) 是独立均匀的 384 位对；随后公开 C 不影响 K 的 128 位猜测熵。此事实不等于“已公布 C 后，新建这行的完整响应仍条件均匀”。潜伏行单列来源，始终不套普通 H_L 新响应的 LeafCollision/LeafLate 引理。

### 4.1 坏事件

定义三类可保守扩大、允许重叠的坏事件。

1. **隐藏标签相等**：任意两枚不同虚拟标签相等，包括跨新缓存项；同缓存项重复使用原对象不是新标签。
2. **普通候选命中隐藏标签**：候选集合包括零值；所有普通 IC 正/逆查询的 key；每个普通 H_L 完整输入的种子字段；每个普通 H_L 响应预留的前 128 位 K。候选总数至多 C_0。有效 H_L 输入种子字段唯一；其他无关格式可一并计入上界。公开叶种子现只用于 H_L 而未必用于 IC，因此输入种子项是必要新增项。输出 K 项保守保护未立即用于 IC 的公开派生密钥。
3. **单个隐藏 AES key 的输出重复**：一个隐藏 key 对不同明文指定了重复输出。master 有 τ 个明文，每个隐藏内部节点有 2 个，洞 tape key 有 r 个。原始洞叶没有 AES 单元。

第 2 类覆盖旧表 key、后来由攻击者自适应选择的正逆查询 key、H_L 对潜伏完整输入的首次触达，以及 public/dummy 派生 K 与隐藏 key 的别名。dummy 的零种子由零候选直接覆盖；其普通 H_L 输出始终保留。仅有两个 256 位承诺值相等不妨碍随机函数补全，故隐藏模拟不额外要求承诺输出全域互异。

### 4.2 无坏事件时的补全

无前两类事件时，各隐藏 AES key 互异，普通 IC 表在这些 key 上为空。00b 已核验的 counter/tweak 编码保证每 key 下指定明文互异；排除第 3 类后，输出也互异。因此每个有限映射都可补成均匀随机置换，正向与逆向已有记录同时保持。普通 key 间相同明文/输出允许存在，互不干涉。

分布耦合按真实派生顺序进行，既非只证明某个补全存在，也非在观察到最终轨迹后将真实 oracle 改写。对隐藏 E 的一个新单元，虚拟侧取均匀 Y；若 Y 没有占用，真实侧使用 Y，若 Y 已占用，真实侧从该 key 的剩余输出均匀重采样并记录 B_perm。若已占用 m 个输出，每个剩余值的真实边缘概率为 1/M+(m/M)/(M−m)=1/(M−m)，恰是随机置换响应。触达已有普通 key 或隐藏 key 别名时先记相应 Bad，之后真实侧照其已有表正常运行。新潜伏 H_L 输入与同一独立 (K,C) 对耦合；若输入已触达，记 B_touch，真实侧返回既有响应。故两侧的各自边缘分布正确，首次 Bad 前逐项一致。

每个潜伏 H_L 输入都不同于所有普通 H_L 输入；潜伏输入彼此也互异（即使 ctx 碰巧相同，原始种子别名已经排除）。于是可填入 S5 的两片输出及独立 XOF 长尾。与普通 H_L 其他输出的相等是随机函数允许的事件，不要求后缀 C 互异。

这种补全重现真实隐藏树、原始叶到派生 K 的连接、洞 tape 及全部公开计算。逆 IC 查询只有指定隐藏 key 才接触植入行，已单列计费；不存在用逆查询无偿跨 key 寻找隐藏 key 的接口。

实际 pk-only 模拟器直接省去隐藏标签和潜伏 IC/H_L 行，只运行普通 oracle 与公共重构。攻击者第一次通过普通查询触达这些潜伏索引，或产生上述补全冲突，才可能区分两种视图。数学上的潜伏行不是模拟器对其真实 IC 的私自改写。

## 5. 经典隐藏距离的新界

在**完全虚拟、潜伏行从不反馈普通计算**的游戏中，全部隐藏标签可延迟到完整普通轨迹产生之后抽样。这是分布重排的事实：普通轨迹可能依赖公开 sibling seeds、C、tape、消息和既有 oracle，但不依赖这些私有标签。

完全虚拟游戏不因标签 Bad 或潜伏植入冲突提前结束，也不将 Bad 标志返回普通计算；先产生完整普通轨迹，再判断这些私有事件。程序冲突和 HitKey 的停止由普通轨迹决定，可以保留。首次差异的 killed/coupling 游戏在这个未按标签 Bad 截断的虚拟分布上另行定义，因而不存在停止时刻泄露隐藏标签后仍套独立抽样界的问题。

固定该普通轨迹，其候选集大小至多 C_0。每枚隐藏标签仍独立均匀，因此

\[
\Pr[B_{labels}\lor B_{touch}]
\le\frac{\binom H2+HC_0}{M}. \tag{S6}
\]

这里按虚拟游戏的未条件化标签抽样直接并合；没有先条件化“未来无坏事件”再主张标签均匀。也不先把这些标签写回普通 oracle 后继续使用这种独立性。

每个隐藏 AES key 的虚拟输出在原始 tape 变量中是独立均匀抽样；与随机置换的不放回抽样逐个耦合，首次重复时失败。各 key 的本地碰撞项求和得

\[
V=Q\left[\binom\tau2+D+\tau\binom r2\right],\qquad
\Pr[B_{perm}]\le V/M. \tag{S7}
\]

公开 sibling seeds 与隐藏 child seed 的相等、master 两孩子相等可能同时计入 S6 与 S7；重计只使上界放宽。通过 §7 的三角变量代换后，完整洞 tape 的联合分布仍是代换前的均匀分布，末块未用位独立补齐，故这一步未把 tape 块假设为条件于最终 transcript 的独立均匀值。

得到本轮候选的保守经典界

\[
\boxed{\epsilon_{hide,C1R1}
=\min\left\{1,\frac{\binom H2+HC_0+V}{2^{128}}\right\}.} \tag{S8}
\]

Q=0 时 H=V=0，取零。该界在任意预算都定义；大预算下可饱和为 1。S8 的分母 2^128 来自独立标签和 with-replacement 虚拟抽样；不是把已有置换表内的条件分母 M−m_K 偷换成 M。真正的置换只在耦合侧按无重复事件匹配，首次冲突已按 S7 收费。

S8 是签名模拟的距离界，不是具体攻击成本，也没有将量子搜索代入经典查询。独立反驳复核已专门核对 S6 的延迟抽样前提与 S7 的补全顺序，结论限于本节经典耦合。

## 6. H_s、RO 编程和缓存

H_s 检测器在攻击者首次触达每个完整 H_s 输入、返回任何长度之前，检查前 16 字节是否为 pk 的合法 Rain 原像，含非零 S 盒条件。命中即输出原像并成功停止。检测适用于任意合法原像，未使用密钥唯一性。

在这个停止时刻前，真正的秘密 H_s 输入未由攻击者触达。每个新的 (μ,ρ) 对应的 (s_root,iv_pre) 因而可隐式采样为两枚独立均匀 128 位值；前者已计入 H。不同缓存项的 s_root 相等由 S6 收费，iv_pre 碰撞由 H4 编程冲突收费。μ 不承担隐藏熵。

相同 (μ,ρ) 在真实和模拟游戏都返回原字节串及原 oracle 记录；randomized 必须先抽新的 ρ，随后才查缓存。不同消息导致相同 μ 的情况也走相同缓存，和真实 H_s 输入一致；此处未暗中假设 μ 单射。

pk-only SimSign 沿用前代 §3 的流程，但 μ 改为 §2 编码、公共重构改用 rain_c1_sets、H_L 普通查询取独立 SHAKE256 表且首次预留 48 字节。H_L 不编程；洞承诺仅填 opening。先抽 Δ，再按真实首次成功分布编程 SHAKE128 的 H1、H2、HΔ；失败 grinding 行和成功同批剩余至多三行完整记录。

每个编程点遇任何长度的旧完整输入就冲突，绝不覆盖旧答案。C1R1 的普通 H_L 调用属于独立域，不会在当前签名中新增 SHAKE128 旧 H1/H2/HΔ 点。因此前代 §4 的新鲜位置论证逐项给出

\[
\epsilon_{program}=Q\left[\frac{h_4+h_1}{2^{128}}
+\frac{h_2}{2^{704}}+\frac{h_\Delta}{2^{448}}\right]. \tag{S9}
\]

h_4,h_1,h_2,h_Δ 是相关角色全部历史输入的确定性上界，包含攻击者与过去签名。当前整批 grinding 共享一个新 chi2 前缀；已经计入历史 h_Δ 后，不再额外乘当前 G。

G 是不超过 2^32 的正 4 倍数，首次成功尾项为

\[
\epsilon_{tail}=Q(1-2^{-g})^G. \tag{S10}
\]

选择 G=min(2^32,4ceil(2^g(128+ceil(log2(max(1,Q))))/4))，未触及上限时尾界至多 2^-128。32 位计数器耗尽归入尾事件；上层 API 的失败处理仍由工程实现单列。

## 7. 无私钥变量代换与结论

固定 Δ、opening、公共子树和普通 RO/IC。每棵树其公开叶 tapes 的 XOR 为 B_t，洞 tape 为 m_t。令 u_t=B_t⊕m_t、u=u_0、c_t=u_0⊕u_t。洞 tapes 与 (u,c_1,…,c_{τ−1}) 是双射。

固定 c、chi1、chi2 后，V=Q⊕uΔ^T。将 u 分成 u_W、u_QS、u_VH，真实发送者的三个公开量是

\[
d=W\oplus u_W,\quad
a=Z_1(W,V_W,chi2)\oplus u_{QS},\quad
u_tilde=VH'_{chi1}(u_W\Vert u_{QS})\oplus u_{VH}.
\]

Z1 仅依赖前 ℓ 行约束 MAC，因此给定任意 (d,a,u_tilde) 可按顺序唯一解出三个 u 段。维度之和恰为 L。这是完整联合双射，允许直接独立采样 (d,a,u_tilde)，分布与 W 无关。真实有效 W 保证 QS 的 b_verify=b_real、接收方 H2 字节串等于发送方 H2 字节串。源码这部分沿用旧 Rain/QS 关系；新的叶接口只把确定 tape 的 key 从 s 换成 K。

因此在固定参数、公钥由真实 KeyGen 产生、有界经典查询、上述理想化和缓存条件下，真实签名视图与仅输入 pk 的模拟器视图在 HitKey 停止前的统计距离至多

\[
\min\{1,\epsilon_{program}+\epsilon_{tail}+\epsilon_{hide,C1R1}\}. \tag{S11}
\]

本文证明的是签名模拟部分。要给出 EUF-CMA 的总界，仍须接入候选 H_c/挑战链、LeafCollision/LeafLate、free/fixed、VHash、QuickSilver 和 Rain 原像归约，统一全部资源口径；这里没有以 S11 取代这些义务。

## 8. 与候选叶绑定引理的隔离

[经典叶绑定替代引理](../../%E5%BD%92%E7%BA%A6%E5%88%86%E6%9E%90/01_C1R1_%E7%BB%8F%E5%85%B8%E5%8F%B6%E7%BB%91%E5%AE%9A%E6%9B%BF%E4%BB%A3%E5%BC%95%E7%90%86.md) 只用于实际 pk-only 游戏的普通 H_L 首响应；这些响应在首次完整输入时真实均匀，其预算为 L_0。τ 条潜伏行仅在 S8 的耦合分析出现，未写入实际模拟表，故不污染该局部引理。

Ext 在签名模拟视图比较完成之后才加入。它读取已有 H_L 完整预留记录不新增 H_L 输入，补 tape 的普通 IC 调用按 rNa1 另计归约时间/调用数。用真实游戏的内部日志先读取隐藏种子，再把读取称为攻击者猜测，会破坏 S6；本证明采用的先后顺序排除了这种用法。

签名来源的 H1/H2/HΔ 编程行必须保留来源标记。最终新消息伪造的提取证明仍须隔离这些程序行并核 μ 链；单凭某行由模拟器产生不代表它属于可任意应用新鲜响应引理的普通行。

## 9. 验证、边界与待审项目

随附脚本仅做有限枚举与整数计数，核六档 S/J/A'_S/A'_V、标签候选的自适应选择、缺少原始 seed 或派生 K 计费的反例、RO 短前缀一致性与单 key 置换补全。它不替代 S6–S11 的一般证明，也不执行原生构建。

内部独立反驳者 `/root/refutation_p02` 对修订 1 核过事件覆盖与计数，未找到 S8 的反例；其提出的两项精度补充——虚拟轨迹不因标签 Bad 提前结束、按真实派生顺序逐单元耦合——已落实在修订 2 的 §4.2/§5。这是内部 AI 审查，不是外部同行评议；完整 CMA 组合单独验收。

本代理运行 [有限核验](%E6%9C%89%E9%99%90%E6%A0%B8%E9%AA%8C_%E8%BF%90%E8%A1%8C01.json) 得 96,923/96,923，通过项为源码参数提取、树路径枚举、虚拟标签候选计数、遗漏角色反例、RO 前缀一致性与正逆置换补全。CPU 0.0625 秒、墙钟约 0.057 秒、峰值工作集 23,019,520 字节、单线程；硬资源上限 120 CPU 秒/512 MiB，全部输入运行前后哈希相同。

另外核读了协议分析代理的 [原生模拟 R3](../../%E5%8D%8F%E8%AE%AE%E5%88%86%E6%9E%90/C1R1%E6%A8%A1%E6%8B%9F/native_R3/evidence/summary.json)：141/141，通过六档每档四份新的 pk-only 模拟签名、字段/消息/公钥负例、缓存、首成功 grinding、短/零输出及计数检查。普通 SHAKE 验签拒绝这些仅在可编程 RO 下成立的模拟签名。该实测确认 A'_V、N 次普通 H_L、τ 次 dummy、零次潜伏 H_L 插入、τ+1 次普通 H_c；概率距离由本文推导承担。

量子叠加查询、QROM Fiat–Shamir、具体 AES/SHAKE 假设与 Rain 类别 1 资源下界均不在此经典定理中。


## 10. 供候选总账本使用的最终接口

a_L 是新 SHAKE256/H_L 域的独立先验查询预算，含任意长度的首次完整输入。它不合并进旧 SHAKE128 的 a_c；若只给全局总查询上界，可以对各 a_j 分别使用该更大数，但须明示这是保守重复计费。两套 XOF 都由归约 B 本地维护，经典长度自适应查询保持相同前缀。用于 Rain 原像假设的外部辅助 oracle 仍只有与挑战独立的双向 IC，不额外赠送可编程 IC。

普通 H_L 与归约实际 IC 的预算为：

```
h'_L = a_L + (Q+1)N
P'   = a_IC + r N a_1 + (Q+1)A'_V
```

Ext 只查已有 H_L 行，故其中没有 a1N 个新 H_L 调用；rNa1 项是它实际补 tape 的普通 IC 成本。H_s 的隐式秘密输入亦不由实际 B 查询。相反，S8 先比较没有安装 Ext 的视图，使用 P0=P'−rNa1；提取钩子随后作非干预记录与普通查询，固定的 IC 随机函数本身不因内部预查询而改变。所有额外 IC 查询仍须进入 B 的时间/查询量 P'。

若总账本需要沿用记号 T'，其完整定义仅为：

```
H  = Q(1+D+2τ)
P0 = a_IC + (Q+1)A'_V
C0 = 1 + P0 + 2 h'_L
T' = H+C0 = Q(1+D+2τ)+1+a_IC+(Q+1)A'_V+2[a_L+(Q+1)N]
V  = Q[binom(τ,2)+D+τ binom(r,2)]
epsilon_hide = min(1, [binom(H,2)+H(T'−H)+V]/2^128)
```

T' 是候选数记号，不沿用旧 C5 的 4T²/(M−T) 形式。Q=0 时 H=V=0、epsilon_hide=0，但 h'_L/P' 仍包含攻击者与最终 Verify 的查询。

SHAKE128 各调用上界保持旧阶段 02 的 B1 形式：

```
h'_c     = a_c + (Q+1)(τ+1)
h'_mu    = a_mu + Q+1
h'_4     = a_4 + Q+1
h'_1     = a_1 + Q+1
h'_2     = a_2 + Q+1
h'_Delta = a_Delta + Q G + 1
```

H_c 每次仍做 τ 个内层与 1 个外层，输入长度变为 32N_t+1 / 32τ+1 字节。输出位数依次仍为 256、256、128、704、448、128；同 SHAKE128 表的合法角色用末字节/固定长度解析，H_c 两层不当作独立函数。

CMA 合并可引用范围为 S11 签名模拟距离、上述资源界和实际 H_L 从未编程这一条件。普通叶引理可以取 h_L=h'_L，使用 binom(h'_L,2)/2^256 与 a1 h'_L/2^256 替代旧 AES 叶绑定的 PairCollision/LateHit；其余挑战链、AU/根界和新消息程序行隔离必须由候选总证明继续接入。HitKey 与最终提取成功属于同一归约 B，只收一次 Adv^{OWF,IC}_{Rain}(B)。本文未把后续组合的审查视为已由局部模拟自动完成。

B 每个新签名做 A'_V 次普通 IC、N 次 H_L、τ+1 次 H_c、至多 G 个 HΔ 行及实际 QS/VHash 运算。Ext 的 tape 补齐总量至多 rNa1，公开 Rain 原像检查至多 a_s+a2。RO/IC 日志的索引维护、输入/输出实际位数、每份提取快照的 N 条 tape/关系记录、Q 份缓存签名以及至多 QG 条 grinding 记录都计入时空成本；例如显式保留完整快照的保守 tape 存储为 O(a1 N r λ) 位，另加全部 oracle 原始输入/响应位数和 Q 份签名。对有限六档是明确有界算法；若扩展成渐近 PPT 参数族，仍要求 N=poly(λ)、g=O(log λ) 和足容纳 G 的参数化计数器，固定 32 位字段不是无限参数族声明。
