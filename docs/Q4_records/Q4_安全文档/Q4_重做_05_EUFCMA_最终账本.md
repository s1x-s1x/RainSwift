## 2. 完整合并界与单位

令 M=2^λ，冻结 λ=128、B_bytes=6、b=48、L₁=704、L₂=448。记 R=3/4，n=R+1、ℓ=Rλ、L=ℓ+2λ+b、r=ceil(L/λ)，N为所有树的总叶数，D=λ−g。所有指数单位都是位。

\[
\begin{aligned}
\epsilon_{sum}={}&\epsilon_{hide}+\epsilon_{program}+\epsilon_{tail}
+\epsilon_{chain}+\epsilon_{pair}+\epsilon_{late}
+a_1\binom{\tau}{2}\epsilon_V+a_2\epsilon_Z
+(3a_\Delta+1)/M,\\
Adv_P^{EUF-CMA}(A)\le{}&
\min\{1,Adv_{Rain}^{OWF,IC}(B)+\epsilon_{sum}\}.
\end{aligned}
\]

| 项 | 实际计算式 | 来源/含义 |
|---|---|---|
| chain | `[C(h_c,2)+C(h_μ,2)+(τ+1)a₁h_c]/2^256 + [C(h₁,2)+a₂h₁]/2^704 + [C(h₂,2)+a_Δh₂]/2^448` | B2，摘要碰撞、迟到摘要、逆时序挑战；同域不合规输入也计费 |
| pair | `min(1,P(P−1)/(2(M−P)))`；P≥M取1 | B3，跨key相同完整(x,y)行 |
| late | `min(1,a₁NP/(M−P))`；P≥M取1 | B4，快照之后匹配未知叶目标 |
| VHash AU | `a₁ C(τ,2)·[2^-176+(n−1)(2n−1)/2^192]` | B5/B6，挑战前固定差分 |
| ZHash | `a₂·[2^-128+(R−1)^2/2^192]` | B7，无效见证残差的组合 |
| challenge | `(3a_Δ+1)/M` | B8，全fixed单点、QS两根及最终未查询挑战 |
| program | `Q_sig·[(h₄+h₁)/M+h₂/2^704+h_Δ/2^448]` | C1，fresh IV/chall1/chall2前缀 |
| tail | 精确式 `Q_sig(1−2^-g)^G`；实际代入上界 `Q_sig/2^floor(G/2^g)` | C2/C3，整数截断与32位耗尽 |
| hide | Q_sig=0取0；T<M时`min(1,4T²/(M−T))`；其余取1 | C4/C5，隐藏标签、普通key（含0）、同key无放回切换 |

各项可能重叠，使用并合，不进行未经证明的概率相乘。pair/late/hide保留原始有理式、定理规定的局部截断和原因；总和最后截到1。P≥M/T≥M时不计算零或负分母。其他未局部截断的项可大于1，仍是合法但平凡的并合上界。

`Adv_Rain^{OWF,IC}(B)`没有数值证据，本次所有结果均写为unknown/null。附加误差很小本身也不确定完整EUF-CMA优势；B的时间及预言成本可能显著高于A。脚本支持明确另给有理OWF条件，但本次未使用该选项。

## 3. 全部查询与归约成本

`a_c,a_μ,a_s,a₄,a₁,a₂,a_Δ`上界A在各域的首次完整输入次数，涵盖短/零长度输出请求及不合规输入。a_Δ也覆盖失败、预计算和x4额外行所对应的首次输入；使用A的全部原始grinding调用数作为这部分上界更松，其他H_Δ域首次输入仍须另计。签名模拟器的Q_sigG另加入h_Δ。`a_IC`计正/逆调用合计。重复XOF扩展的位数和A总运行时间另计。每个首次H_s输入检测一次，重复/补长复用判定。

\[
\begin{aligned}
A_S&=(r+3)N-\tau,\\
A_{V,effective}&=(r+3)(N-\tau)-2D,\quad A_V=A_{V,effective}+\tau,\\
S_0&=1+D+\tau,\quad J_0=2D+(r+2)\tau,\\
P&=a_{IC}+rNa_1+(Q_{sig}+1)A_V,\\
P_H&=a_{IC}+Q_{sig}(A_S+\tau)+A_V,\quad T=1+P_H+Q_{sig}S_0.
\end{aligned}
\]

`A_V+J₀=A_S+τ`保证每个模拟重构的零key临时调用均已进入隐藏分析。P是实际归约B的调用界，P_H/T只服务先于Ext的隐藏耦合。两者分开报告。

\[
\begin{aligned}
h_c&=a_c+(Q_{sig}+1)(\tau+1),\quad h_\mu=a_\mu+Q_{sig}+1,\\
h_4&=a_4+Q_{sig}+1,\quad h_1=a_1+Q_{sig}+1,\quad h_2=a_2+Q_{sig}+1,\\
h_\Delta&=a_\Delta+Q_{sig}G+1,\quad h_s=a_s,\\
G&=\min\left(2^{32},4\left\lceil 2^g\left(128+\lceil\log_2\max(1,Q_{sig})\rceil\right)/4\right\rceil\right).
\end{aligned}
\]

B额外执行至多rNa₁个tape调用、Q_sig次公共重构和一次最终Verify、Q_sigG条模拟grinding记录，以及a_s+a₂次公开Rain关系检测。XOR、域乘和索引工作按01 §7的多项式计费，没有把异构操作当等价时间。固定实例的32位counter与一般参数族所需容量分别处理。
