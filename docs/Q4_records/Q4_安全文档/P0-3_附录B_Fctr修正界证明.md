# P0-3 附录 B：F^ctr 的 PRG 优势界及证明

本文件是本作品自己的推导，不是 rFAEST 论文的内容。复核状态见 `P0-3_Lemma3.6_反例严格核验.md` 第六节。

## 设定

游戏取 [rF] Definition 3.3（p.5），F = F^ctr（p.6），E 为理想分组密码，|iv| = |com| = λ（§3.3 的取法）。攻击者 A 至多调用 Get Q_I 次、调用理想原语 Q_P 次（正向 E(s,u) 或逆向 E⁻¹(s,v)），可以自适应。

第 j 次 Get(f_j, i_j) 使用 m_j ≤ q := ⌈ℓ/λ⌉+3 个块。块 c 的输入为 x_{j,c} = iv_j ⊕ ⟨i_j, a_{j,c}⟩，其中各 a_{j,c} 互不相同、⟨·,·⟩ 是单射；输出为 y_{j,c}。记 X_j = {x_{j,c}}_c，Y_j = {y_{j,c}}_c。

不失一般性，假设 A 是确定性的、不重复查询，并且游戏结束时把全部 k_j 交给 A；这只会增加 A 的优势。

定义 μ_X = max_x |{j : x ∈ X_j}|，μ_Y = max_y |{j : y ∈ Y_j}|；E₁[·] 表示理想世界（b = 1）中的期望。

## 定理 B.1

Adv^prg_{F^ctr}(A) ≤ Q_I·q(q−1)/2^{λ+1} + Q_I(Q_I−1)·q²/2^{2λ} + Q_P·(E₁[μ_X] + E₁[μ_Y])/2^λ。

## 引理 B.2

E₁[μ_X] 与 E₁[μ_Y] 都不超过 Σ_{s≥1} min{1, C(Q_I, s)·(q²/2^λ)^{s−1}}。几个特例（λ = 128）：Q_I = 1 时，两者都不超过 1；Q_I ≤ 2^40、q ≤ 9 时，不超过 1 + 2^-42；Q_I ≤ 2^64、q ≤ 9 时，不超过 2 + 2^-53。审查者用 120 位十进制精度重算，三个值依次为 1、1 + 2^-42.66、2 + 2^-53.91。

## 证明

用 H 系数法（[rF] Lemma F.1，取 δ = 0）。

转录写成 τ = (τ_P, τ_G, (k_j)_j)，其中 τ_P = ((s_t, u_t, v_t))_t，v_t = E_{s_t}(u_t)，正向、逆向查询都记成这个形式；τ_G = ((f_j, i_j, iv_j, y_j))_j。满足下面任一条件的转录称为坏转录：

- **(A)** 某个 y_j 内部有两块相同。
- **(D)** 存在 j ≠ j′，使 k_j = k_{j′}，并且 X_j ∩ X_{j′} ≠ ∅ 或 Y_j ∩ Y_{j′} ≠ ∅。
- **(C)** 存在 t、j，使 s_t = k_j，并且 u_t ∈ X_j 或 v_t ∈ Y_j。

### 理想世界中坏转录的概率

**事件 (A)。** 理想世界里各块独立均匀，所以 Pr[A] ≤ Σ_j C(m_j, 2)/2^λ ≤ Q_I·q(q−1)/2^{λ+1}。

**事件 (D)。** k_j 与 k_{j′} 相互独立、均匀，且与所有 iv、y 独立，所以 Pr[k_j = k_{j′}] = 2^-λ。

另一方面，较晚那次 Get 的 iv 是在 A 选定 (f, i) 之后才均匀抽取的。X_j ∩ X_{j′} ≠ ∅ 要求 iv_j ⊕ iv_{j′} 落在至多 m_j·m_{j′} 个值里，概率不超过 q²/2^λ；Y 一侧同理。

两部分相乘，再对无序对求和：Pr[D] ≤ C(Q_I, 2)·2^-λ·2q²/2^λ = Q_I(Q_I−1)·q²/2^{2λ}。

**事件 (C)。** 理想世界中的 (k_j) 在交互过程中从未被使用，所以与不含密钥的转录 τ⁻ = (τ_P, τ_G) 独立。

固定 τ⁻，令 J_t = {j : u_t ∈ X_j 或 v_t ∈ Y_j}。J_t 由 τ⁻ 决定，且 |J_t| ≤ |{j : u_t ∈ X_j}| + |{j : v_t ∈ Y_j}| ≤ μ_X + μ_Y。

于是 Pr[C | τ⁻] ≤ Σ_t |J_t|·2^-λ ≤ Q_P(μ_X + μ_Y)/2^λ。再对 τ⁻ 取期望，得到定理的第三项。

注意 u_t、v_t 可以由 A 在看到 iv_j、y_j 之后自适应地选择；这里唯一用到的随机性是 k_j。

### 好转录的概率比

设 τ 是好转录。对每个密钥值 κ，收集两类输入输出对：

- 「理想原语对」P_κ = {(u_t, v_t) : s_t = κ}，共 p_κ 对；
- 「Get 对」G_κ = {(x_{j,c}, y_{j,c}) : k_j = κ}，共 g_κ 对。

由 (A)、(D)、(C) 都不发生，加上 ⟨·,·⟩ 是单射、A 不重复查询，P_κ ∪ G_κ 中各对的输入两两不同、输出也两两不同。因此它构成一个部分置换，真世界能产生这样的转录。

记 (N)_d 为降阶乘。真世界中：

Pr[T₀ = τ] = Pr[keys, ivs] · Π_κ 1/(2^λ)_{p_κ+g_κ}。

理想世界中：

Pr[T₁ = τ] = Pr[keys, ivs] · 2^{−λ·Σ_j m_j} · Π_κ 1/(2^λ)_{p_κ}。

两式相除，比值为 Π_κ 2^{λ g_κ}·(2^λ)_{p_κ}/(2^λ)_{p_κ+g_κ}。因为 (2^λ)_{p+g} = (2^λ)_p·Π_{r<g}(2^λ − p − r) ≤ (2^λ)_p·2^{λg}，所以这个比值 ≥ 1。

由 Lemma F.1，取 ε = Pr[T₁ ∈ T_Bad]、δ = 0，定理 B.1 得证。

### 引理 B.2 的证明

若 μ_X ≥ s，则存在 s 个不同的 Get，按发生顺序记为 j₁ < … < j_s，它们的 X 集合有公共点；特别地，对 r = 2, …, s 都有 X_{j_r} ∩ X_{j₁} ≠ ∅。

第 r 个事件只依赖 iv_{j_r}，而 iv_{j_r} 在 (f_{j_r}, i_{j_r}) 选定之后才均匀抽取，与此前的一切独立，所以它的条件概率不超过 q²/2^λ。把 r = 2, …, s 的条件概率链式相乘，再对 C(Q_I, s) 个下标集合取并，得到 Pr[μ_X ≥ s] ≤ C(Q_I, s)·(q²/2^λ)^{s−1}。

又因为 E[μ] = Σ_{s≥1} Pr[μ ≥ s]，且每一项不超过 1，引理对 μ_X 成立。μ_Y 的证明相同：理想世界中各块独立均匀，块间重合的概率同样不超过 q²/2^λ。

## 与原式对照

Q_I = 1 时，定理 B.1 给出 q(q−1)/2^{λ+1} + 2Q_P/2^λ。区分器 A1 的优势为 (Q_P/2^λ)(1−2^-λ)^{Q_P}，所以第三项在常数 2 以内是紧的。

原式的前两项与这里的前两项同量级（原式更松）；原式的第三项 2Q_I·Q_P·q/2^{2λ} 比 A1 的优势小约 2^λ 倍。

## 在 Theorem 4.3 中的代入

Lemma 3.5 的混合论证给出 τ(k+2)·Adv^prg_F(Q_sig, Q_P)，其中 Q_I = Q_sig。按引理 B.2：

- Q_sig ≤ 2^40 时，新增线性项约为 τ(k+2)·2·T/2^λ；
- Q_sig = 2^64 时，约为 τ(k+2)·4·T/2^λ。

τ(k+2) 来自混合论证，是界的松弛部分。代入时 Q_P 还要计入归约者自己的 E 调用，见第七节第 5 条。

## 七、独立复核与补充

一个独立审查者逐步核对了本证明。结论是「正确，需补几处」：在全块输出的情形下，定理 B.1 与引理 B.2 都成立，没有找到破坏界的步骤。补充如下。

1. **不重复查询的含义。** 指 A 不做冗余查询：不会用正向查询去问一个已经由逆向查询得到答案的点，反之亦然。否则 (2^λ)_{p_κ} 的计数不对。这一假设不失一般性。
2. **独立性的表述。** 准确说法是：理想世界中 (k_j) 与整个不含密钥的转录 τ⁻ 独立，而不只是与 iv、y 独立。理由是 Get 与 E 在 A 停止前都不使用 k_j，密钥最后才交出。
3. **随机带末块截断。** F_tape 只输出 ℓ 位，末块可能只有 r < λ 位。设 A 攻击截断版本，构造攻击全块版本的 A″：A″ 照搬 A 的全部查询，把 Get 的输出在本地截断后交给 A。A″ 与 A 的 Q_I、Q_P 相同，所以截断版本的优势不超过全块版本，定理 B.1 照样成立。
4. **叶子的联合 Get。** 叶承诺 com 与随机带 m 用同一个叶子种子（[rF] 图 1），所以 Lemma 3.5 混合中的叶子一步要用一次 f = com‖tape 的联合 Get，共 1 + ⌈ℓ/λ⌉ ≤ q 块。定理 B.1 的证明只用到「各块输入互不相同、编码是单射」，覆盖这种情形；需要相应扩展的只是 Definition 3.3 的 Get 接口。
5. **代入 Theorem 4.3 时的 Q_P。** Lemma 3.5 的混合中，归约者要自己模拟没有被替换的节点，它的 E 调用也算进该步 PRG 游戏的 Q_P。

   证明里实际得到的是 Pr[C] ≤ 2^-λ·E[Σ_t |J_t|]，比定理 B.1 的陈述更细。代入时按这个式子计数：只有落进某个 X_j 或 Y_j 的调用才有贡献。

   实现里调整值按（深度, 树号）编排（`vector_com.inc`：内部节点 `(depth + 1) * TAU + tree_i`，叶子 `(tree_depth + 1) * TAU + tree_i`），所以同一棵树、同一深度的节点共用 AES 输入。替换深度 d 的路径节点时，归约者对同深度另外 2^d − 1 个节点的展开（每个 2 块）都落进 X_j。替换叶子时，另外 N − 1 片叶子的 com‖tape 调用（每片 q − 2 块）也落进 X_j。一棵树的全部替换步合计少于 Σ_d 2(2^d − 1) + (N − 1)(q − 2) < N·q 次。

   其余调用只在输出恰好落进某个 Y_j 时才计数，每次调用的期望不超过 Q_I·q/2^λ，可以忽略。

   合起来，新增一项与攻击者算力无关的常数 Q_sig·τ·N·q·E₁[μ_X]/2^λ。这一项是自推导，数值见 P0-4 账本。
6. **λ 的取值。** 引理 B.2 的三个数值都按 λ = 128 计算；λ 更小时会变大，例如 λ = 120、Q_I = 2^40 时为 1 + 2^-34.7。
7. **「每次查询只检验一个隐藏种子」只是估计。** 审查者指出：若按论文的抽象写法，调整值只含节点号、不含树号，那么 E_g(iv⊕⟨1,0⟩) 与 E_g(iv⊕⟨1,1⟩) 这两次查询就能同时检验 g 是否等于 τ 个根中的任何一个，因为每个根都有一个孩子被打开。形式界已经覆盖这种情形。我们的实现里调整值含树号，同一深度只有路径上那一个节点是秘密的，所以真实成功率约为 μ·T/2^λ。但这句话依赖实现细节，没有形式证明，只能算估计。
