## 2. AU：对每个潜在反例的检查

### 2.1 自适应Source会不会破坏不同key的剩余置换独立性

攻击者可以依先前回答选择key、IV、承诺及H₁时机；模拟器亦有程序RO行。仅在固定当前Source/RO前缀及来源随机币后，整个算法到此只通过已记录的普通IC单元读取E。一个固定且一致的前缀因此只约束各key已观测的映射；各key未观测部分仍是各自均匀剩余双射，条件分布按key分解。

这依赖真实模拟接口：程序RO行由独立模拟币、普通IC值及过去RO产生，没有另读未知E值。原虚拟游戏与pk-only算法满足此接口。私有Full值先被删除，后来首次Source提升仍算新的来源曝光；以原Full物理缓存“已经读过”为由删去这些映射将破坏此证明。

H_s停止只由候选真实Rain检查决定，且Rain挑战与辅助IC独立，不增加未观测E约束。因而上面的前缀结论适用于该停止前的所有已到达查询。

### 2.2 目标桶由历史挑选是否还能使用Bernoulli矩

给定当前前缀，已选(x,y)固定。若某key的x或y已被一个不相符单元占用，成员指标为0；已观测E_s(x)=y计入O；其余key各贡献成功率1/(M−m_s)的独立Bernoulli。由Σ_s m_s≤q0：

~~~text
E[Z | prefix]
 ≤ Σ_s [1/M+m_s/(M(M−q0))]
 ≤ 1+q0/[M(M−q0)].
~~~

它不依赖桶在过去如何选出。不同桶互相相关甚至完全相同，所以后续乘积矩使用Hölder，而非跨桶独立性。对Bernoulli和Z，下降阶乘矩≤λ_*^k，Stirling展开系数非负，给出Poisson矩上界；v≥1又覆盖空同com桶的D补项。这三点共同支持A3。

### 2.3 Source桶尾是否漏掉逆向或主动选输出

对固定的v+1个不同key、同(x,y)首次Source曝光位置，第一条给出目标值。后续正向调用只可能靠新y命中，逆向调用只可能靠新x命中；若指定端不符则概率0，符合时剩余分母至少M−q0。已经是旧Source行的重复读取不增加桶大小。依次条件并合给出：

~~~text
Pr[BadSrc(v)] ≤ min(1, binom(q0,v+1)/(M−q0)^v).
~~~

它无需额外M²因子，因为第一行已经选择了(x,y)。它也没有覆盖整张E所有未读桶，故δ_src和δ_u职责分开，δ_u仍付一次。

### 2.4 未来桶帽和最终伪造选择是否偷偷进入条件分布

A7的合法性来自分支拆分：

- 当前PrefixGood可由过去Source判断，直接在该固定前缀上用矩上界，再对χ₁取AU概率；
- 当前PrefixBad分支先固定整张E与过去历史，在G_u内用确定性C_U(u)，然后乘当前坏前缀的概率上界δ_src；
- 对每个可能H₁先建立这些界，再并合a₁次。最终伪造选择哪条链不进入前述采样条件。

第二分支使用G_u的是确定性族大小，不是在未来G_u条件下宣称剩余IC仍均匀。A5、A6与旧AU上界都是同一个AU事件（或它的超集）的上界，所以A7可取最小。算法只执行一条最终链的B_final不改变a₁并合。

### 2.5 系数与边界复核

逐项展开：

~~~text
½ Σ_t (Σ_(j in t) |B_j|)^2
 → (μ2/2)Σ_t N_t²

½(τ+Σ_(N/2 pairs) max(1,|B_j|)max(1,|B_k|))²
 → τ²/2 + τNμ2/2 + N²μ4/8.
~~~

μ2、μ4公式与v=2、4且λ=1的静态恒等值10/151、26/799一致。此处只有符号代数核对，没有执行数值扫描。

q0≥M回退旧AU；a₁=0时项为0；v为分析阈值，u仍限制实际算法和其他结构项。复核认可A7按这些条件接入。

## 3. CMA：E1—E8的事件和独立性

### 3.1 E1去重是按隐藏源，非按保护单元

完整虚拟普通轨迹不使用隐藏标签。固定它之后，所有L_i仍相互独立均匀。对每个源i，D_i合并所有输入端及F输出端候选数值key，事件正好为L_i∈D_i，得到：

~~~text
1−Π_i(1−|D_i|/M).
~~~

同一源r+1个保护单元同时被同一key触达，只需一次标签等式；不同源则保留不同随机变量。若将每个单元当成独立标签，乘积会错误；受审稿没有这样做。

标签输出不属于F，需L_i=K且L_j=y；符号图i≠j，普通轨迹也不依L_i/L_j，仍用q0QE/M²。E1没有遗漏该项。

### 3.2 E2正向F输出的两次匹配

F原始值包括未来可能建立的所有对象，预分配QF个槽并补独立未用槽，而不是只在最终被选择的对象上抽样。固定全部原始F与当前前缀，辅助E仍是普通剩余置换；自适应查询只造成已记录单元约束。

一条首次正向Source行的K、x在回应前固定；其新y命中某个固定F值的概率≤1/(M−q0)。隐藏源标签在整个普通轨迹给定后仍均匀，因此另付L_i=K的1/M。依次条件取期望即可乘出1/[M(M−q0)]。

关键反例排除：先用逆向查询指定y=F，再把同一行作正向缓存命中，并不获得一次新的随机y。受审稿把每个规范Source单元归属首次引入方向，因此这种行仍在逆向类支付u_y/M。

同样，先被私有Full读到的行以后才Source曝光，在无反馈边缘中仍按新Source处理。B_final实际先完成Source再做私有工作，更直接满足这一前提。

E2/E3中的p_forward、p_inverse若被读作实际随机轨迹次数，概率公式应取预设确定上限，或在对应逐步不等式中取次数的期望。E8已显式改用确定q_forward/q_inverse，因此本次合成没有该记号歧义。它是阅读口径，不影响E8固定式。

### 3.3 E4同对象重构的H_self

树t的每层d有2^d−1个非隐藏路径公开内部节点。每个节点的两次子扩展针对同一个隐藏内部源，不需付两次标签碰撞；公开叶的r+1个调用也针对同一个叶源。

逐树的公开组数为：

~~~text
Σ_(d=0..k_t−1)(2^d−1) + (N_t−1) + 1
 = (N_t−1−k_t)+(N_t−1)+1
 = 2N_t−1−k_t.
~~~

最后的1是零key洞承诺dummy。所有树求和给H_self=2N−τ−D。master根展开在公开重构中没有同地址组。即使数值公开seed彼此相等，并合只变宽；它们不读取隐藏标签，所以每个源组最多付1/M。

本次认可的是固定E4的H_self；没有接入另一个尚未固定的更强减项。

### 3.4 E6跨对象交叉

固定公开组B_p及保护源偏移X_i，输入相交要求IV_v−IV_j∈X_i−B_p。四lane模加法是群平移；可逐个偏移差并合。较晚对象生成前的历史已固定较早IV，原Bad4首次坏事件论证给较晚IV的任一指定点条件质量≤(κ+1)/M。

公共组数量与偏移只依参数和深度，原030不把叶位置编码进输入，因此它们不随隐藏洞编号产生额外自适应种类。接着在完整普通轨迹上给隐藏标签命中数值key另付1/M。按有序对象对并合得到E6；每个潜在差分可共享事件，并合允许多计。

~~~text
C_cross=Σ_p Σ_i |X_i−B_p|
 ≤ (Σ_p |B_p|)(Σ_i |X_i|)
 = AV J.
~~~

同对象公开组的实际单元数为：

~~~text
2(N_t−1−k_t)+(r+1)(N_t−1)+1
 =(r+3)(N_t−1)−2k_t+1,
~~~

求和正是原AV，因此C_cross=AVJ的保守选取与完整重构计数相容。

H4命中旧行使新IV并非独立均匀，κ与δ4均保留。攻击者普通输入和最终Verify输入也没有被当作另一独立签名IV，仍在u_x(aIC+AV)/M中支付。

### 3.5 E8是否覆盖所有原T11事件

按旧共同耦合分项核对：

| 原事件 | E8去向 |
|---|---|
| 普通—保护输入，攻击者和最终Verify | u_x(aIC+AV)/M与δ_x |
| 普通—保护输入，诚实同对象 | QH_self/M |
| 普通—保护输入，不同签名对象 | (κ+1)Q(Q−1)C_cross/M² |
| 普通—F输出，首次逆向 | u_y q_inverse/M与δ_y |
| 普通—F输出，首次正向 | q_forward QF/[M(M−q0)] |
| 普通—隐藏标签输出 | q0QE/M² |
| 同源保护输出重复 | Qv0/M |
| 不同源保护输出重复 | binom(QJ,2)/M² |
| 跨对象保护输入相交 | (κ+1)binom(Q,2)J²/M² |
| H4重输出尾 | δ4 |

同一δ4、δ_x、δ_y事件分别并合一次；没有因几处引用而重复付尾，也没有删除任何必要类别。最终Verify仍有全部AV调用。原program、grinding尾、HitKey与共同首次坏事件顺序保持，故E9对同一虚拟游戏旧T11与新E8取最小合法。

Q=0时Hide=0；q0≥M时回退原T11；只有完全禁用逆向时才可同时删逆向项及其专用δ_y。通用双向分析采用q_inverse≤aIC及q_forward≤q0，即使两者之和大于实际行数，也只使上界更宽。

成本稿允许舍去“有效K但W其他字段错”的旧额外成功，而把该W纳入非零e分支；这是正确的新归约论证。它没有把新旧成功事件强行等同。对B_final，实际只检查最终链W一次，但统计仍对所有历史H₂的非零e并合。

## 5. 接入B_final与结果表述

认可的组合方式为：使用同一个B_final及其全部实际资源，在F-ST中把AU旧项替换A7、把epsSim中的Hide替换E9，其余program/tail/chain/cap/Canon/Parent/Twin/ZHash/最终挑战项按旧接口保留。CheckW用实际关系乘法费用，H_s仍付不同K的完整forward检查。

后处理只求值最终一条链，而A7/E8均是Source游戏的统计界；Source无反馈删除原理在这里适用。所有a₁、a₂、a_Δ及最终Verify仍被统计预算覆盖。允许算法资源和概率上界的并合次数不同，原因已由逐个历史函数的挑战前固定性明确证明。

这项合成减少“用伪造者构造求逆者”的成本和附加证明误差。它不测得原030真实安全位数，也不独立建立Rain优势函数在这些实际资源处的上界。整体等强结论仍需根稿的完整证书及范围判断。
