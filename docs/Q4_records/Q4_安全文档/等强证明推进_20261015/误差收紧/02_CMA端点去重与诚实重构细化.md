# CMA 隐藏距离：按源去重、正逆首次来源及诚实重构

2026-10-15；C030-RFAEST128-TIGHT2；acceptance_gap_check。本文在原按 IC 单元的同一个虚拟签名游戏上收紧事件计数。它不修改真实 Sign/Verify、模拟器输出分布、Source 调度或 B 的实际工作。诚实重构的输出端点项可从一次概率降到两次匹配概率；同对象共享明文导致的输入端点项仍有真实的一次标签匹配，本文给出该项的按节点计数。

## 1. 记号与保持的游戏

M=2^128，Q 为新缓存对象数的先验上界，N=sum_t N_t，D=sum_t k_t。r=6/7，沿用

~~~text
J=2D+(r+2)tau，E=D+tau，F=D+(r+1)tau，
v0=binom(tau,2)+D+tau binom(r+1,2)，
AV=(r+3)(N-tau)-2D+tau，
q0=aIC+(Q+1)AV.
~~~

AV 的最后 tau 次零 key 洞承诺死读取保留。aIC 包括正逆攻击者调用；最终 Verify 的全部公开工作仍包含于 q0。本文先在没有 Ext 的普通 Source 边缘比较签名视图，再添加原来的无反馈私有读取。Full 缓存命中在首次 Source 提升时才进入本概率过程；实际外部调用和CPU仍按真实B另计。

每个新对象有 S=1+D+tau 个相互独立、均匀且可延迟抽样的符号源标签 L_i。所有保护单元有 (L_i,x_e,Y_e) 形式。非标签 F 类原始输出在虚拟表示中独立均匀，与普通 IC 族及 L_i 独立；它们包括公开兄弟种子、洞承诺、完整洞随机带块。标签输出是独立符号标签图中的有向边，保留单独计数。

以下概率论证不以隐藏标签碰撞或未来端点好事件为条件。普通轨迹包括非标签原始变量、公开重构、RO/签名选择及来源可测停止；这些计算不读取 L_i。

## 2. 引理 E1：同一源的端点命中精确合并

固定完整虚拟普通轨迹。对每个符号源 i，定义有限数值 key 集合

~~~text
D_i={K: 普通表含(K,x,y)，且
       x属于源i的保护输入，或y属于源i的F类保护输出}.
~~~

输入相交或 F 类输出相交恰是某个 L_i 落在 D_i。由于所有 L_i 仍独立均匀，条件概率精确为

~~~text
Pr[input-or-F-output hit | virtual ordinary trace]
 =1-product_i(1-|D_i|/M)
 <=sum_i |D_i|/M.                                      (E1)
~~~

同一隐藏源的 r+1 个叶单元若都由同一个公开 seed K 命中，只形成一个 L_i=K 事件。重复调用、相同 key 的重复端点和输入/输出同时命中也可以在 D_i 中去重。源编号须按同一个符号标签合并；把每个保护单元错当成独立标签将破坏乘积式。

标签输出相交仍要求 L_i=K、L_j=y 两个独立等式，i不等于j；因此原 q0 Q E/M² 上界继续适用。E1 没有删除这一类。

## 3. 引理 E2：只有首次逆向引入能主动选中 F 输出

把每个不同普通 IC 单元归属到它首次成为 Source 映射时的调用方向。设 p_forward 是首次由正向引入的单元数，p_inverse 是首次由逆向引入的单元数。诚实公开重构与最终 Verify 都只调用正向 AES。

在分析中预分配至多 QF 个独立原始非标签值；未被调用的对象只用作独立填充，不向对手公开。固定这些值及当前 Source 历史后，对任一首次正向引入的单元 (K,x)，K,x 已定，返回 y 在同 key 的剩余输出上均匀。普通IC的这一条件分布来自“F先独立抽取、公开子树正常查询”的原虚拟表示；实际pk-only模拟器可经既有三角双射产生同分布，无须知道私钥。

对每个 F 类保护输出 Y_e，先付 y=Y_e 至多 1/(M-q0)，再付独立源标签 L_i=K 的 1/M。因此在 q0<M 时，

~~~text
Pr[F-output hit from first-forward cells]
 <=p_forward QF/[M(M-q0)].                              (E2)
~~~

两次计费不依赖“未来没有冲突”；隐藏标签始终未反馈普通流程。相反，首次逆向查询可直接指定已见的 Y_e，故仍须用

~~~text
Pr[F-output hit from first-inverse cells]
 <=u_y p_inverse/M + delta_y,
delta_y=binom(QF,u_y+1)/M^u_y.                           (E3)
~~~

重复 Source 行按首次引入方向计；后来的逆向重放并不产生一条新的可控输出行。私有 Full 已先读取的单元不据此视为“旧 Source”：应删除无反馈私有读取，再在首次提升时采用普通剩余置换分布。

如先验预算分别为 a_forward,a_inverse，则

~~~text
p_forward <= a_forward+(Q+1)AV，
p_inverse <= a_inverse，
a_forward+a_inverse=aIC.
~~~

若只记录合计 aIC，可保守用 p_forward<=q0、p_inverse<=aIC。它们只是概率上界，不是减少 B 的调用数。若确有 a_inverse=0，则 (E3) 整项为零，也无须为这项额外支付 delta_y；双向通用模型保留它。

## 4. 引理 E3：诚实重构的同对象输入项按节点付费

固定一份新缓存对象。在树 t 深度 d，d=0,...,k_t-1，隐藏路径含一个内部源；公开重构在该深度有 2^d-1 个其他节点。每个公开节点的两次 AES 明文都属于同一个隐藏内部源的保护输入集合，故按 E1 只需一次 key 相等事件。公开叶有 N_t-1 个，每叶的承诺与 r 个带块同样只指向该树一个隐藏叶源。零 key dummy 的承诺单元每树再计一次。

master 的 tau 个根展开输入与公开重构地址不同；没有对应的公开 master 组。固定同 IV 下其他源输入互异，真实共享明文只发生在同树同深度或同树叶角色。于是每份诚实公开重构的自对象输入事件满足

~~~text
Pr[self input hit] <= H_self/M，
H_self=sum_t [sum_(d=0..k_t-1)(2^d-1)+(N_t-1)+1]
      =2N-tau-D.                                       (E4)
~~~

这里没有假定公开 seed 互不相等；相同数值 seed 只让上述并合更宽。公开节点 key 可由已知兄弟种子或普通 IC 回应产生，均不使用延迟隐藏标签，故 key 可能依赖普通历史而仍可付1/M。Q个对象合计 Q H_self/M。

这保留真实线性风险，但去掉按内部节点的两次调用、按叶的r+1次调用反复付同一个源标签相等事件。

## 5. 引理 E4：不同对象的输入交叉需另付 IV 匹配

取四lane模加法群。每个保护源 i 有固定偏移集合 X_i；其实际输入为 IV+X_i。把一份诚实重构分成第4节的公开源组 p，其偏移集合为 B_p。内部组有两个偏移，叶组有 r+1 个，dummy组有一个。偏移及每种组的数量只依冻结参数和树深，和具体隐藏叶编号无关，且

~~~text
sum_p |B_p|=AV，sum_i |X_i|=J，number_of_public_groups=H_self.
~~~

定义可有限核验的偏移差集合常数

~~~text
C_cross=sum_p sum_i |X_i-B_p| <= AV J.                   (E5)
~~~

一份对象v的公开组p与另一对象j的保护源i输入相交，只可能发生在 IV_v-IV_j 属于 X_i-B_p 时。保留原稿 Bad4 与首次坏事件顺序：较晚新对象的 IV 对任一指定值的条件质量至多 (kappa+1)/M。对应源标签与全部普通轨迹独立，再付1/M。对不同对象的有序对并合，得到

~~~text
Pr[cross input hit and no earlier Bad4]
 <=(kappa+1)Q(Q-1)C_cross/M².                           (E6)
~~~

可以直接使用较宽但不需新增偏移枚举的 C_cross=AV J。缓存复用不是新对象，沿用同一组标签/保护单元；不同对象偶然重复 IV 或不同 IV 发生lane抵消全部由 (E6) 覆盖。

攻击者普通行和最终 Verify 的输入并非独立新签名 IV，仍保留原重数界

~~~text
u_x(aIC+AV)/M + delta_x，
delta_x=binom(Q,u_x+1)J^(u_x+1)((kappa+1)/M)^u_x.         (E7)
~~~

最终 Verify 的 AV 不因“不向对手返回内部结果”而从接受事件比较中删除。

## 6. 新的完整隐藏模块上界

取正整数 kappa,u_x,u_y，Q>0且q0<M。令

~~~text
delta4=binom(h4,kappa+1)/M^kappa，
q_forward=a_forward+(Q+1)AV，q_inverse=a_inverse，
或只知aIC时保守取q_forward=q0、q_inverse=aIC。
~~~

把 E2/E3、自对象和交叉输入项与原有标签输出及保护—保护项合成：

~~~text
Hide_refined =
 [u_x(aIC+AV)+u_y q_inverse+Q(H_self+v0)]/M
 +(kappa+1)Q(Q-1)C_cross/M²
 +q_forward QF/[M(M-q0)]
 +[q0 Q E+(kappa+1)binom(Q,2)J²+binom(QJ,2)]/M²
 +delta4+delta_x+delta_y.                               (E8)

epsHide_new=min(1, Hide_refined, old_Hide_T11).            (E9)
~~~

old_Hide_T11 指原同一虚拟游戏的未截断表达式。同一坏事件的两个上界可取最小；这里没有更换 B。Q=0时隐藏距离仍为零；q0>=M时回退原T11。所有尾界按概率统一截断的约定不变。

旧T11的 u_y(Q+1)AV/M 已移入正向剩余置换的二阶项；诚实新签名的 u_x Q AV/M 变成 Q H_self/M 及跨对象二阶项。攻击者逆向和最终 Verify 输入项仍在。CMA的program、grinding tail、HitKey、共同IC/RO耦合顺序、ST的所有提取和链条误差均保持原接口。

## 7. 两个明确反例：哪些简化会失效

第一，整个公开重构输入项直接归零会漏掉实际端点不一致。四点局部置换例中，普通公开重构已有 (K=1,x=0,y=2)，隐藏源取L=1并要求保护单元0映到3。虚拟抽样对此赋正概率，但同一置换无法同时实现这两个映射。这个单源、单保护单元例子已经需要输入相交事件；在完整树里共享明文的公开叶或同层节点可以给出同类冲突。它只反驳当前耦合的漏项，未据此宣称一个完整低成本伪造。

第二，即使每个新 H_s 的 iv_pre=U 独立均匀，IV=H4(U)也不是跨签名独立均匀。取两个独立U、同一个随机函数H4，精确有

~~~text
Pr[H4(U1)=H4(U2)]=1/M+(1-1/M)/M=2/M-1/M².
~~~

它严格大于1/M。旧 H4 行的重输出还可提高条件点质量。因此本文保留 kappa、delta4、输入重数尾及lane差分集合；不把每个IV替换成独立新随机块。

## 8. 原T11在两参数组之间的一致支配充分条件

这是供 root 对照原030与EM128实例的纯算术引理，且只比较隐藏模块。设双方用相同aIC,Q,kappa,u_x,u_y，h4预算也相同。若 q_R<=q_E、J_R<=J_E、F_R<=F_E，令

~~~text
dE=max(0,E_R-E_E)，dv=v0_E-v0_R。
~~~

唯一可能上升的E项满足

~~~text
Q(q_R E_R-q_E E_E)/M² <= Q q_R dE/M².
~~~

因此 q_R dE<=M dv 足以由同源输出项 Qdv/M 的下降吸收它；q_R<=M且dv>=dE是一组简单充分条件。其余J/F重数尾和保护—保护项单调不增，截断到1保持支配。Q=0时双方隐藏距离均为零。

更精确地，可以直接检查

~~~text
(u_x+u_y)M(q_R-q_E)+QM(v0_R-v0_E)
 +Q(q_R E_R-q_E E_E) <= 0.                              (E10)
~~~

J/F项的下降可先忽略；若(E10)成立已足够。H1编程输入长度、g/G尾、其他ST分项、实际B成本及EM的相关IC原语条件都不由这一支配式解决。尤其隐藏分项更小不等于整个签名的实际工作因子已更大。

## 9. 研究状态与检查方式

本稿只进行数学推导、受审材料和真实地址映射的只读核对；没有运行密码实验、参数扫描、构建或跑分。E1是固定轨迹下的精确乘积式；E8给出可直接代入六组的保守新上界。若有限算术只使用 C_cross=AV J，无需额外扫描真实偏移集合。

独立反驳的重点是F预分配与普通剩余置换的联合边缘、Source首次方向、同对象节点组计数、H4条件点质量及最终Verify保留。B仍执行原AV和全部私有工作：本稿只收紧概率，不把数学去重记为程序加速或新签名算法。
