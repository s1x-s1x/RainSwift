## 2. 正确的条件分布：只看当前 Source 前缀

在虚拟签名游戏中删除全部无反馈的 Ext 私有读取。固定某次合规普通 H1 首次回应前的完整 Source/RO 历史及来源随机币；当前 H1 的新回应尚未抽取。Source 包括 A 正逆查询、模拟器公开重构及其已发生的其他普通读取；最终 Verify 也在全程 q0 上界中。没有把私有 Full 缓存的命中当作已免费公开：在带 Full 的实现中首次 Source 提升的行，正对应删除私有读取后来源过程首次获得该 IC 单元的时刻。

这个边缘过程只通过普通 IC 回应读取 E。pk-only 签名的程序行由独立模拟随机币、正常 Source 读取及已发生的 RO 回应生成；隐藏符号标签和私有提取结果不反馈源流程。H_s 成功停止是来源可测事件。因而固定这样的历史，只对每个数值 key 的置换施加它自己已经 Source 触达的映射约束。条件后的各 key 剩余置换相互独立，各自在剩余双射上均匀。正向和逆向请求都仅增加一条同样的映射约束；其方向不改变这个结论。

本结论不以“未来所有 Source 桶都不超 v”或“整张 E 满足 G_u”为条件。对手可依先前结果适应性选择 IV、承诺、树及当前 H1；给定当前历史后，它们已经固定。ST 的合规 H1 森林及 canonical 仍按既有解析和来源水位定义；未知或程序链由原 epsChain 隔离。

## 3. 引理 A：一个已选桶的未知部分

设当前选择的桶为 B(x,y)={s:E_s(x)=y}。令 O(x,y) 为其中已经 Source 触达的不同 seed 数。对其他 seed：已知 E_s(x) 不等于 y，或 y 已被同 key 的另一输入占用时，该 seed 的成员指标为零；其余指标是独立 Bernoulli，其成功率为 1/(M-m_s)，m_s 为该 key 已知的不同单元数。因此

~~~text
|B(x,y)|=O(x,y)+Z(x,y),
Z 为条件独立 Bernoulli 之和，
sum_s m_s <= q0 < M.
~~~

同一桶内的独立性来自不同 key。不同桶之间无须独立。

未知部分的均值满足更精确的统一上界

~~~text
E[Z | prefix] <= lambda_* = 1 + q0/[M(M-q0)].             (A1)
~~~

证明是对每个 key 使用

~~~text
1/(M-m_s)=1/M + m_s/[M(M-m_s)]
         <=1/M + m_s/[M(M-q0)]
~~~

并在所有 M 个 key 上求和。实际候选 key 只是其中子集。该界还保留了全部源预算；不是把 q0 替换成攻击者的直接调用数。

## 4. 引理 B：Source 全程桶尾

令 BadSrc(v) 为全程 Source 表中存在同一输入输出对 (x,y)，由 v+1 个不同 key 实现。v 为正整数，q0 为确定的全程来源调用上界。在 q0<M 时，

~~~text
Pr[BadSrc(v)] <= delta_src(v)
 = min(1, binom(q0,v+1)/(M-q0)^v).                       (A2)
~~~

把 v+1 条首次 Source 曝光的不同映射按曝光次序排列。第一行确定 x,y。以后每个命中行的 key 须不同于已选 key，且其单元此前尚未 Source 触达。若新调用为正向，指定输入须为 x，再由新随机输出命中 y；若为逆向，指定输出须为 y，再由新随机输入命中 x。指定端不匹配时概率为零，匹配时概率至多 1/(M-q0)。已经存在的普通缓存行没有产生新的映射；带私有 Full 的首次提升按第2节的无私有边缘计数。对所有 v+1 个曝光索引并合即得 (A2)。自适应调用、提前停止、同 key 的其他行均被 q0 和剩余集合下界覆盖。

这里直接并合“被 Source 实际发现的碰撞行组”，不再乘 M²。它与全 E 的 G_u 是不同事件；(A2) 不能取代整个 delta_u。

## 5. 引理 C：未知桶的矩及语义族对数

在当前 H1 可测事件 PrefixGood(v) 上，所有已选桶的 O 均不超过 v。因 v>=1，

~~~text
|B_j| <= v+Z_j,
max(1,|B_j|) <= v+Z_j.
~~~

独立 Bernoulli 和的 k 阶下降阶乘矩至多 lambda_*^k。以第二类 Stirling 数展开通常矩，得到 Z 的 p 阶矩至多 Poisson(lambda_*) 的 p 阶矩；本稿只用 p=2,4。定义

~~~text
mu2(v,l)=v^2+2vl+l^2+l,
mu4(v,l)=v^4+4v^3 l+6v^2(l^2+l)
          +4v(l^3+3l^2+l)+l^4+6l^3+7l^2+l.
~~~

故 E[(v+Z_j)^p | prefix]<=mu_p(v,lambda_*)。即使某些目标桶完全相同，或不同目标桶相关，广义 Hölder 不等式仍给出任意总次数为 p 的乘积的期望至多 mu_p。

用 ST 的实际全桶语义族，令 C_i 为第 i 次 H1 中需要排除的不同元素对数。以下都是全 E 固定后的确定性计数上界：

~~~text
|E_t| <= sum_(该树N_t个叶目标j) |B_j|,
|union_t F_t^+|
 <= tau + sum_(N/2个底层对(j,k)) max(1,|B_j|)max(1,|B_k|).
~~~

第二式的 max(1,·) 覆盖“两个 com 相同而桶空”的 D 补项；非空时 D 已由同 seed 抵消包括。它没有假设所有承诺都不同。

分别展开平方，舍去 binom(z,2) 中有利的负线性项，再用二阶或四阶 Hölder，得

~~~text
E[C_i | prefix, PrefixGood(v)] <= C_mom(v,q0),

C_mom = (mu2/2) sum_t N_t^2
        +tau^2/2 + (tau N mu2)/2 + (N^2 mu4)/8,           (A3)

mu_p = mu_p(v,lambda_*).
~~~

“prefix, PrefixGood”表示只在已固定前缀本就满足可测条件时使用此界；不是对未来好事件作条件化。

代数检查用例：当 l=1 时，v=2 给出 mu2=10、mu4=151；v=4 给出 26、799。这是公式恒等式，不是密码实验或真实安全位数。

## 6. 引理 D：AU 事件与两种合法尾项合成

固定当前前缀并进一步固定整张 E 后，当前 H1 的新 chi1 仍独立均匀，全部语义候选已固定。AU 性质逐对给出 epsV。先对 chi1 取概率、再对 E 的剩余置换平均，得到

~~~text
Pr[AU_i and PrefixGood_i]
 <= epsV E[C_i 1_(PrefixGood_i)]
 <= epsV C_mom.                                         (A4)
~~~

把所有 a1 次 H1 并合，若某次前缀坏则全程 BadSrc 发生，故可直接用

~~~text
Pr[any AU_i] <= delta_src + a1 epsV C_mom.               (A5)
~~~

还可以保留原 G_u，获得通常更强的加权尾项。在 PrefixBad_i 分支固定 E 与当前前缀；此时仍用新 chi1 的 AU 性质，而 G_u 内确定性的候选对数至多 C_U(u)。因此

~~~text
Pr[AU_i and G_u and PrefixBad_i]
 <= epsV C_U(u) Pr[PrefixBad_i]
 <= epsV C_U(u) delta_src.
~~~

这一步只使用 G_u 下的确定性族大小，不在 G_u 下重新采样剩余置换；PrefixBad_i 本身发生在当前 H1 回应前。好前缀分支直接用不以 G_u 为条件的 (A4)。于是

~~~text
Pr[(any AU_i) and G_u]
 <= a1 epsV [C_mom + C_U(u) delta_src].                  (A6)
~~~

结合原 ST 对同一事件的旧界，可在同一个 B、同一 G_u 上使用

~~~text
epsAU_new = min(1,
               a1 epsV C_U(u),
               delta_src + a1 epsV C_mom,
               a1 epsV [C_mom+C_U(u)delta_src]).          (A7)
~~~

这是同一事件的三个已证明上界取最小值，未把不同归约的 OWF 优势拼接。所有使用 G_u 的结构事件最终仍共同加一次 delta_u。

## 7. 接入 ST 与适用域

在原 ST 中仅将 a1 epsV C_U(u) 替换为 (A7)。epsSim、epsChain、delta_u、epsCanon、epsParent、epsTwin、a2 epsZ、(2aDelta+1)/M 及同一个 B 的 Rain 优势保持原接口。u 继续控制 Canon/Parent/Twin、K_vis 溢出分支、CPU 和空间；v 只分析 Source 前缀，不限制算法可见桶。

本引理使用 v>=1、q0<M。原 ST 的 q0<=M-3 和 d0+r-1<M 仍分别管相应结构分母。q0>=M 时回退原 AU 界，不把失效分母代入。a1=0 时 AU 项为零。有限核验可只比较预先选定 v=2、4；更换分析阈值须连同 delta_src 和完整其他项报告。
