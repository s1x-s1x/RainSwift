## 2. 最终选择：成功事件须从最终伪造直接推出

旧归约可能在某个最终未采用的H2获得正确Rain原像；B_final只执行最终伪造所指的H2。两者的全部成功事件并不相同。因此，仅以“私有工作无反馈”为由，把旧ST中的Adv(B_old)换成Adv(B_final)，不足以证明新定理。

受审稿第6节没有这样替换，而是为每个普通H2首次记录j定义潜在Phi_j。这一函数使用其旧H1/H2输入、两个Source水位、旧RO水位和固定E；它不读取本次χ2，也不依赖将来选中了哪个j。KnownU、canonical、桶帽分支和W都由这个旧函数确定。

定义每个j的ZHash坏事件时，可以在CheckW有效分支把该事件置空；无效分支的e(W_j)非零且在χ2_j前固定。因此该j的坏事件仍由epsZ界定，对全部a2个j并合。最终被选中的j依赖后续挑战，也仍包含于这些预先定义事件的并集；没有条件于“j最终被选中”后再主张χ2_j均匀。

在正确旧链、结构/AU/Twin坏事件均未发生时，最终有效伪造有三种分支：

1. 最终链known且CheckW通过：B_final实际重算该W，并输出有效Rain原像。
2. 最终链known且CheckW失败：e(W)非零，先由该历史H2的epsZ覆盖线性压缩抵消；排除后，原QS非零最高次系数论证给至多两个挑战根。
3. 最终链unknown：仍是完整KnownU搜索无命中；既有TwinUnknown论证给至多两个兼容Delta。

每个旧普通HDelta输入的目标集合仍在其首次回应前固定，保留2aDelta/M。最后Verify中的全新HDelta由签名已固定这一事实另付1/M。旧H1/H2缺失、程序行、逆时序与后来补链继续付epsChain。H_s公开成功仍立即输出，旧ST规定的私有成功仅缓存而不改变Source流程，这与本次删除所有私有工作并重放的耦合一致。

**因此，减少实际求值次数只减少资源；a1、a2、aDelta及Twin中的a2因子均保持。** Root的ST2正确沿用了这个最终事件包含，而非借用旧归约任意一次私有成功。

## 3. 历史水位与候选完备性

本次逐项挑战以下可能漏项，固定稿均作了明确处理：

| 反驳方向 | 固定稿中的处理及判定 |
|---|---|
| 用最终Full候选替换过去候选，令选择依赖χ1或χ2 | 成员资格只用s1/s2；Full仅提供同一固定E的数值 |
| H1后、H2前才出现的parent没有直接叶承诺Source行 | 该parent的两个child仍进入s2的K_vis；只有canonical资格受s1限制 |
| 找到一个canonical后提前停掉其他parent扫描 | 明确遍历所有s2前相关parent；未选parent也贡献child |
| 某历史行原来属于另一IV/另一角色 | 按选中森林的实际input匹配；原先调用的语义名称不影响资格 |
| 逆向IC来源被丢弃 | 正逆统一规范化为(K,x,y)，保留首次Source时间 |
| 私有补出的child继续生成新的Source根 | 明确禁止递归自举；所有根来自旧Source前缀 |
| 两次RO之间Source没有增长，误以为二者同一时刻 | 同时保存RO全局序号，s1=s2不替代严格RO先后关系 |
| Verify后新增Source或RO前像补出原来缺失链 | Verify仍计q0，但这些行不获得旧s1/s2/RO水位资格 |
| 同com空桶使D候选漏算 | 沿用KnownU显式D项，空桶也检查；不先假定桶非空 |

固定稿第4节与既有全桶语义稿第5节的KnownU伪代码一致：先A，再同com的D，再按固定pair顺序用左hash字典与右seed顺序查找，重复hash保留固定首个seed。这保持实际可计算候选的完备性。语义V只参与分析，真实归约为判定或输出Rain原像仅需W，故没有因省去V列而丢失所需计算。

## 4. 一个固定森林的IC成本上界

当前森林中C、T与底层父格输入互异。这来自冻结tweak的树余数、高lane结构/tape区分和低lane左右偏移；结论只针对同一个固定IV。不同IV的历史行依实际input重新归类，所以仍每行至多匹配一个当前角色。

令R_rel为s2之前落入这些地址的不同Source行数。直接C行不再取com；T来源的一个不同seed至多补一次com；一个去重后的parent至多补另一父格与两个child的com，共三次。因此

```text
n_T+3n_P ≤ 3R_rel ≤ 3q_anchor。
```

全部K_vis成员至多2R_rel。先将com分类、过滤、去重，再检查目标桶帽。若溢出，在tape读取之前停止。若未溢出，最多N个目标com桶各至多u个seed，故

```text
K ≤ min(Nu,2R_rel) ≤ min(Nu,2q_anchor)。
```

每个canonical child的父支持早于H1，所以该child已在H2的K_vis；匹配的com又保证其属于保留集合。这覆盖了全部canonical tape，没有遗漏一份独立的基线读取费用。

所有轨迹统一满足

```text
Q_priv ≤ 3q_anchor+r min(Nu,2q_anchor)，
P_final ≤ q0+Q_priv ≤ q0+(2r+3)q_anchor。
```

Rain-3/4的粗系数分别为15/17。溢出分支只有≤3q_anchor的com完备化费用，因此这个运行上界并不以未来G_u成立为条件。最终Source结束后才补Full缺失单元，可以去重已有值；上述式子保守计所有请求，正逆缓存都已包括。

Root合成稿第4节对nC/nT/nP的简写应按正式稿理解：父节点先按(tree,parent key)去重，每个描述符选其一条合资格Source支持行作代表；另一侧重复行不产生新根。这与其“总和≤q_anchor”及三次上界相容。

## 5. 真实CPU、关系检查与空间接口

固定稿的T_src已经包含A、模拟签名和最终Verify的普通IC/RO工作，额外只加Q_priv乘IC成本。P_final另作为查询预算坐标保留。Root合成稿也明确区分“普通工作已含IC”与“排除oracle费用的CPU向量”两种计账口径，未将二者叠加。

归约仍保留全部Source/RO日志和旧水位、哈希链解析、索引/排序、parent扫描、完整输入输出、VH缓存与候选查找。一次A_t聚合的NL位XOR不是总成本；a1/a2虽然不再乘实际森林求值，仍在RO日志、内存和概率并合中。

对已知完整W，CheckW检验各轮x_i y_i=1。通过推出各x_i非零、y_i为实际逆元和末轮公共输出关系；失败则e(W)非零。这恰好是最终事件分解所需的二分。只拥有K的H_s检测仍执行完整forward，不用CheckW费用代替。全套PSI初始化、成功输出映射、读写/比较/控制和缓存成本仍由正式稿单列。根合成稿当前固定版本进一步明确：本稿OWF目标须输出塔域K，所以成功分支实际支付PSI_INV；额外附带W不能代替这一输出费用。该澄清保持算法、概率式和资源公式。

本次认可的是有限可实施资源上界及接口。T_final中的大O常数尚非统一机器价格，15/17亦非总CPU放大率。实际签名实现和测量数据没有因此发生改变。

## 6. AU、CMA与ST2合成

B_final对Source的普通随机轨迹没有新增反馈。AU仍在每个历史H1前缀上分析全桶语义候选，故A7可以覆盖相同事件；K_vis的算法桶帽u和结构事件共用的delta_u仍保留。v只是矩分析阈值，不是更小的运行桶帽。好前缀矩不条件于未来G_u，重复桶用Hölder，空桶D用v≥1覆盖。

CMA端点式仍先在无私有提取的普通虚拟Source上比较签名视图。后置私有查询不会改变A、签名模拟或Verify接受事件的边缘分布；它们仍计真实OWF资源。E8保留输入、逆向、标签输出、保护—保护、H4/输入/输出重数尾，E9仅对同一隐藏事件取更小上界。程序冲突和grinding尾另外保留，Q=0时模拟距离为零。

记号上，E2/E3若p_forward、p_inverse指实际随机次数，概率右端须使用其确定上界或相应期望；E8和根合成稿已经使用预设的q_forward、q_inverse。通用总预算模式用q_forward=q0、q_inverse=aIC，因此实际ST2与R2公式没有这个随机上界歧义。

ST2保留epsChain、delta_u、epsCanon、epsParent、epsTwin、a2 epsZ和(2aDelta+1)/M，且OWF项绑定同一个B_final。Canon/Parent的q0≤M−3条件、Twin的剩余置换分母、AU与E8的q0<M条件均有失效回退。T12中的704/448、H1完整修正串熵和T13的grinding尾均与既有共同耦合一致。没有仅因求值一次而删除任何事件费用。
