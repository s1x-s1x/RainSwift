# 原030：最终伪造重放、收紧误差与同一个归约的资源

2026-10-15；`C030-RFAEST128-TIGHT2`；限额探索。本文合成新归约`B_final`、全桶前缀矩界和CMA端点细化，保留全部其余ST误差及真实计算费用。正式使用时同时核对本阶段交付清单绑定的独立审查版本。原030的Sign、Verify、参数和协议字节保持冻结。

## 1. 数学对象与假设范围

固定原030六组之一、一个公钥。使用经典前缀一致ROM、普通双向理想密码；辅助理想密码与真实拒零Rain公钥挑战独立。Rain求逆游戏接受给定(P,C)的任意有效密钥，要求所有逆元输入非零；它不是仅猜回生成时的原密钥。实际AES/SHAKE的理想化、Rain计算困难性与实现侧信道是不同层次。

沿用[既有ST](../%E5%85%B7%E4%BD%93%E7%95%8C%E6%8E%A8%E8%BF%9B_20261015/02_%E7%A2%B0%E6%92%9E%E5%AE%B9%E5%BF%8D%E8%A7%81%E8%AF%81%E6%8F%90%E5%8F%96%E4%B8%8E%E5%AE%8C%E6%95%B4%E6%80%BB%E7%95%8C.md)的全部RO预算及符号。令

```text
M=2^128，b=48，L=(r−1)128+b，r=6或7，
N=sum_t N_t，D=sum_t log2(N_t)，
AV=(r+3)(N−tau)−2D+tau，
q0=aIC+(Q+1)AV，q_anchor=aIC+Q AV。
```

Q是签名请求的先验上界，实际新缓存对象数可以更小。aIC计攻击者正逆IC调用总数；a1、a2、aDelta、a_s分别计相应RO域首次完整输入。来源包含模拟器公开重构及最后一次Verify；私有补查始终另计。u是结构/算法桶帽，v是新的AU分析阈值，κ、u_x、u_y是模拟分析阈值，三类不可混用。

## 2. 新的实际归约与原在线提取的关系

新归约的算法及完整证明见[最终伪造选择与按需提取](%E6%8F%90%E5%8F%96%E6%94%B6%E7%B4%A7/01_%E6%9C%80%E7%BB%88%E4%BC%AA%E9%80%A0%E9%80%89%E6%8B%A9%E4%B8%8E%E6%8C%89%E9%9C%80%E6%8F%90%E5%8F%96%E5%BD%92%E7%BA%A6.md)。核心步骤如下：

1. 正常模拟A、pk-only签名及所有来源RO/IC。每个合规普通H1/H2记录不可变输入、Source首次曝光水位及RO历史水位；过程尚不运行私有提取。公开H_s合法密钥检测仍在回应前执行，成功立即输出。
2. 收到最终伪造后运行完整Verify。未接受、非新消息或落入没有旧历史链的分支，依原接口处理；新的最终链和末次挑战仍由原epsChain及1/M项收费。
3. 对最终有效伪造指向的那一个旧普通H2，按它自己的旧H1/H2切口重放确定性提取。canonical的支持资格仅来自H1前Source父格；H2候选池仅来自H2前Source。未来Full缓存值可以正常用于读取同一E的值，未来Source或RO记录不获得历史资格。
4. 先补承诺并过滤，再为匹配的不同(tree,seed)读取tape；桶帽溢出在读取这些tape前私下返回失败。按原固定次序做VH线性查找，得到同一个潜在f和W=d xor f[0:ell]，或返回unknown。
5. 对唯一选中的W做[乘法关系核验](%E6%88%90%E6%9C%AC%E5%88%A4%E6%8D%AE/01_Rain%E7%B2%BE%E7%A1%AE%E6%93%8D%E4%BD%9C%E8%AE%A1%E6%95%B0%E4%B8%8E%E5%85%AD%E7%BB%84%E8%AF%81%E4%B9%A6%E8%BE%B9%E7%95%8C.md)。对本稿固定的密钥输出OWF游戏，通过后付一次PSI逆映射并输出塔域K；若另外要求完整见证，再同时输出已知W并计入输出费用。H_s仅有K的检测仍使用完整forward。

**为何延后计算仍保留挑战前固定性：**在分析中预先抽取整张E。对每个旧普通H2，按其当时前缀定义潜在的f_i、W_i及known/unknown。这是该前缀和E的确定函数，在该次新χ2回应前已固定；实际求值时间不改变函数值。这个整张E只用于概率分析，实际B照常付费读取有限单元。

最终选择的H2可以依赖所有后来挑战。论证不对“事后选中i”再条件化并声称χ2均匀，而是保留原来对全部a1/a2/aDelta次查询的事件并合：最终已知W有效则实际B输出；最终已知W无效则进入该查询的非零约束/ZHash/挑战坏事件；unknown则进入原Twin或至多两点挑战分支。这是对最终有效伪造逐点重写成功/坏事件包含，未把旧“所有私有缓存都未成功”直接替换成新的失败事件。

旧在线PPT提取器及其审查继续保留。B_final用于完整EUF-CMA到Rain求逆的归约，实际提取发生在最终输出后；本稿未将它登记成新的在线Ext。

## 3. 完整附加误差

在各结构分母有效的域内，定义

\[
\begin{aligned}
\epsilon_{new}={}&\epsilon_{Sim,new}+\epsilon_{Chain}+\delta_u
 +\epsilon_{Canon}+\epsilon_{Parent}+\epsilon_{AU,new}\\
 &+\epsilon_{Twin}+a_2\epsilon_Z+(2a_\Delta+1)/M.
\end{aligned}
\]

则新归约的条件结论为

\[
\boxed{\operatorname{Adv}_{030}(A)\le
\min\{1,\operatorname{Adv}_{Rain}(B_{final})+\epsilon_{new}\}.}
\tag{ST2}
\]

此处OWF项属于真实B_final。旧在线B或较宽资源球的优势不直接替换为这一项；也未将它置零。

### 3.1 新模拟项

采用[端点细化稿](%E8%AF%AF%E5%B7%AE%E6%94%B6%E7%B4%A7/02_CMA%E7%AB%AF%E7%82%B9%E5%8E%BB%E9%87%8D%E4%B8%8E%E8%AF%9A%E5%AE%9E%E9%87%8D%E6%9E%84%E7%BB%86%E5%8C%96.md)E8/E9。令

```text
J=2D+(r+2)tau，E=D+tau，F=D+(r+1)tau，
v0=binom(tau,2)+D+tau binom(r+1,2)，
Hself=2N−tau−D，Ccross≤AV J。
```

若只知正逆总预算，保守取q_forward=q0、q_inverse=aIC。Q>0、q0<M时，新的未截断隐藏界为

\[
\begin{aligned}
H_{new}={}&\frac{u_x(a_{IC}+A_V)+u_yq_{inverse}+Q(H_{self}+v_0)}M\\
&+\frac{(\kappa+1)Q(Q-1)C_{cross}}{M^2}
 +\frac{q_{forward}QF}{M(M-q_0)}\\
&+\frac{q_0QE+(\kappa+1)\binom Q2 J^2+\binom{QJ}2}{M^2}
 +\delta_4+\delta_x+\delta_y.
\end{aligned}
\]

取epsilonHide_new=min(1,H_new,H_oldT11)。δ4/δx/δy仍按原公式支付；编程与grinding仍完整保留：

\[
\epsilon_{Sim,new}=\min\left\{1,\epsilon_{Hide,new}
+Q\left[\frac{h_1}{2^{L(\tau-1)}}+\frac{h_2}{2^{704}}+\frac{h_\Delta}{2^{448}}\right]
+Q(1-2^{-g})^G\right\}.
\]

Q=0取整个模拟项为0；q0≥M时退回旧T11。G为正4倍数且≤2^32，所有实际grinding原始调用仍计入hDelta。原输入端点和攻击者逆向项留存：同对象公开叶共享AES明文，存在真实的一次隐藏标签匹配，未把所有诚实重构风险都删成二阶。

### 3.2 新AU项

使用[前缀桶矩稿](%E8%AF%AF%E5%B7%AE%E6%94%B6%E7%B4%A7/01_%E5%85%A8%E6%A1%B6AU%E7%9A%84%E5%89%8D%E7%BC%80%E6%A1%B6%E7%9F%A9%E7%95%8C.md)A1–A7。对v≥1、q0<M，令

\[
\lambda_*=1+\frac{q_0}{M(M-q_0)},\qquad
\delta_{src}=\min\left\{1,\frac{\binom{q_0}{v+1}}{(M-q_0)^v}\right\}.
\]

二阶/四阶矩μ2、μ4是该稿给出的(v+Poisson(lambda_*))矩多项式；定义

\[
C_{mom}=\frac{\mu_2}2\sum_tN_t^2+\frac{\tau^2}2
+\frac{\tau N\mu_2}2+\frac{N^2\mu_4}8,
\]

\[
C_U(u)=\sum_t\binom{N_tu}{2}+\binom{\tau+Nu^2/2}{2}.
\]

取同一事件的已证上界之最小值：

\[
\epsilon_{AU,new}=\min\{1,\ a_1\epsilon_V C_U,
\ \delta_{src}+a_1\epsilon_V C_{mom},
\ a_1\epsilon_V(C_{mom}+C_U\delta_{src})\}.
\]

好前缀只在当前H1可测的Source历史上取剩余置换矩，未条件于未来全程好事件。坏前缀的加权尾通过先固定E、再对新χ1用确定性族帽得到；不是直接相乘两个相关坏事件概率。相同桶的相关性由Hölder处理，等com空桶补项也保留。若q0≥M则回退旧AU；a1=0时为0。

### 3.3 其余项原样保留

\[
\delta_u=\min\{1,M^2/(u+1)!\},
\quad\epsilon_{Canon}=\min\left\{1,\frac{q_0(q_0-1)u^2}{(M-q_0-1)(M-q_0-2)}\right\},
\]

\[
\epsilon_{Parent}=\min\left\{1,\frac{a_1Nq_0u^2}{2(M-q_0-1)(M-q_0-2)}\right\}.
\]

Canon/Parent要求0≤q0≤M−3，失效时对应项取1。Twin仍为原来的

\[
a_2u^4\sum_{t<s}(N_t/2)(N_s/2)\,
\min\left\{1,\frac{M/2^b}{\prod_{j=0}^{r-1}(M-d_0-j)}\right\},
\quad d_0=q_0+3\tau+r(\tau-1),
\]

其剩余分母条件失效时内部概率取1。epsilonZ=1/M+(R−1)^2/2^192，R为Rain轮数。epsChain的Hc/Hmu/H1/H2碰撞与新链项完全沿用ST。Gu相关结构事件共同支付一次δu；本稿未借AU收紧删除它。

## 4. 同一个B_final的IC上界

最终只物化一个森林。其H2切口前每条Source行在真实冻结地址下至多属于一种相关C、T或底层P角色。记各类根数nC,nT,nP，其和≤q_anchor。

- C根已经含com；T根补一次com；P根至多补另一孩子和两孩子com，共3次。
- 对实际森林目标com先过滤并按(tree,seed)去重。每个C/T根至多产生一个seed，P根至多两个；所以候选数≤2q_anchor。
- 每桶超过u就私下返回；否则不同匹配seed数也≤Nu。canonical孩子也在这个池中，全部选中seed每个至多读取r个tape块。

因此这一个明确算法同时满足

\[
P_{private}\le3q_{anchor}+r\min\{Nu,2q_{anchor}\},
\]

\[
\boxed{P_{full}\le q_0+3q_{anchor}+r\min\{Nu,2q_{anchor}\}
\le q_0+(2r+3)q_{anchor}.}
\tag{P2}
\]

这比旧逐Source根所有角色补齐的q0+(138或174)q_anchor更紧。数值小仅表示这一归约的IC调用上界下降，不等于原030签名加速，也不等于总CPU放大率等于P2中的系数。

## 5. CPU、IO、空间与关系核验仍收费

记录所有历史RO输入和Source水位、维护索引、运行pk-only签名和最终Verify的工作都仍存在。令T_source包括A及全部普通RO/IC、签名重构和Verify的真实费用，但不含新增加的私有提取、H_s检测和管理索引。则额外IC费用只加P_private乘每次IC成本；若改用排除IC费用的非oracleCPU向量，再统一加P_full即可，二者不要同时重复收费。

选中森林的A_t由全叶基线异或得到，至多NL个bit-XOR；V只用于证明，无需再构造k_max列。候选D_t,i的VH值可由VH线性组合获得；实际重建一个命中的f最多再用4L个bit-XOR。仍应支付选中seed tape读取、VH计算、按承诺/哈希值排序和字典查找，相关访问与比较不因函数线性而免费。

对完整W的CheckW只需R次GF(2^128)乘法、R−1次128维线性映射、2R+1次128位异或和R次等于1比较。它在本归约至多执行一次。H_s只有K的不同候选仍按完整Rain forward检查，次数至多a_s；Rain3/4完整forward分别有297/396个源级CLMUL调用，其他位运算、矩阵、读写和控制流另计。这些是源级操作向量，未转换成虚构的CPU周期。

全部Source/Full表、RO输入及程序行、历史水位、tape/VH缓存、字典和原A/模拟器工作空间继续纳入Gamma_final。精确计费接口见[提取资源稿](%E6%8F%90%E5%8F%96%E6%94%B6%E7%B4%A7/01_%E6%9C%80%E7%BB%88%E4%BC%AA%E9%80%A0%E9%80%89%E6%8B%A9%E4%B8%8E%E6%8C%89%E9%9C%80%E6%8F%90%E5%8F%96%E5%BD%92%E7%BA%A6.md)与[Rain成本稿](%E6%88%90%E6%9C%AC%E5%88%A4%E6%8D%AE/01_Rain%E7%B2%BE%E7%A1%AE%E6%93%8D%E4%BD%9C%E8%AE%A1%E6%95%B0%E4%B8%8E%E5%85%AD%E7%BB%84%E8%AF%81%E4%B9%A6%E8%BE%B9%E7%95%8C.md)。

## 6. 这条定理能支持什么判定

ST2给出更紧的完整经典条件归约，P2与全部CPU/空间共同限定其真实资源。给定一个有依据且与枚举相容的Rain优势上界H_Rain，以及明示的共同成本/成功率标尺，充分认证条件仍是

\[
H_{Rain}(\Gamma_{final}(A))+\epsilon_{new}(A)\le p_{ref}(A).
\]

参考作者没有规定唯一的机器成本曲线，故本稿未把某个额外默认p_ref冒充用户标准。原语优势上界需针对实际拒零分布、包括公开代数电路计算，并在这个实际归约的资源处使用；将它设为零、仅数某个Rain API调用或以已知昂贵攻击推断困难性下界，都不构成该证书。

下一步的数值合成只改变受审的两项误差和归约资源；有限算术核验、内部独立审查以及原语困难性假设分别登记。整体等强状态由本阶段主判定单独报告，未从一个局部改进或有限模型检查数直接推出。
