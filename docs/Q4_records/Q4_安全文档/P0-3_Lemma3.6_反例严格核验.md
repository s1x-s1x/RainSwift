## 二、区分器与合法性

**A1（单块）：**

1. 调用一次 Get(tree, i)，得到 (iv, y₀‖y₁)。
2. 计算 x₀ = iv⊕⟨i,0⟩。
3. 对 M = Q_P 个两两不同的猜测密钥 g，各做一次正向查询 E_g(x₀)。
4. 若有某个 E_g(x₀) = y₀，输出 b′ = 0；否则输出 b′ = 1。

**A2（双块）：** 每个猜测固定做两次查询 E_g(x₀)、E_g(x₁)，所以 M = ⌊Q_P/2⌋；两块都等才输出 b′ = 0。

| 检查项 | 结论 | 依据 |
|---|---|---|
| Get 是否返回 iv | 是 | Def 3.3：Get 返回 (iv, y) |
| x₀ 能否算出 | 能。⟨i,a⟩ 是公开的 λ 位编码，i 由 A 自己选 | p.6 |
| 输出块有无掩码 | 无。F_tree^ctr 直接输出两块 E_s 值 | p.6 |
| A 能否用任意密钥查询 P | 能。P 是理想分组密码 E，Q_P 统计的就是对 E 的查询 | p.6 |
| 查询计数 | A1：Q_I = 1，Q_P = M = 2^100 次正向查询。A2：每个猜测 2 次，M = 2^99。本地计算量不计入 Q_P | — |
| 前提 Q_I·N + Q_P ≤ 2^{λ−1} | 满足（N ≤ 2^12 时 2^12 + 2^100 ≤ 2^127） | Lemma 3.6 |
| \|iv\| = \|com\| = λ | 满足（λ = 128，AES-128） | Lemma 3.6 |
| 自适应、重复 | A1 不需要自适应；猜测密钥两两不同；输入 x₀ 固定、不重复（同一输入配不同密钥） | — |
| 是否用了逆查询 | 没有 | — |

## 三、概率与严格不等式

记 p = M/2^λ。

**A1 的成功概率。** 真世界中，k 均匀，落在猜测表里的概率是 p，此时必然命中。若 k 不在表里，表中每个 E_g(x₀) 是不同密钥的置换在 x₀ 上的值，相互独立且均匀，与 y₀ 无关，所以

Pr[b′=0 | b=0] = p + (1−p)(1 − (1−2^-λ)^M)。

理想世界中，y₀ 均匀且与 E 独立，所以 Pr[b′=0 | b=1] = 1 − (1−2^-λ)^M。

两式相减得 Adv(A1) = p·(1−2^-λ)^M，这是精确值，不是近似。

**A2。** 真世界成功概率 ≥ M/2^λ。理想世界中，每个猜测两块同时命中的概率 ≤ 1/(2^λ(2^λ−1))，所以 Adv(A2) ≥ M/2^λ − M/2^{2λ}。

**λ = 128 的数值（mpmath，200 位精度）。** Adv(A1) = 2^-28.000000；Adv(A2) ≥ 2^-29.000000。Lemma 3.6 的完整上界（三项之和）如下：

| ℓ | q = ⌈ℓ/λ⌉+3 | Lemma 3.6 上界 | Adv(A1) | 附录 B 修正界 |
|---|---|---|---|---|
| 688（我们的 ℓ̂） | 9 | 2^-121.660 | 2^-28.000 | 2^-27.000 |
| 1,384（rFAEST-EM-128f） | 14 | 2^-120.385 | 2^-28.000 | 2^-27.000 |
| 8,192（VHash 前提 ℓ̂ ≤ 2^13 的上限） | 67 | 2^-115.868 | 2^-28.000 | 2^-27.000 |
| 2^20 | 8,195 | 2^-101.999 | 2^-28.000 | 2^-27.000 |
| 2^40 | ≈ 2^33 | 2^-62.000 | 2^-28.000 | 2^-27.000 |

**严格不等式。** 对任意 ℓ ≤ 2^40，有 q < 2^34，所以

Lemma 3.6 上界 < 2^68/2^128 + 2^68/2^256 + 2·2^100·2^34/2^256 < 2^-59。

而 Adv(A1) = 2^-28·(1−2^-128)^{2^100} ≥ 2^-28·(1−2^-28) > 2^-28.0001。因此 Adv(A1) > 2^31 × 上界。

要让原式不被违反，需要 q ≳ 2^50，即 ℓ ≳ 2^57 位，远超任何有意义的参数（VHash 引理本身要求 ℓ̂ ≤ 2^13）。所有量的计量方式一致：Q_P 计理想原语查询，Q_I 计 Get。

## 四、原证明中的缺口位置（初判）

附录 F 的坏事件 (ii) 要求 s_i = k_j 且 u_i = iv_j⊕⟨a_j,c⟩。原文把这两个条件按各自概率 2^-λ 相乘，得到 2^{-2λ}。但 iv_j 由 Get 返回给 A（Def 3.3），A 可以在看到 iv_j 之后把 u_i 设成 iv_j⊕⟨a_j,c⟩，第二个条件就以概率 1 成立。所以每次查询的真实概率约为 2^-λ，而不是 2^{-2λ}。

这是我们对缺口位置的解读：原文没有逐行说明这个乘积的理由。无论缺口具体在哪，第三节的反例都独立成立。

F^dm（p.19）的证明有同构的坏事件，那里的密钥 iv⊕⟨i,a⟩ 是公开的，界也是 2Q_I·Q_P(⌈ℓ/λ⌉+3)/2^{2λ}。F^dm 与 F^ro 都有同类区分器：前者比较 E_{iv⊕⟨i,0⟩}(g)⊕g 与 y₀，后者比较 H_tree(g, iv, i) 与 y。优势都约为 Q_P/2^λ。这两种我们只做了推理，没有模拟，因为本作品只用 F^ctr。

## 六、独立反驳复核

复核方式：交给一个独立审查者，只给论文 PDF 和待检命题，不给本文的结论与推导，要求它专门寻找攻击不合法、原式漏项、概率算错、接口理解错误这几类问题。结论是 **CONFIRMED**，要点如下。

1. **A1 合法。** p.5 写明攻击者「can make oracle queries to P at most Q_P times」、「Get(f,i) returns (iv, y)」，没有查询顺序的限制；Q_P 只计攻击者自己的查询；F^ctr 中「set the seed as a secret key」；附录 F 允许 E 与 E⁻¹ 两个方向。
2. **概率正确。** 它独立算得 2^-28.000000005，A2 ≥ 2^-29。它自己做的玩具复现：λ = 12、M = 256，A1 实测 0.0587 ± 0.0023，A2 实测 0.0315 ± 0.0010，而原式只有 0.0040。
3. **与完整界的比较正确。** 三项分别为 2^-121.66、2^-249.66、2^-151.83；直到 ℓ ≈ 2^57 原式才达到 2^-28；Q_P = 82 时就已被违反。
4. **找不到挽救办法。** iv 在签名里也是公开的（Alg. 4 第 25 行）；「keys revealed at the end」只会帮攻击者；原式只在「每个原语查询都先于它针对的那次 Get」时才成立，而论文没有写这个限制。
5. **附录 F 的界没有推导。** F^ctr（p.18）的坏事件正是 A1 在 c = 0 时触发的那个，概率至少 M/2^λ。F^dm（p.19）同构，其界甚至没有 q 因子。F^ro（p.17）把公开的 iv 当成了秘密。
6. **F^ro、F^dm 同样被攻破。** 审查者的玩具复现：F^ro 0.0608 ± 0.0014，F^dm 0.0585 ± 0.0023，都远高于 0.0040。

审查者给的一处措辞更正已采纳：Adv^prg 是对攻击者取最大值，所以准确说法是 Adv^prg ≥ Adv(A1) = p·(1−2^-λ)^M。附录 B 的修正界另由第二个审查者核对，结论是「正确，需补几处」，补充内容见附录 B 第七节。
