## 1. 固定对象、模型与游戏

一次实验固定一个参数集 P 和一个公钥。六组分别适用；源码没有参数集域标签，本文不声称六参数共享公钥/预言的联合多协议安全。参数和字节序以 [00b](Q4_%E9%87%8D%E5%81%9A_00b_%E5%85%AD%E7%BB%84%E5%8F%82%E6%95%B0%E8%A1%A5%E5%85%85%E6%98%A0%E5%B0%84.md) 为准。

记 λ=128、M=2^λ、B_bytes=6、b=48、Rain 轮数 R∈{3,4}、见证长度 ℓ=Rλ、L=ℓ+2λ+b、r=ceil(L/λ)=6/7。第 t 棵树高 k_t、叶数 N_t=2^{k_t}，N=Σ_t N_t，D=Σ_t k_t=λ−g，g 是 grinding 零位数。W 表示见证，避免与旧参数表的 w 混用。

理想分组密码是独立的 λ 位置换族 {E_K}，允许正向和逆向查询。记录规范化为 `(方向,K,x,y,首次建立时刻,本次调用时刻,调用者)`。正向/逆向都落到同一 `(K,x,y)` 行；同 key 的输入与输出分别唯一。攻击者、提取器、签名模拟器、最终验证器的调用均计费。

SHAKE 模型为**一个按完整输入串索引的无限随机位串预言**。末字节 01/03/04/08/09/0A/0B 分隔角色；同输入的不同输出长度必须是同一位串的前缀。两层 01 聚合仍共用一张表，合法输入长度区分角色。攻击者首次以任意输出长度触达格式合规的 09/0A 输入时，归约先执行相应钩子、内部预留协议所需完整输出，再返回所请求前缀；后续补长没有新快照或新挑战。所有域统一采用首次触达预留：即使只请求短前缀或零长度返回，按完整输入末字节为 H_c/H_μ/H_s 预留 2λ 位、H₄/H_Δ 预留 λ 位、H₁ 预留 L₁ 位、H₂ 预留 L₂ 位。格式不合规的同域输入也普通采样并计费，只有合规 H₁/H₂ 触发提取钩子。其他输入照常保持同输入前缀一致。完整预留值进入归约的内部反查索引，未请求部分不向 A 透露；后续补长沿用该值。额外输出尾部按需独立延长，首次输入一次计费，预留采样、输入/输出长度和读取工作另计入时间。

记 H₁=H₂¹、H₂=H₂²、H_Δ=H₂³；H_s 是源码另一个 H₃（秘密前缀派生），二者不混用。H₁/H₂ 输出长度分别 L₁=5λ+64=704 位、L₂=3λ+64=448 位。

**EUF-KO：**从冻结 KeyGen 得到 (pk,sk)，仅给 A 公钥、上述普通 RO 和 IC；A 输出 (msg,σ)，用冻结 Verify 判定成功，无签名 oracle。**EUF-CMA：**另给 A 指定 deterministic 或 randomized 模式的真实签名 oracle；输出消息未被签过且 Verify 接受才成功。本文先给提取接口，03 在同一归约内模拟签名并隔离编程行，不把编程模拟器直接当普通 EUF-KO 对手。

Rain OWF 游戏由冻结 KeyGen 采样公钥 `(pt_T,ct_T)`；B 需输出 K_T，使真实 Rain_K(pt)=ct 且所有轮的 S 盒输入非零。KeyGen 本来拒绝零输入，这不属于新增缩密钥空间。任意合法原像均算成功，不要求恢复唯一原密钥。本文明确使用带独立辅助理想密码的游戏：IC 置换族与 KeyGen 的随机数及公钥挑战独立，B 获得普通正/逆 IC 访问，并在本地为 A 模拟及编程随机预言。挑战者仅按上述 Rain 关系验原像，不给 B 秘钥、陷门或 IC 编程权限。03 的优势记为 Adv^{OWF,IC}_{Rain}(B)，严格 PPT 和查询成本均相对此 IC 模型定义；此处未把它等同于普通无 oracle Rain 假设的同价优势。将后者换入时，须另处理辅助随机结构的模拟时间及任何截断损失。04 确认前，本文不会把这项单向性条件当作已证明的具体位数。

## 2. 源码事实与合法提取时序

对固定 IV，令 X_iv(c,z)=iv⊞(c,0,0,z)，⊞ 是四个小端 32 位 lane 的模加法。叶 j 的 seed s 是 AES **密钥**：

\[
com_{t,j}=E_s(X_{iv}(0,(k_t+1)\tau+t)),\quad
m_{t,j}=\operatorname{prefix}_L\left(\mathop{\Vert}_{c=0}^{r-1}E_s(X_{iv}(c,2^{31}+t))\right).
\]

完整根/树调用链、角色 tweak 和末块截断见 00b §§3–4。同树全部叶承诺共享明文；`small_tweak` 在当前实例化中被忽略。本文按实际 `(x,y)` 对建立索引，处理这种共享。

| 时刻 | 当时可用输入 | 尚未产生的值 | 提取器行为 |
|---|---|---|---|
| 首次 H₁ 输入、回复前 | μ、h_com、c、iv；过去 RO/IC 行 | chall1、chall2、Δ、open | 两层反查承诺，冻结唯一种子和 tape |
| 首次 H₂ 输入、回复前 | chall1、ũ、全部 Ṽ 列、d；原快照 | chall2、最终 Δ/open | 分类 free/fixed，固定 u*、V*、W* |
| H_Δ 每次查询 | chall2、ã、声明的 b̃、ctr | 当前 H_Δ 回答 | 只做已固定目标/多项式的随机命中分析 |
| 最终签名与验证 | σ 中的 Δ、open、iv_pre、ctr | 无 | 检验此前快照对该开示的覆盖；不回填旧见证 |

实际哈希输入分别为

\[
\begin{aligned}
X_1&=\mu\Vert h_{com}\Vert c_1\Vert\cdots\Vert c_{\tau-1}\Vert iv\Vert09,\\
X_2&=chall1\Vert\tilde u\Vert\widetilde V_0\Vert\cdots\Vert\widetilde V_{127}\Vert d\Vert0A,\\
X_\Delta&=chall2\Vert\tilde b\Vert\tilde a\Vert ctr_{LE32}\Vert0B.
\end{aligned}
\]

X₁ 未直接包含叶向量。所有反查仅检索已有 RO 行，不求哈希原像。碰撞、迟到前像、逆时序及最终未查询 H_Δ 的概率由 02 单列。

## 3. H₁ 快照：可执行伪代码

维护输出到输入的 RO 索引、`(x,y)→keys` 的 IC 索引、按**完整 X₁/X₂ 输入**缓存的快照与提取记录。Signer 编程行单独标记；该钩子只用于攻击者首次触达的普通行。

```text
BeforeFirstH1(X1):                         // 尚未透露任何 chall1 前缀
  parse X1 as (mu,hcom,c[1..tau-1],iv); c[0] = 0
  A = old Hc inputs of length 32*tau+1 with output hcom
  if |A| != 1: cache bottom_hash; return
  parse A as (h[0],...,h[tau-1],0x01)
  for t = 0..tau-1:
    B = old Hc inputs of length 16*N[t]+1 with output h[t]
    if |B| != 1: cache bottom_hash; return
    parse B as (com[t,0],...,com[t,N[t]-1],0x01)
  for all (t,j):
    target = (X_iv(0,(k[t]+1)*tau+t),com[t,j])
    register target with current timestamp
    K[t,j] = all keys in old IC rows matching target
    if |K[t,j]| > 1: cache bottom_pair; return
    known[t,j] = (|K[t,j]| == 1)
  freeze the entire known/unknown array
  for all known positions (t,j), in lexicographic order:
    m[t,j] = prefix_L(concatenate r ordinary forward IC tape queries)
  for each complete tree t:
    U[t] = XOR_j m[t,j]
    V[t,b] = XOR_(j_b=1) m[t,j]
    a[t] = U[t] XOR c[t]
  cache immutable snapshot
  return                                  // 随后才抽样/透露 H1 回答
```

早退 `bottom_hash` 时，分析器仍登记已有根摘要及可解析内摘要的迟到命中目标；它不为缺失承诺虚构叶目标。记录这些目标无需查询预言。若补齐 tape 对别的快照触发坏事件，仍按 02 计费。当前快照的已知集合在补齐前已冻结，后来的新记录不升级它。

**普通附加读取的非干预性。**在实验开始时选定所有 E_K，提取器仅提前读取确定位置，不改变这些置换或给 A 新答案。投影到 A 的可见查询/回答与没有这些读取时一致。Lazy sampling 只是延迟揭露同一置换，适用于自适应正/逆读取。该耦合不允许人为设定 IC 答案；新增 rN 次调用仍增加预算与坏事件数量。

## 4. H₂ 提取与每列正确性

固定相应 H₁ 快照、χ=chall1 和源码线性函数 VHχ:{0,1}^L→{0,1}^{λ+b}。H₂ 输入中的 d 有 ℓ 位，ũ 与每列 Ṽ 有 λ+b 位。最后 λ−D 列在真实协议中为零；输入非零时返回 `bottom_format`。

### 4.1 完整树

令 `a_t=U_t⊕c_t`。对任何隐藏索引 β=Σ_b β_b2^b，真实重构的第 b 列为

\[
q_{t,b}(\beta)=\bigoplus_{j:(j\oplus\beta)_b=1}m_{t,j}\oplus\beta_bc_t
=V_{t,b}\oplus\beta_ba_t. \tag{1}
\]

被隐藏项的系数为零。此式适用于任意恶意 c_t，不预设诚实关系。设

\[
T_t=VH(a_t)\oplus\tilde u,\qquad
E_{t,b}=VH(V_{t,b})\oplus\widetilde V_{t,b}.
\]

验签形成同一 X₂，当且仅当全部 `E_{t,b}=β_b T_t`：

* T=0 且每个 E=0：free，所有 β 都满足叶级哈希式。
* T=0 且某 E≠0，或 T≠0 且某 E∉{0,T}：不相容，返回 `bottom_non`。
* T≠0 且全部 E∈{0,T}：fixed，唯一 `β_b=1[E_b=T]`。

### 4.2 不完整树

恰一片未知叶 j₀ 时，只允许隐藏 j₀；其他可开示叶 tape 均在快照中。计算

\[
q_{t,b}(j_0)=\bigoplus_{j\ne j_0:(j\oplus j_0)_b=1}m_{t,j}\oplus(j_0)_bc_t. \tag{2}
\]

若全部 `VH(q_{t,b})=Ṽ_{t,b}⊕(j₀)_bũ`，记 fixed、β=j₀；否则 `bottom_non`。这里没有恢复洞 tape。若未知叶至少两片，返回 `bottom_non`；在 02 两个 IC 坏事件的补集，一个洞不足以隐藏两个未知位置。

### 4.3 输出规则

```text
BeforeFirstH2(X2):                         // 尚未透露 chall2 的任何前缀
  find the unique earlier ordinary H1 record and its immutable snapshot
  if missing/ambiguous: cache bottom_hash; return
  classify each tree by 4.1 / 4.2; reject incompatible/padding cases
  if no free tree:
    cache bottom_fixed and Delta_star = concat(beta[t]) || 0^g; return
  t0 = smallest free tree index; u_star = a[t0]
  if a[t] != u_star for another free tree: cache bottom_AU; return
  for each active column (t,b):
    if t free:  V_star[t,b] = V[t,b]
    if t fixed: V_star[t,b] = q[t,b](beta[t]) XOR beta[t]_b*u_star
  set remaining lambda-D columns to 0
  W_star = d XOR u_star[0:ell]
  cache (u_star,V_star,W_star), then answer H2
```

每次重复 X₂ 复用第一次记录；不会利用后来 IC 行或后来 Δ 改写结果。若全为 fixed，本算法严格返回 ⊥，不输出任意 u=0 的伪成功。Δ_star 仅用于计算其后命中的概率。

至少一棵 free 树时有 `VH(u*)=ũ`；对 free 列 `VH(V*)=Ṽ`，对 fixed 列由式 (2) 和线性性亦得同式。对**所有**与该记录相容的后续真实开示，逐列成立

\[
q_c=v_c^*\oplus\Delta_cu^*,\qquad
Q=V^*\oplus u^*\Delta^T. \tag{3}
\]

free 列用式 (1)，fixed 列必须使用缓存的 β，故由定义成立；非活跃列三项均为零。式 (3) 覆盖全部 L 个有意义行，未把列存储尾部当协议信息。

## 5. 成功伪造的覆盖，不要求任意查询易提取

在 02 的哈希链事件补集，最终开示对应的两层承诺向量与 H₁ 快照完全相同。在 `¬PairCollision∧¬LateHit` 下，任一最终打开叶的 seed 已在快照唯一匹配：若 `(x_com,com)` 原未知，其首次匹配触发 LateHit；若原已对应另一个 seed，则两把 key 给同 `(x,y)`，触发 PairCollision。最终验签补做的 IC 查询也在事件范围内。

这同时覆盖 seed 来自迟到父节点、其他树输出或 tape 输出的情形。无需递归枚举所有可能把输出用作 key 的闭包；实际打开叶最终仍必须经过该完整承诺行。树拓扑只缩小叶级可开示集合，本算法分析一个超集即可。

故在有效伪造上，缺两叶、不相容或错误尾列均排除；剩余返回失败只有：不同 free a_t 的 VHash 碰撞、所有树 fixed 的唯一 Δ 猜中，或已单列的坏事件。A 完全可以大量提交无效 H₂ 输入使 Ext′=⊥，本文不给这种无条件失败事件小概率界。

## 6. QuickSilver 到 Rain 原像

源码定位：[quicksilver.hpp:307](../../../src/quicksilver.hpp#L307)、[quicksilver.hpp:521](../../../src/quicksilver.hpp#L521)、[quicksilver.hpp:563](../../../src/quicksilver.hpp#L563)、[rain_constraints:754](../../../src/owf_proof.inc#L757)。

把 V* 转置，每行作为 F=GF(2^λ) 元素 M_i。验签前 ℓ 行加上 d 后，由式 (3) 得

\[
K_i=M_i+\Delta W_i^*\quad(i<\ell),\qquad
K_i=M_i+\Delta u_i^*\quad(\ell\le i<\ell+\lambda). \tag{4}
\]

用不定元 X 代替 Δ。`rain_combine` 只做固定 GF(2) 线性组合；公共常量在一次表达式中乘 X。每个源码 `x_i*y_i+1` 验证约束因此为

\[
f_i(X)=A_{i,0}+A_{i,1}X+e_iX^2,\quad
e_i=x_i(W^*)y_i(W^*)+1. \tag{5}
\]

W* 与整个 e 在 H₂ 回答前固定。H₂ 的线性组合键将各系数分别哈希为 Z₀、Z₁、E。记 η₀ 是 V* 的下一 λ 行按多项式基合成的 mask，η₁ 是 u* 对应 λ 位，则真实 `qs.verify` 的检查值为

\[
b'(X)=Z_0+\eta_0+(Z_1+\eta_1+\tilde a)X+EX^2. \tag{6}
\]

H_Δ 输入中 ã、声明 b̃ 固定后，如果 E≠0，方程 `b'(X)=b̃` 最多有两个域根。02 给出错误 e 被 H₂ 哈希为零的概率及每次原始 H_Δ 查询的根命中界；不对已经通过 grinding 的条件分布误用 2/M。

若 W* 的全部 e_i=0，源码每轮 `x_i y_i=1` 使 x_i 非零且 y_i 恰是其唯一逆元。W* 的首 λ 位是多项式基下密钥，后 R−1 组是逆元输出，末轮 `y_{R−1}=ct⊕K`。依次代入冻结线性层、轮常数和公钥，得 Rain_K(pt)=ct。逆向固定可逆基映射得到塔域 K_T；用真实公钥关系再核验后输出。无需猜 sk，也无需等待最终伪造才检查已提取候选。

## 7. PPT 与明确计费

当前源码只有 λ=128 六个有限实例。渐近算法复杂度另针对如下显式族：λ 是 64 的倍数，R=O(1)，ℓ=Rλ，b≤λ 且为字节倍数，k_max=O(log λ)，τ≤λ，g=O(log λ)，Σk_t=λ−g。于是 N≤λ·2^{k_max}=poly(λ)，r=O(1)。IC 扩展为 λ 位 key/block；角色编码随 λ 用足够位数编码，保持固定 IV 下注入性，不能把固定 32 位字段声称对无限 λ 足够。Rain 关系是给定的多项式大小约束族；本文不另声称构造了或证明了所有 λ 的 Rain 实例。

64 位辅助哈希在该族保留 64 位键；data 含 n_64=(ℓ+λ)/64 个系数，02 的一般根数因子使用 n_64−1。在 λ=128 时才是 2(R+1)−1。所有系数和次数均多项式有界，所列统计项随 λ 消失。

每个首次 H₁ 至多增加 rN 次 IC 查询；两层输出索引仅查已有哈希行，种子索引最多 N×P 次朴素比较；XOR/列和计算 O(N k_max L) 位操作。每个 H₂ 只做线性哈希、逐列比较及拼接，无新增 IC 或全局 2^D 枚举。存储上界 O(a₁NL+a₂λL) 位加 oracle 表，时间为输入长度、a₁、a₂、P、N、λ 的多项式。

沿用 02 的 a₁：对应 H₁ 末字节域的全部首次完整输入次数上界，包含不合规、短前缀及零长度返回的查询；合规提取钩子触发数至多 a₁。Q_sig 为签名请求上限；一次模拟仅调用一遍公开重构与 QS 验证。00b 的实际 Verify AES 次数为

\[
A_V=(r+3)(N-\tau)-2D+\tau.
\]

最后的 +τ 是随后丢弃的零 key 洞承诺调用，也包含在表中。理论归约的总 IC 调用可取

\[
P\le a_{IC}+rNa_1+(Q_{sig}+1)A_V. \tag{7}
\]

其中 a_IC 同时计 A 的正/逆查询；+1 是最终验签。实际测试额外多次 Verify 的成本单独记录，不从理论归约预算消失。签名缓存只减少运行，不在先验上界擅减 Q_sig。

归约每个首次触达的完整 H_s 输入至多检查一次 Rain 原像，重复输入及 XOF 补长复用已判结果，每个成功输出的 W* 最多再检查一次；最多 a_s+a₂ 次公开关系计算。03 给出每次签名的多项式 grinding 截断和统计尾项，从而整个 B 为严格 PPT；这个截断属于模拟器及证明耦合，不改变冻结 Sign。
