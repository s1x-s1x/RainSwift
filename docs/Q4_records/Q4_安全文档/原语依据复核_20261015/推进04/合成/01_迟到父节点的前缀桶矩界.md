# 迟到父节点：前缀桶二阶矩与加权尾界

2026-10-15；推进04；root。分类：静态局部证明改进，待独立反驳审查。原030六组、Sign/Verify/KeyGen、SALT归约的实际算法及资源均沿用冻结版本。

本稿为同一迟到父节点事件给出新的概率上界，保留旧ST2及本轮针对旧公式的证书障碍。新界没有改变协议，也没有证明完整签名与rFAEST等强。

## 1. 固定输入、事件与范围

沿用[整列Genie证明](../../../%E5%85%B7%E4%BD%93%E7%95%8C%E6%8E%A8%E8%BF%9B_20261015/%E5%85%B1%E4%BA%AB%E5%9C%B0%E5%9D%80/04_%E8%BF%9F%E5%88%B0%E7%88%B6%E8%8A%82%E7%82%B9%E7%9A%84%E6%95%B4%E5%88%97Genie%E7%95%8C.md)第1—7节的模型与事件，以及[AU前缀桶矩](../../../%E7%AD%89%E5%BC%BA%E8%AF%81%E6%98%8E%E6%8E%A8%E8%BF%9B_20261015/%E8%AF%AF%E5%B7%AE%E6%94%B6%E7%B4%A7/01_%E5%85%A8%E6%A1%B6AU%E7%9A%84%E5%89%8D%E7%BC%80%E6%A1%B6%E7%9F%A9%E7%95%8C.md)第2—6节的Source过滤族、剩余置换与桶尾。

这些前提包括：经典前缀一致ROM；各key独立的双向均匀理想密码；辅助IC与真实Rain挑战独立；私有Full读取对Source没有反馈；合规H1切口的IV、实际承诺对和树由该切口前Source/RO历史固定；公开重构及最终Verify也计入Source上界q0。若H1序号不存在或链不合规，事件取空。哈希链缺失等情况仍由既有epsChain处理。

设M=2^128，0≤q0≤M−3，a1为普通H1首次查询上限，N=Σ_t N_t。令

~~~text
den=(M−q0−1)(M−q0−2)>0。
~~~

固定一个H1切口i和树t。父两输入x0、x1与承诺输入xC两两不同。切口前两条父行都未被Source触达的key组成P_i,t^0。去重后的有序实际承诺对集合为T_i,t，其大小l_i,t≤N_t/2。L_i,t表示：某个p∈P_i,t^0在切口后至少一次作为Source查询key被触达，且

~~~text
(E_{E_p(x0)}(xC), E_{E_p(x1)}(xC))∈T_i,t。
~~~

L=∪_{i,t}L_i,t覆盖真实有效开示中的迟到父节点事件。它不引用私有候选池、canonical标签或私有成功状态。

G_u仍是整张IC所有(x,y)桶宽≤u的全域事件；旧delta_u=min(1,M²/(u+1)!)仍在总归约外部共同支付一次。本稿的目标是Pr[L∩G_u]的可替换上界，不删除G_u或其算法桶帽u。

## 2. 可测的前缀事件与已有二阶矩

定义PrefixGood_i(v)：切口i前Source表中，每一输入输出对(x,y)由至多v个不同key实现，v≥1为分析整数。它对该切口历史可测。任一PrefixBad_i(v)发生均蕴含全程BadSrc(v)，故已有引理给出

~~~text
δsrc(v)=min(1,binom(q0,v+1)/(M−q0)^v)，
Pr[BadSrc(v)]≤δsrc(v)。
~~~

v只用于分析；它与实际提取器桶帽u不同，也可以与AU的分析阈值分别选择。

固定一份满足PrefixGood_i的完整Source/RO前缀H。对任一已经由H选定的桶B(x,y)={s:E_s(x)=y}，分解

~~~text
|B(x,y)|=O(x,y)+Z(x,y)，O(x,y)≤v，
λ*=1+q0/[M(M−q0)]，
E[Z|H]≤λ*。
~~~

不同key的剩余置换条件独立，所以Z是独立Bernoulli之和，且

~~~text
E[|B(x,y)|²|H]≤μ2，
μ2=μ2(v,λ*)=v²+2vλ*+λ*²+λ*。
~~~

对任意两桶，无需声称两者独立。条件Cauchy–Schwarz直接给出

~~~text
E[|B(x,y0)||B(x,y1)||H]≤μ2。                    (PM1)
~~~

相同目标、重合桶或跨桶相关性均受此式覆盖。这里没有条件化于未来BadSrc不发生或G_u成立。

## 3. 去掉全域桶帽的整列Genie点态界

对这一个固定(i,t)，条件于前缀H，只向分析器揭示完整一列C(s)=E_s(xC)。记B_C(c)={s:C(s)=c}。

旧Genie证明在首次post-cut任意key触达前，揭示该key的两条父行；其余key的剩余置换仍条件独立。对尚未揭示的合格key p，两条父输出在剩余m_p个值中均匀无放回，m_p≥M−q0−1。对于一个目标(c0,c1)，精确概率为

~~~text
(ab−c)/(m_p(m_p−1))
≤|B_C(c0)||B_C(c1)|/den。
~~~

a、b是两桶与p的剩余输出集合的交集大小，c为交集重合项。该式对每一具体C成立；不需要桶宽≤u。数值key/seed别名、自指、逆向调用和旧行重访仍按旧Genie同一方式处理。

每个新候选key先消耗一个post-cut Source调用槽，总数至多q0。对自适应触达次序逐步并合，得到

~~~text
Pr[L_i,t | H,C]
≤min(1, q0/den · Σ_(c0,c1∈T_i,t) |B_C(c0)||B_C(c1)|)。
                                                               (PM2)
~~~

这里Σ按T_i,t的有序目标对求和。T_i,t已由H固定；它没有在看到完整C后重新选择。对每个(i,t)分别建Genie，最后对原游戏的边际事件并合，没有一次免费揭示多列后再声称所有父行新鲜。

## 4. 对完整列平均：直接尾界

固定满足PrefixGood_i的H。先用(PM2)逐点界，再对C的剩余分布平均，并应用(PM1)，得

~~~text
Pr[L_i,t|H]≤q0 l_i,t μ2/den。
~~~

因此

~~~text
Pr[L_i,t∩PrefixGood_i]≤q0 N_t μ2/(2den)。        (PM3)
~~~

若L发生，要么相应前缀好，要么全程BadSrc发生。对i,t并合并支付一次后者：

~~~text
Pr[L]≤min(1, δsrc + K μ2)，
K=a1 N q0/(2den)。                              (PM4)
~~~

(PM4)甚至没有使用G_u；故它也是Pr[L∩G_u]的上界。a1=0或q0=0时L为空，下节最终式的旧零项会自动给出零，亦可显式设该项为零。

## 5. 当前列包含关系给出的加权尾界

对坏前缀不使用未知桶矩。令CGood_i,t表示该一列所有桶宽≤u。G_u⊆CGood_i,t。固定H,C且CGood_i,t成立时，(PM2)给出

~~~text
Pr[L_i,t|H,C]≤q0 l_i,t u²/den。
~~~

PrefixBad_i由H决定，故

~~~text
Pr[L_i,t∩G_u∩PrefixBad_i]
≤Pr[L_i,t∩CGood_i,t∩PrefixBad_i]
≤q0 N_t u²/(2den) · Pr[PrefixBad_i]
≤q0 N_t u² δsrc/(2den)。                       (PM5)
~~~

这不是把相关事件L和PrefixBad的概率直接相乘。乘法来自对每个坏H、每个合规C都成立的同一个条件上界；先对C逐点限制，再积分。G_u只通过包含关系出现，从未加入剩余置换的采样条件。

好前缀分支用(PM3)去掉G_u后上界；两分支及所有i,t合并：

~~~text
Pr[L∩G_u]≤min(1, K(μ2+u²δsrc))。               (PM6)
~~~

## 6. 与旧ST2、SALT及有限本地IC桥组合

结合旧同一事件上界min(1,Ku²)，得到本稿唯一替换项

~~~text
εParent,mom =
 min(1,
     K u²,
     δsrc(v)+K μ2(v,λ*),
     K[μ2(v,λ*)+u²δsrc(v)])。                  (PM7)
~~~

同一个a1,q0,N,u,v、同一底层随机对象和同一SALT实际算法同时满足这几个上界，所以取最小值没有混接不同归约的资源。参数v允许独立于AU的分析参数；每个选择须连同δsrc支付。

在[ST2总归约](../../../%E7%AD%89%E5%BC%BA%E8%AF%81%E6%98%8E%E6%8E%A8%E8%BF%9B_20261015/02_%E5%AE%8C%E6%95%B4%E6%94%B9%E8%BF%9B%E5%BD%92%E7%BA%A6%E4%B8%8E%E8%B5%84%E6%BA%90%E8%B4%A6.md)中仅以(PM7)替换旧εParent，所得附加误差记为εST2,PM。其余Sim、Chain、δu、Canon、AU、Twin、Z、末次挑战项保持原式。全域δu仍共同支付一次；没有将δsrc作为事件独立性前提。

推进03的私有随机盐、有限m核验及L次有界置换本地模拟于是给出

~~~text
Adv_sig,rand(A)
≤min(1, Adv_plainRain(C_L,m)
        + εST2,PM(A) + δcap(Q,a_s,m) + δperm(F,L))。
                                                               (PM8)
~~~

这里引用[推进03完整同一归约证书](../../%E6%8E%A8%E8%BF%9B03/%E5%90%88%E6%88%90/03_%E5%90%8C%E4%B8%80%E5%BD%92%E7%BA%A6%E7%9A%84%E5%AE%8C%E6%95%B4%E8%B5%84%E6%BA%90%E4%B8%8E%E5%85%AD%E7%BB%84%E8%AF%81%E4%B9%A6.md)。m、L及该稿的字长、arena、管理/核心/IO/RNG/空间都保持同一实际程序的计费；(PM7)没有新的算法步骤。Genie没有在真实归约中枚举M个key，因此也没有隐藏的免费实际表构造。

q0≥M−2时，原结构分母失效，Parent继续取平凡上界1；本稿不在失效域延伸公式。无任何密码实验或算术程序用于证明本稿。
