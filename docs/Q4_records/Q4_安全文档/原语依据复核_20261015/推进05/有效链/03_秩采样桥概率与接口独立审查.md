## 2. 双向表、空端点与秩选择

T_F按(K,x)存y，T_I按(K,y)存x。未命中正向时在T_I选择未用y；未命中逆向时在T_F选择未用x。两次插入使用同一新映射，且期间不给B控制权。只要调用入口的不变量成立，每个答复结束后两张表继续互为正逆索引。

计数是已完成映射叶数。新插入的两条路径各自从根到叶计数加1，已有映射不再增加计数。深度128节点给该key的n；n=M时每个端点均已存在，所以未命中分支自然排除s=M−n=0。端点为0及叶value为0均有效，存在性用非零节点指针判断。

SelectUnused只在固定key后的128层使用容量2^h。进入每层时rank小于当前空叶数；左空叶数为2^h−usedLeft，右侧是余下空叶。两个分支分别保持rank范围，最终到达一个未用端点。这个过程实现未用端点升序与秩的双射。

以下边界都被实际程序覆盖：

- key尚无节点时，整棵后缀子树为空，选择过程中保持虚拟空节点即可。
- 左子树满时freeLeft=0，rank自然走右；右侧选择后减左空叶数，仍在有效范围。
- 只剩一个端点时s=1，rank恒为0，并找到该端点。
- 选择和只读查找不分配新节点；只在成功插入时分配、清零并链接。
- 每个key最多M个映射的计数需要129位；本机256位字容纳它。程序没有试图在一字中表示整个256位键域的2^256个叶容量。

这些性质不依赖请求是公开、私有、正向还是逆向，也不需要假设key不重复。

## 3. 固定384位抽样的精确距离

设D=2^384、s=M−n在1到M之间。每读一个新比特，将旧余数j变为2j+bit，数值严格小于2s；最多减一次s就恢复0≤j<s。因此流式程序严格计算384位均匀整数U模s，中间量小于2^129，未调用免费大整数取模。

写D=as+r，0≤r<s。前r个余数各有a+1个原像，其余各有a个。相对均匀s点分布的正、负偏差绝对和各为r(s−r)/(sD)，故总变差距离恰为：

~~~text
d_s = r(s−r)/(sD) ≤ s/(4D) ≤ 2^-258.
~~~

SelectUnused为双射，所以从rank映射到未用端点后距离保持。s=1和s=M都整除D，实际误差为0。固定384步是有限最坏运行帽，既没有无限拒绝抽样，也没有漏列拒绝终止尾项。

## 4. 自适应耦合与先验帽

比较两个世界：精确普通双向IC懒采样世界，以及C_rank的近均匀有限表世界。把真实Rain挑战、B的其他私币和RO管理随机性相同地耦合；IC内部取样通过逐次最大耦合连接。

在首次分歧之前，两边B状态、下一请求、key、方向及两张完整映射表一致。缓存命中产生相同答复；新映射时两边s相同，单步条件分歧概率至多2^-258。未用端点的精确均匀选择恰是普通IC的条件分布，任意自适应正逆请求都符合这一点。

若fbar是整个执行所有可能轨迹的新映射数帽，首次分歧并合给：

~~~text
TV(完整执行分布) ≤ min(1,fbar·2^-258).
Adv_IC(B) ≤ Adv(C_rank)+min(1,fbar·2^-258).
~~~

该帽涵盖预处理、模拟、Verify及私有提取；它按新映射计数，缓存命中不加抽样误差。p为所有请求帽时取fbar=p始终保守。一次实际运行观察到较小f，或只统计Source曝光数，都不足以替换这个先验帽。

两边首次分歧之后没有要求继续保持表相同；总变差界已覆盖由该分歧引起的所有后续行为变化。因而这个证明没有在最终成功条件下再假设新答复均匀，也没有把不同坏事件的概率相乘。

## 5. Full/Source与ST2的接口

用于s=M−n的n必须是完整物理IC表中该key的映射数，包含私有查询。新稿第2节明确了这一点。Source只记普通来源的曝光及水位，原B继续维护这些标签；本地抽样器不提升一条私有行的Source身份。

两张新模拟索引为B的全部查询共享同一个E。原B自身的Full缓存、Source历史、RO旧输入、Checked及盐上下文保持。对Full缓存命中而后来由Source普通读取的行，来源记账仍按原B执行；缓存是否触发新物理抽样是另一件事。

首现条件矩、Genie、Canonical、AU及其他ST2事件仍在精确IC世界证明。然后对整个B的输出事件应用一次上述耦合损失。这是C8所采用的顺序；没有把近均匀抽样表直接代入要求精确独立置换的旧事件公式。

P03的同一个B_salt,m有全部请求帽：

~~~text
F = q0 + 3q + (R+3)min(Nu,2q).
~~~

它与m无关，包含全部普通和私有请求。新桥取fbar=F，将新增RAM、384F随机位、代码装载IO及双表空间加入同一个归约截距，m斜率保持原SALT的CheckKey/Checked费用。这与P03完整合成中的F、V0、V1、R0、I0及S0all接口一致。

应用本轮已审Parent界后，C8保留其余ST2误差、一次delta_u、delta_cap及本桥delta_rank。旧C_L的V_IC和delta_perm不再混入这条新算法；旧桥作为另一条完整历史路径保留。
