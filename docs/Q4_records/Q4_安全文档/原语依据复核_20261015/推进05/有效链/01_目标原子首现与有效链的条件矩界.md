## 2. 可测的目标原子与首次出现

每个可解析旧H1切口i，依冻结的两层Hc历史解析器，从该切口前的Source/RO日志恢复叶承诺列表。解析只使用旧水位，采用预定的歧义处理顺序，不借最终开示补造旧Hc前像。

“可解析”在当前前缀决定；它不是条件于未来整条伪造通过。未来碰撞、后来补链或错误旧链仍由既有epsChain处理。缺少旧Hc材料的H1不产生本节原子。

对树t及某个底层有序承诺对(c0,c1)，定义

~~~text
x0 = IV ⊞ (0,0,0,k_t·τ+t)，
x1 = x0 ⊞ (1,0,0,0)，
xC = x0 ⊞ (0,0,0,τ)，
α = (x0,x1,xC,c0,c1)。
~~~

⊞是四个32位lane上的分别加法。固定参数组下τ固定，所以xC已决定x0、x1；原子也可简记(xC,c0,c1)。保留三地址写法便于对照既有Genie证明。

以下情况都按相同原子处理：同一列表内重复的有序值对、同IV/com的不同μ或c、跨H1复用，以及不同树标签恰好给出相同实际地址与值对。位置名和树编号不另加重复收费。只凭h_com相同仍不足以认定原子相同，因为IV可能变化。

令σ_α为α第一次在上述可解析H1前缀出现的切口，严格位于该次χ1回应或预留之前。一个H1同时引入多个新原子时按预定字典序排号。这个先后顺序对Source/RO过滤族可测，最多引入a1 N/2个原子。

记s_α为σ_α之前的实际Source调用次数，包含重复、正向、逆向及公开重构，且

~~~text
r_α=q0−s_α。
~~~

r_α是该前缀可测的剩余调用槽上界。它不是最终被选中的父key数，也不使用未来成功状态。

在σ_α定义

~~~text
P_α^0={p:(p,x0)及(p,x1)均无此前Source记录}，
F_α(p)=(E_{E_p(x0)}(xC),E_{E_p(x1)}(xC))。
~~~

L_α表示存在p∈P_α^0，σ_α之后Source至少一次将p用作任意IC调用的key，并且F_α(p)=(c0,c1)。正向、逆向、旧行重访、模拟器及最终Verify都属于触达。

### 引理1：同原子的后来迟到事件被首次事件覆盖

若同一原子在后来切口i再次出现，且p在i前两条父行均无Source，则p在更早σ_α前也没有这两条父行。因此P_i^0⊆P_α^0。i之后触达p也属于σ_α之后触达；匹配函数F_α和有序承诺对没有变化。

所以逐条完整轨迹都有

~~~text
L_{i,t,目标对α} ⊆ L_α，
全部切口的L并集 ⊆ ⋃_α L_α。                       (A1)
~~~

实际最终有效伪造的迟到Parent只使用其中一些原子，因此也被右侧覆盖。这里没有条件于“α最终被选中”，也没有把首次出现当作事前固定地址。

## 3. 按真实Source占用计算条件矩

固定一个σ_α处的完整Source/RO前缀H。令

~~~text
o_c(H)=#{s:Source已在输入xC记录E_s(xC)=c}。
~~~

同一个key的重复查询只计一次；逆向回答规范化后同样计入。此处不读私有Full标签。对实际目标记o0=o_c0、o1=o_c1。

将完整承诺列桶分解为B_c=O_c+Z_c。O_c=o_c固定；Z_c由各个尚未在xC记录Source行的key贡献。条件于H，各key剩余置换独立。若某key此前已有d_s条不同映射，其当前输出取指定尚未用值的概率至多1/(M−d_s)。

Σ_s d_s≤s_α，故对任何目标c都有

~~~text
E[Z_c|H] ≤ λ_α，
λ_α := 1+s_α/[M(M−s_α)] ≤ λ*，
λ* := 1+q0/[M(M−q0)]。                            (A2)
~~~

推导是把每个未定key的1/(M−d_s)写成1/M+d_s/[M(M−d_s)]，再用总曝光行数上界。若s_α=0，则λ_α=1。

### 引理2：有序双输出使用交叉矩或阶乘矩

当c0≠c1时，同一个key在同一xC只输出一个值，因此该key对两个桶的随机指示互斥；不同key剩余置换独立。于是

~~~text
E[Z_c0 Z_c1|H]
=E[Z_c0|H]E[Z_c1|H]−Σ_s Pr[I_s,c0=1|H]Pr[I_s,c1=1|H]
≤λ_α²。
~~~

加回观测部分，得

~~~text
E[|B_c0||B_c1| |H] ≤ (o0+λ_α)(o1+λ_α)。          (A3a)
~~~

当c0=c1=c时，父置换两个不同输入的输出必不同，使用B_c(B_c−1)：

~~~text
E[B_c(B_c−1)|H]
≤o_c(o_c−1)+2o_c λ_α+λ_α²。                      (A3b)
~~~

定义ζ_α(H)为(A3a)或(A3b)相应右侧。这个条件矩保留了Source在该原子首次出现时已经知道哪些桶；没有把每一个桶都强行视为达到某个全局最大值。

## 4. 首次出现的加权Parent定理

对单个α只向分析器揭示一列C(s)=E_s(xC)。沿用[整列Genie第3—6节](../../../%E5%85%B7%E4%BD%93%E7%95%8C%E6%8E%A8%E8%BF%9B_20261015/%E5%85%B1%E4%BA%AB%E5%9C%B0%E5%9D%80/04_%E8%BF%9F%E5%88%B0%E7%88%B6%E8%8A%82%E7%82%B9%E7%9A%84%E6%95%B4%E5%88%97Genie%E7%95%8C.md)：首次post-cut任意key触达前揭示该key两个父输出，其余key的剩余置换保持条件独立。

在这一次父输出揭示之前，两个输出在该key的剩余集合中均匀无放回。若两个目标桶与剩余集合的交集大小为a、b、交集重合为c，则单次精确概率为

~~~text
(ab−c)/(m_p(m_p−1))， m_p≥M−q0−1。
~~~

因此c0≠c1时的分子至多|B_c0||B_c1|；c0=c1时至多B_c(B_c−1)。首次post-cut key触达数至多r_α。逐步自适应并合，再对该完整列平均，得到

~~~text
Pr[L_α | H] ≤ r_α ζ_α(H)/den。                   (A4)
~~~

每个α分别建立一个分析Genie；不在一个联合Genie中免费揭示多个自适应列。真实归约未增加全列枚举。

对原子首次出现序号应用全期望与有限并合；若某序号没有出现，其事件与权重都取零：

~~~text
W_path := Σ_α r_α ζ_α(H_σα)，

Pr[⋃_α L_α]
 ≤ min(1, E[W_path]/den)。                        (A5)
~~~

(A5)对更窄的“最终有效伪造、正确旧链及实际提取失败”的迟到Parent交集同样成立，因为该交集包含于(A1)右侧。

**预算使用规则。** 若从一个事先规定的完整源类或资源域证明统一上帽W_path≤Wbar，则可用min(1,Wbar/den)。也可证明一个统一的期望上帽。单次已观察轨迹上的W_path数值不直接充当整个对手类的先验保证。

(A5)直接控制L，不以G_u为条件，也不另付δsrc。全ST2中供其他结构事件及实际桶帽使用的δu仍完整保留。

### 4.1 可直接组合的截断版本

若暂未得到Wbar，仍可保留推进04的前缀尾控制。设

~~~text
β_path := Σ_α r_α，
β_path≤βbar，J_path≤Jbar，
βbar≤Jbar·q0≤a1 N q0/2，

δsrc(v)=min(1,binom(q0,v+1)/(M−q0)^v)，v≥1，
μ_cross(v)=(v+λ*)²，
K_atom=βbar/den。
~~~

在每个好前缀，o0,o1≤v，故ζ_α≤μ_cross；相同com的阶乘矩还少一个v。μ_cross比PM7使用的μ2=(v+λ*)²+λ*更小。

旧桶帽界给K_atom u²。前缀坏事件统一并入BadSrc一次，得δsrc+K_atom μ_cross。对坏前缀用每列桶帽的点态条件界积分，得加权尾K_atom u²δsrc。最后一步可直接由

~~~text
Σ_α r_α 1{PrefixBad_α}
 ≤ βbar·1{BadSrc}
~~~

得到；不是把相关事件概率相乘。

所以同一真实归约可使用

~~~text
εParent,atom =
 min(1,
     K_atom u²,
     δsrc+K_atom μ_cross,
     K_atom[μ_cross+u²δsrc],
     Wbar/den（仅在已证明该上帽时）)。              (A6)
~~~

未给出Wbar时删除最后一候选项。与PM7取最小值亦合法；本稿没有新算法步骤，SALT管理、核心、历史、IO/RNG、置换截断和空间预算保持。

固定IV且实际目标对集合不变时，Jbar≤Σ_t|T_t|≤N/2，无需a1倍放大。不同IV可能给出新xC；相同h_com不自动降低Jbar。没有β/J特征的资源球仍可用a1 Nq0/2，这一最坏替换本身不会解决所有预算障碍。

## 5. Q=0的无IC前缀切片：q118的六组Parent严格小于1/64

本节给出一个新的可验证静态正结论，区分它与全域认证。

设Q=0，所有可解析H1查询都在Source第一次IC调用之前发生，H1数至多q=2^118；随后攻击者IC调用至多q，最终Verify仍按A_V保守收费。H4、Hc、Hμ、H1、H2均是ROM调用，不使Source IC表产生观测桶。

因此每个首次原子都有

~~~text
s_α=0，o0=o1=0，λ_α=1，ζ_α≤1，
J_path≤qN/2，r_α=q0=q+A_V。
~~~

由(A5)：

~~~text
Pr[⋃_α L_α] ≤ (qN/2)q0/den。                    (A7)
~~~

六组N≤17408、A_V<2^18，且q=M/1024。于是q0<5q/4、q0+2<2q，故

~~~text
den>(M−2q)²=(511M/512)²，

(qN/2)q0/den
 <5N/(32·511²)
 <1/64。                                         (A8)
~~~

最后一式等价于10N<511²，而10N≤174080<261121。全部推导是静态整数不等式，没有研究算术运行。

这包括“先复用一份旧Hc森林链、产生许多新IV的合规H1/H2，再做全部IC”的源形态。此时J仍可能随qN/2增长；改善来自实际零IC前缀的条件矩为1，并非声称不同IV都属于同一原子。

(A8)只处理Parent。Canon、AU、Twin、Z、Chain、末次挑战、原语优势、归约完整资源及适用时的其他尾项均保留。它没有证明整个共同预算域的rFAEST等强比较。

## 6. 旧预算障碍与合法哈希链的准确含义

[推进04旧ST2障碍稿:37](../../%E6%8E%A8%E8%BF%9B04/%E8%AF%81%E4%B9%A6%E9%9A%9C%E7%A2%8D/01_ST2%E5%85%A8%E6%A1%B6%E5%B8%BD%E9%A5%B1%E5%92%8C%E4%B8%8E%E5%90%88%E6%B3%95%E6%BA%90%E9%A2%84%E7%AE%97.md)的A_q每轮递增iv，μ、h_com和c为零；它只调用IC与H1，没有Hc前像查询。最终签名又在grinding高位处确定被拒绝。

因此：

- 该源不是固定IV/com重复源，原子去重不以“IV不变”为由解释它。
- 依本稿前缀解析器，它没有可解析旧Hc森林链，J_path=0，Parent事件为空；Adv=0也由实际Verify直接得到。
- 推进04证明的是旧预算表达式的饱和，并未声称其真实Parent概率为1。这个历史负结论保持正确。
- 在A_q上删掉不存在的有效链，并不等于已经给所有合法源的完整具体界。

还可以一次构造任意完整叶承诺列表、查询两层Hc与Hμ，然后对多个iv_pre查询H4，并把相同h_com带入不同IV的H1。得到χ1后，以任意定长ũ、128列摘要及d查询H2。这条旧哈希链可以完全可解析，却没有保证其VOLE值或Rain约束匹配任何实际开示。

因为两层Hc输入不含IV，共享同一列表跨IV使用没有逐IV重哈希N片叶承诺的逻辑义务。逐IV的H4/H1/H2、完整输入输出、规范原语及源控制仍须付费。本稿未从一个程序的规范成本上界推断所有源的成本下界；具体完整预算源由本轮反例分工单独列账。

## 7. 最终接受真正要求的新引理

### 7.1 需要界定的交集

设F为最终有效新消息伪造；GoodChain为既有epsChain之外的正确唯一旧H1/H2/HΔ连接；LateFinal为该最终开示使用了H1前无Source父格支持的实际父节点；Fail_B为同一个实际SALT/B_final提取器未输出有效Rain原像。

本轮有意义的剩余事件是

~~~text
E_eff = F ∩ GoodChain ∩ LateFinal ∩ Fail_B，
~~~

再与其他已支付坏事件的补集相交。若实际B已经成功，该部分F已进入OWF优势项，无需重复收取Parent损失。仅把F与全体不相干的L并集相交仍然较宽。

(A5)/(A6)给出E_eff的有效上界，但尚未充分利用接受和Fail_B。

### 7.2 待证的预响应允许挑战集合引理

一条可直接组合的新桥应按如下接口陈述。

对每个普通旧HΔ首次查询j，在其回应之前，固定当前完整Source/RO前缀、同一全E及由该输入确定的旧H1/H2链。定义S_j为：存在未来实际开示，使最终验签接受、落在LateFinal∩Fail_B且避开其他已支付坏事件时，可能使用的Δ值集合。

若能证明：

1. S_j在该次新HΔ回应前已经由上述数据固定；未来自适应开示至多选择其中元素；
2. 在所声明的好事件范围内，|S_j|≤s，且相关坏事件的概率及资源已经另行证明；
3. Fail_B指实际有限归约的输出失败，非一个拥有全表查询能力的语义失败标签；

则依经典ROM新回应均匀性，每个j贡献至多s/M，所有旧HΔ继续并合为s a_Δ/M；最终新点仍按冻结接口付1/M。若该分项同时有Parent界，也可对同一事件取较小界。

源码里的VH、QS与HΔ连接本身并没有证明这三个条件。尤其不要直接把Parent概率乘2^-128、删除a_Δ，或先条件于最终被选中的j再称其回应新鲜。

### 7.3 全E基线与可执行提取的待核接口

B_final目前按H1前Source支持选择canonical，之后只在最终旧H2快照求值。若新证明将canonical改成全E上的全局父节点，语义上可在χ1之前固定；实际计算A_t、候选f及W仍须给出有限实现。

可考虑的具体后处理接口是：利用最终Verify重构出的全部可见叶tape，逐树计算

~~~text
S_t=c_t XOR XOR_{j≠h_t}m_t(j)，
f=S_t XOR m_t(s)，
~~~

其中h_t是该树的隐藏叶，s遍历H2旧K_vis中匹配隐藏com的seed。若VH(f)=ũ，再形成W=d XOR f[0:ell]并做真实CheckW。实际读取、候选桶溢出、排序、VH、历史过滤和输出都应计费。

这只是可实现操作的候选接口，还缺两类证明：其一，所有最终开示都被一个χ1前固定、大小可控的语义f族覆盖，且AU保证所有匹配f一致，从而事后选择h_t不改变χ2前的W；其二，有限旧池找不到s时，原TwinUnknown及两点挑战结论仍成立。没有这两类桥时，本稿保留旧B_final算法及全部费用。
