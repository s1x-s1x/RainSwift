## 2. 双向计数树与不变量

用两棵256层二叉树T_F和T_I，键为128位key K拼接128位端点a。T_F叶值为像y，T_I叶值为原像x。每个节点连续占四个256位字：

~~~text
offset 0: left
offset 1: right
offset 2: count
offset 3: value（只有深度256的叶使用）
~~~

null指针为0；两个真根用非零地址，根的四字全部显式置0。节点用单调游标分配；新节点的四字在链接和读取前显式置0。叶的value直接装一个128位端点，没有额外三元记录或payload对象。

count等于该节点下已完成映射叶的数目。根和key前缀以上节点的count可以跨key累计，最大为f；深度128的key节点count恰为该key的n_K，满足0≤n_K≤M。计数使用完整256位字，n_K=M需要129位而仍在范围内。

这里的已完成映射包括B的一切公开及私有IC读取，是完整IC物理表的占用，绝非Source曝光条数。B的Full/Source标签仍由原管理层维护，新的两张索引为所有请求共用同一个E。

每次成功增加映射(K,x,y)时，同时插入T_F的(K,x)→y与T_I的(K,y)→x；两条路径从根到叶的257个节点均增加一次count。插入中间不调用B，不暴露半完成状态。程序没有中途资源耗尽的秘密分支：下面的先验容量已经覆盖所有执行。

由归纳得到：

1. 两表始终是同一有限双射的正向及逆向索引。
2. 非空深度256叶恰对应已插入映射；中间未分配孩子代表空子树。
3. 对每个key，两边已占端点数相同，等于其深度128节点count。
4. 命中缓存时返回既有值；未命中时当前key至少有一个未用端点。若n_K=M，则所有端点都已缓存，未命中分支不会发生。

固定key后的秩选择只在余下128层进行。它不对整个256位键域宣称有可存入一个字的2^256个空叶容量。

## 3. 完整答复程序

~~~text
IC(direction, K, a):
    依direction选择已知端点树T和对侧树U
    在T按256位键 K || a 查找
    若命中叶，返回该叶value

    在U沿K的128位前缀找到key节点p0
    n := 0；若p0非空，n := LOAD(p0+2)
    s := M-n                         // 1≤s≤M
    j := ModRank384(s)
    b := SelectUnused128(p0,j)

    Insert256(T,K||a,b)
    Insert256(U,K||b,a)
    返回b

ModRank384(s):
    j := 0
    固定执行384步：
        bit := 一个新的均匀随机位
        j := (j << 1) OR bit
        若j≥s，j := j-s
    返回j
~~~

所有输入端点都按128位处理，K||a由一次左移及一次OR打包。两个方向共用同一套程序，只交换树根；没有复制两套完整代码。外部方向和合法固定宽输入按原IC接口给定，内部传参、复制和控制另在费用中列出。

### 3.1 未用端点的秩选择

用升序0,…,M−1排列该key未用端点。第j个未用端点由如下程序找到：

~~~text
SelectUnused128(p,j):
    y := 0
    按h=127,126,...,0静态展开：
        left := 0; right := 0; usedLeft := 0
        若p非空：
            left := LOAD(p)
            right := LOAD(p+1)
        若left非空：
            usedLeft := LOAD(left+2)
        freeLeft := 2^h-usedLeft
        y := y << 1
        若j<freeLeft：
            p := left
        否则：
            j := j-freeLeft
            y := y OR 1
            p := right
    返回y
~~~

2^h是随展开指令加载的至多128位立即数。所有动态p+1、left+2分别付ADD。读取null子树前先判断；空子树的占用数为0，不为选择过程预先物化节点。

进入一层时j严格小于当前子树空叶数。左右空叶数相加等于该数，故选择的子树空叶数为正，更新后j仍在有效范围。归纳到最后，所返y未被占用；上述过程为秩与未用端点的一一映射。

### 3.2 插入与真实初始化

~~~text
Insert256(root,z,value):
    p := root
    LOAD(p+2)，加1，STORE回p+2
    按j=255,254,...,0静态展开：
        bit := (z >> j) AND 1
        edge := p+bit
        child := LOAD(edge)
        若child为0：
            child := next
            next := next+4
            显式STORE 0到child,child+1,child+2,child+3
            STORE child到edge
        p := child
        LOAD(p+2)，加1，STORE回p+2
    STORE value到p+3
~~~

插入只用于已知缺失端点。新映射的对侧端点由SelectUnused保证缺失，故两次插入的计数增加都正确。即使端点全为0，其叶value为0也不与“叶不存在”混淆：是否存在由指针判断。

arena容量是地址/空间上界。程序只初始化实际分配节点，不读尚未分配字；不执行整个最坏容量的预清零。该差异是新程序的真实行为，原P03管理程序的全arena初始化仍在B原费用中。

## 4. 精确统计距离及自适应组合

固定任意查询前的完整历史。缓存命中没有差异；新映射时令s=M−n≥1，D=2^384。384位随机串对应U均匀分布于{0,…,D−1}。流式余数归纳保持j为已读前缀模s；每步中间数小于2s≤2^129，最多减一次s即可，因此不需要大整数模指令。

写D=as+r，0≤r<s。U mod s有r个值概率(a+1)/D，其余s−r个值概率a/D。与均匀s点分布的总变差距离恰为

\[
d_s=\frac{r(s-r)}{sD}
\le \frac{s}{4D}
\le 2^{-258}.                                      \tag{R1}
\]

当s整除D时误差为0，包括s=1和s=M；式R1是统一上界，不声称每次都达到它。

若秩严格均匀，选未用端点与普通双向IC的精确懒采样一致。SelectUnused为双射，保持上述总变差距离。新模拟器始终给出自洽双向置换的部分表；差异仅在剩余端点的近均匀选择。

对两边共同的完整前缀，当前请求、key、方向、表及s都相同，可将下一次新回答最大耦合，条件分歧概率≤2^-258。缓存请求条件分歧概率为0。直到首次分歧，B的全部状态及选择相同；对自适应的至多fbar次新映射并合：

\[
\delta_{\rm rank}(fbar)
=\min\{1,fbar\,2^{-258}\}.                         \tag{R2}
\]

这个耦合涵盖B的私有补查、公开重构、最终Verify和任意方向的源请求；用fbar时需要它是完整执行的先验帽，事后观察到较小f不替代该帽。有限预算且不持有外部时钟/私有表接口的B满足

\[
\operatorname{Adv}^{IC}_{G_R^+}(B)
\le \operatorname{Adv}_{G_R^+}(C_{\rm rank})
   +\delta_{\rm rank}(fbar).                       \tag{R3}
\]

本程序固定384步取秩，没有拒绝抽样终止参数L。对p≤M且fbar≤p，R2≤2^-130；这只是辅助模拟误差，没有赋值完整签名安全位数。

## 5. 可展开的七维费用

向量次序为(LOAD,STORE,ADD/SUB,BIT,CMP,BRANCH,MOVE)。指令语法与共同机器一致：动态寻址另计ADD；每个比较和控制跳转分别计；算术三地址写寄存器是该动作本身。新随机位记RNG，每位另保守计一次MOVE落到寄存器。

固定长度循环全部静态展开；代码/立即数存储与装载在第6节收费。null分支有实际CMP/BRANCH，未作“常见路径”摊销。下表每个子程序有头尾包，覆盖参数搬移、末叶检查、载值/返回和固定栈控制；p请求外层包再单独列出。

| 部件 | 每层/每步上界 | 次数 | 头尾向量 |
|---|---|---:|---|
| 256位缓存查找 | (1,0,1,2,1,1,0) |256| (8,0,8,8,8,8,16) |
| 对侧128位key前缀查找 | (1,0,1,2,1,1,0) |128| (8,0,8,8,8,8,16) |
| ModRank384 | (0,0,1,2,1,1,1) |384| (0,0,8,4,4,4,12) |
| SelectUnused128 | (3,0,4,2,3,4,4) |128| (4,0,4,4,4,4,8) |
| 一次Insert256 | (2,6,7,2,1,1,2) |256| (8,8,16,8,4,4,16) |
| 请求外层 | — |每请求1次| H=(32,32,64,64,32,32,64) |

缓存/前缀查找每层：提取一位2BIT，null检查CMP+BRANCH，edge动态寻址ADD，孩子LOAD。深度256后的null检查、p+3及value加载在头尾内；prefix返回节点或0。该实现没有把缺失叶的value当作有效返回。

Select每层最坏3LOAD为left、right及left.count；4ADD/SUB为两个动态偏移、freeLeft及右支rank减法；2BIT更新输出；3CMP检查p、left和rank；4BRANCH包含右支跳过左支赋值；3个初始化MOVE及一个p赋值。左/右分支不同时执行，使用其中较贵路径作为坐标上界。

Insert每层2LOAD为孩子与计数；6STORE为新节点四零、父边以及计数写回；7ADD/SUB为edge、next增长、三个初始化偏移、count地址及count加1；2BIT取位；1CMP+1BRANCH判空；2MOVE为child取得游标及p更新。根count、末叶value写回、参数打包和函数控制落在头尾内。

外层H的用途限于完整固定宽请求接收、方向选根、K/端点归一及两次键打包、key节点count读取、s计算、缓存查找之后五个子程序调用（完整缺失路径共六次调用）的固定传参/返回、缓存出口以及结果复制。参数/返回槽总数少于32；六次调用及六次返回、方向/缓存/key空判断与最后出口合计至多16次控制跳转。调用、返回槽和缓存早返均在H或已列头尾包内；每个动态槽先ADD再LOAD/STORE。H各坐标均覆盖这些实际动作，不另包含任何与p、f、128或256成比例的隐藏循环。数据传输的位IO在B的既有接口帽中保留，本地搬运照常另计。

由逐行向量相加，定义

\[
\begin{aligned}
V_{\rm hit}&=(296,32,328,584,296,296,80),\\
V_{\rm fresh}&=(1564,3088,4660,2336,1432,1560,1988).
\end{aligned}                                      \tag{C1}
\]

V_hit包含一次完整缓存查找和外层H；V_fresh是在缺失时增加的一次前缀查找、取秩、选择及两次插入。

\[
\|V_{\rm hit}\|_1=1912,\qquad
\|V_{\rm fresh}\|_1=16628,\qquad
\|V_{\rm hit}+V_{\rm fresh}\|_1=18540.               \tag{C2}
\]

因此任一运行的新增请求RAM向量≤pV_hit+fV_fresh，新增随机位≤384f。对先验fbar可统一取

\[
V_{\rm req}\preceq pV_{\rm hit}+fbar V_{\rm fresh},
\qquad RNG_{\rm new}\le384fbar.                     \tag{C3}
\]

没有给出fbar<p时，令fbar=p，得到新增运行总工作≤18924p。这里18540是所给具体有限程序的RAM帽，384是另外的随机位费用；不是CPU周期或对所有实现的下界。

## 6. 代码、准备、容量与IO

两个方向通过选根共用正文。允许逐个长度固定子程序展开，也可静态复制两次插入段。已计主体的最长路径至多18540条；加入Select未走的至多128条左支赋值，再给固定loader、头尾和剩余控制块不超过2^12条，总代码并集小于18540+128+4096=22764<32768。缓存早返和分配分支的主要代码已在主体内，未按p复制代码。

使用不超过128个寄存器编号及固定返回槽。单条指令的opcode、至多三个7位寄存器字段、一个至多129位立即数及15位模块内静态控制标签能装进256位字。动态返回目标用完整字寄存器/固定返回槽；15位只指该固定模块内部标签，不限制B的全局代码地址。模块与B的入口/返回链接、控制地址形成和搬移在固定准备及调用包内；长地址来自寄存器；树游标与B的空间基址不以一个带其他字段的256位立即数字面量硬塞入指令。固定M可用1左移128形成；mask、rank容量与位索引的代码存储照计。

固定常量数据≤64字，固定寄存器、控制栈、临时缓冲及两个根共占不足2^15字。因此统一固定空间帽为2^16字。每新映射最多为每表分配256个四字节点，故

\[
S_{\rm rank}(fbar)=2^{16}+2048fbar.                 \tag{C4}
\]

实际程序不为S_rank大小的区域执行预清零。固定程序/常量的装载IO≤256(2^15+64)<2^24位；B的逻辑查询/回答IO仍使用原帽。固定根及工作区初始化、代码/常量搬运、展开生成和loader控制可统一用

\[
V_{\rm prep}=2^{22}(1,1,1,1,1,1,1),\qquad
I_{\rm prep}=2^{24}.                              \tag{C5}
\]

这一包络包含：每指令至多64个字段形成/搬运动作的展开生成≤2^21；程序/常量写入、读取与计数各单一RAM坐标≤2^17；固定工作区初始化与控制各单一RAM坐标≤2^17。单一坐标之和小于2^22。准备没有随机位；这些固定数据与挑战、IC独立。完整准备总工作

\[
\|V_{\rm prep}\|_1+I_{\rm prep}<2^{26}.             \tag{C6}
\]

设B峰值空间S_B已经有先验帽，采用与其并存的独立地址区。要求S_B+S_rank(fbar)+1<2^256，所有实际计数/游标加1及指令地址均可表示。游标只加4，末次节点初始化地址在该界内。可寻址容量是运行前的接口条件；没有未收费的逐请求容量计算或回绕检查。输入域超出这个条件时不使用本稿证书。

p=0时直接运行B，省去整个新程序/表，所有新增资源和误差均取0。p>0、实际缓存居多时仍可使用上述统一先验帽；较小实际耗时不反向改变已选预算。

## 7. 接到同一个SALT归约

                  +F(V_{\rm hit}+V_{\rm fresh}),\\

&=(V_0+V_{\rm rank}(F),\
