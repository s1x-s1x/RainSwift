## 2. 费用闭合后最小的独立输入记录

将一个可引用或可明确提出的原语假设记为记录h，而非只写“Rain安全”。记录至少含下列字段。

| 字段 | 最小内容 |
| --- | --- |
| 对象 | 固定的Rain-128-3或Rain-128-4、固定线性层和常数、实现所用非零关系；两种轮数分别登记。六组签名只需共享相应轮数的原语记录，无须凭空增加六种原语。 |
| 游戏 | G_R^+：独立均匀采样(P,K)，整对拒绝重采样至所有求逆输入非零，公布(P,C)，接受任意满足真实关系的K'。 |
| 接口 | 独立于挑战的辅助ROM和双向IC、公开Rain计算，以及记录允许的预处理/建议串；与实际归约接口一致。 |
| 资源 | 同一完整抽象机器上的上限Γ_h：所有公开计算、存储/访问、控制、输入输出、随机比特/预言及预处理均收费。若用加权时间，给出权重；零权重种类需由明确其他上限约束。 |
| 概率 | 对所有符合Γ_h的普通算法C，Adv_G_R^+(C)≤p_h，0≤p_h<1。明确最坏预算或期望预算，不免费互换。 |
| 身份与依据 | 文献中的具体前提，或本项目单独提出的计算猜想；其数值和动机来自原语问题，保留已知攻击核查与不确定性，不由签名所需余量反解后冒充依据。 |

若引用明确的总化逆元游戏G_R^0，沿用已证连接J：相同算法在全部输入上满足同一个最坏资源帽时，

\[
\operatorname{Adv}_{G_R^+}(C)
 \le \frac{\operatorname{Adv}_{G_R^0}(C)}{1-R/2^{128}}.
\tag{1}
\]

故记录中的原语概率需按此导入，保留分母损失。若来源只保护“原生成密钥”，还须对应的纤维控制或直接提出Any-OWF前提。全密钥空间与固定K时P↦C为置换，不等于固定P时密钥唯一。相关游戏与连接已在封存稿证明，本稿没有把它们当作新成果。

此外，比较记录至少指定共同的目标成功率p*、目标工作量T*及使用域U，包括签名次数、存储、预处理和接口。T*仍解释为固定参考rFAEST-EM128f/s所声称128档；原文没有规定的常数须明示为共同分析约定。固定对照为提交`7a59c5c18b199bae427bd71d3b9fb5ea3f3b6d97`；快/均衡对f，短对s。

### 独立猜想可以提出，但它的身份不变

例如，可先在共同机器上、与签名误差无关地提出一族候选：对于事先指定的存储和预处理范围，工作量小于α_R·2^128个该机器单位时，普通Any-OWF成功率至多p0。α_R、p0及资源范围是**原语猜想的内容**，需通过已知攻击筛选并单独解释。n位设计定位可以说明考察2^128量级的动机，却没有唯一给出α_R或p0。

这类猜想是允许的条件证明前提；既不要求作者事先打印完全相同常数，也不要求把它无条件证明。本稿没有采用任何新的α_R、p0数值，没有声称用户已接受某个新常数标准。取p0=1/4等仅是可能的固定成功率约定，未由“达到1/2需约2^128工作”推出；封存连接稿中的易实例子集反例已说明，重复同一个实例上的算法不保证所需平均成功率放大。

## 3. 有限记录的精确覆盖判据

这节把已有单点充分定理细化成费用闭合后可执行的验收判据，避免以全曲线作额外要求。

对签名档s，令

\[
V_* =\{v\in U:T_A(v)<T_*\}.
\]

v包括全部所声称源对手资源。取事先明确的**有限**归约菜单K_s；每个k对应一个完整程序，例如固定块容量的B_batch或固定核验阈值的B_salt,m，并已证明

\[
\operatorname{Adv}_{\rm EUF,s}(A)
 \le\operatorname{Adv}_{G_R^+}(B_{s,k}[A])+e_{s,k}(v),\qquad
\operatorname{Res}(B_{s,k}[A])\preceq\Gamma_{s,k}(v).
\tag{2}
\]

私有随机盐路径的e保留ε_ST2和δ_cap；批量路径保留其实际全部误差。每个Γ来自这个同一程序的完整账，不将某程序的低时间与另一程序的低空间拼成一个不存在的归约。m/c在其程序中预先固定；数学上比较多个已证明上界不需要归约在轨迹中免费求最优参数。

令H_R为该轮数的有限独立阈值记录集，各概率已经导入G_R^+。定义覆盖区

\[
C_{s,k,h}=\{v\in V_*:
 \Gamma_{s,k}(v)\preceq\Gamma_h,
 \ p_h+e_{s,k}(v)<p_*\}.
\tag{3}
\]

**命题P（针对这些已证不等式的精确判据）。** 这些记录与归约的逐项标量上界足以排除整个V_*内成功率至少p*的伪造，当且仅当

\[
V_*\subseteq\bigcup_{k\in K_s,h\in H_R}C_{s,k,h}.
\tag{4}
\]

这里“当且仅当”只描述**用(2)和这些阈值记录所能出具的证书**，不描述真实算法安全性的必要条件。

**证明。** 对每个v，取满足资源帽的候选对(k,h)，其标量上界为min(1,p_h+e_s,k(v))；没有候选时取1。有限菜单下最小值u_s(v)存在。若(4)成立，u_s(v)<p*，由(2)立即排除该v下成功率≥p*。反之，若某个v未被覆盖，则所有可用标量上界均≥p*，数值p*仍满足这些上界约束；仅靠这些约束没有排除它。这不构造一个实现该数值的伪造者，也不否定其他证明。证毕。

这个形式允许不同源预算区域采用不同完整归约和独立阈值，不要求一条原语优势函数覆盖所有成功率。root的盐核验整数证书给出了特定覆盖区中m可行性的静态求解；本稿不重复该推导。

### 全域与严格端点

若选一个共同(h,k)，用Γ_*逐坐标控制所有Γ_s,k(v)，再用d*=sup_V* e_s,k(v)，则Γ_*≼Γ_h且p_h+d*<p*是方便的充分条件。它一般强于逐点严格条件：开放域上可能每点p_h+e<p*，但未取得的上确界正好为p*。只有说明最大值确实取得，才将此形式称为等价。实际整数资源若在每一维均有有限上限，有限可行集合可取最大值；未限费用的输入长度、预处理、内存或接口会使这个论证失去前提。

几个样本点、一段有利预算窗口、或仅对某一种查询分配成立，都未覆盖(4)的整个V_*。反过来，(4)也未要求在T_A≥T*的域继续证明逐点优势支配；把饱和为1的参考上界当作等强通过依据没有固定成功率含义。

## 4. 已知枚举给出的可证伪筛选

推进02已证明：普通原语攻击者可从一个独立均匀循环起点开始，验证q个不同密钥。对任意真实生成密钥K，K落入候选段的概率为q/M，M=2^128。因此成功恢复任意有效原像的概率至少q/M；真实联合拒零分布的偏差不改变这个下界。

攻击者可以使用与归约相同的分块批量逆元优化，并流式处理候选；无需承担归约的完整源对手历史或显式列表存储。这里比较的攻击费用仍应包括起点抽样、候选循环、每轮矩阵/域运算、判定、存储访问和输出。仅有CLMUL计数不代表该程序的完整费用。

对一个阈值Γ，定义已知算法底线

\[
g_R(\Gamma)=\max\{q/M:\text{已有完整费用证明的上述枚举程序可在}\Gamma\text{内运行}\}.
\tag{5}
\]

空集取0；q在0至M内，算法参数事先固定。可以比较多个固定程序的数学保证；真正执行运行时参数搜索还需支付相应费用。本轮不运行程序求q。

**命题E1。** 任一有效的G_R^+阈值记录必满足p_h≥g_R(Γ_h)。若完整M键枚举已落入Γ_h，则成功率1的已知算法使任何p_h<1记录失效。

**证明。** 记录保护其资源球内所有普通算法，故也保护(5)中的每个公开枚举程序。逐项取最大值即可。证毕。

**命题E2（证书路线的必要条件）。** 对一个拟使用的完整归约和阈值资源帽，存在可同时满足已知攻击底线及严格目标余量的标量p_h，须有

\[
g_R(\Gamma_h)+e_{s,k}(v)<p_*.
\tag{6}
\]

等价地，可能的数值区间为

\[
p_h\in[g_R(\Gamma_h),\ p_*-e_{s,k}(v)).
\tag{7}
\]

若(6)失败，单纯补一个更强的普通困难性猜想也救不了这组**同一资源球、同一误差项**的证书。若(6)成立，只说明没有被这类已知攻击立即排除；区间中的任一数值仍需独立困难性依据或明确猜想，未由区间非空证明其正确。

这个筛选解释了为什么费用是实质问题：归约花费很大，会把普通原语阈值的允许资源球放大；该资源可被原语攻击者重新分配给密钥搜索。实际B_s成功率未因它昂贵而变成1，但其所属资源球可能已包含成功率1的另一个算法。参考原印刷提取器的全空间枚举障碍正属此类，限制的是那条资源证书路线；它未自动撤销作者层级的设计评估，也不要求先修复参考证明才研究我方。

## 6. 本轮可以继续做、以及费用齐全后仍需什么
