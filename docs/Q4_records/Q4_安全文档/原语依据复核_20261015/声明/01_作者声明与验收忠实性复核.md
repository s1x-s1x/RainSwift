# 作者声明与验收忠实性复核

2026-10-15；reference_standard；只读论文及静态数学复核。

**实质修正：把上一阶段C3的“全域优势包络逐点支配”作为Q4唯一验收门槛，会增加作者没有明确交付、用户也没有明确指定的要求。C3仍是正确的充分证书路线，保留全部归约损失也不会使它变成同档工作因子的必要定义。作者确实声称128位安全级别，这多于一个参数标签；作者同时给出了带原语假设的条件安全界，却没有交付唯一、完整、数值化的机器优势曲线。**

## 2. 对上一阶段方案的独立挑战

[参考01](../../%E8%AE%A4%E8%AF%81%E7%AA%97%E5%8F%A3_20261015/%E5%8F%82%E8%80%83%E6%A0%87%E5%B0%BA/01_rFAEST%E5%8E%9F%E5%BC%8F%E4%B8%8E%E5%8F%AF%E6%93%8D%E4%BD%9C%E6%AF%94%E8%BE%83%E6%97%8F.md)把原定理整理成C1/C2函数族，并将

\[
\forall v\in\mathcal U:\quad
h_{Rain}(\Gamma_B(v))+\epsilon(v)\le p_{claim}(v)
\tag{C3回顾}
\]

称为“充分条件”。这一数学定位正确。下面三步却没有来自原文的必然性：

1. **唯一化。** C1/C2需要另行固定原语数值函数、资源映射、使用域及源码包络约定；R没有给出唯一这一组数据。
2. **必要化。** 某条有效归约上界没有逐点优于参考上界，既不排除存在更好的证明，也不排除实际方案有相同工作因子。保留所有损失只让该上界比较更忠实，不会把充分条件变成必要条件。
3. **从单档工作因子扩成所有成功率曲线的形状约束。** 同一固定成功率下达到目标工作量，不要求低成功率处的每一个优势值都受另一条上界逐点支配。反过来，低预算几个点通过也未证明整个目标工作因子。

此外，两个正确安全上界之间的大小关系本身不确定两个真实最优优势的大小。这一点对“作者全项包络”也同样成立；作者包络不是作者真实最优攻击曲线。

因此，C3可继续作为一条更强证书路线；把“先完成C3或同形的完整曲线”写成原用户目标的唯一前置条件，应予纠正。这是对验收解释的修正，不撤销上一阶段公式、列表桥或有限算术的有效范围。

此前[CALIB声明核查](../../128%E5%8F%A3%E5%BE%84%E8%90%BD%E5%9C%B0_20261015/%E5%AF%B9%E7%85%A7%E5%8F%A3%E5%BE%84/01_rFAEST%E5%A3%B0%E6%98%8E%E4%B8%8E%E9%AA%8C%E6%94%B6%E6%A0%87%E5%B0%BA.md)已指出“无损T/2^128”不是唯一门槛。本次新增判断是：即使换成保留原文全部损失的C3，逐点包络支配依然不宜被升格为唯一必要门槛。没有新增外部密码分析结果。

## 3. 保持用户目标的正式判定标准

忠实的目标仍为：**固定原030实际实现，在与rFAEST-EM128f/s可比的经典模型、使用范围和成本解释下，支持相同的128档安全声明；所用假设、常数和证据层级明确。** 单独证明PPT安全、单独写λ=128、或单独列“无已知攻击”均未完成这个目标。

验收时应同时保留以下内容，而非以一个更强的全曲线任务替代它们：

| 条件 | 可核对的完成内容 |
|---|---|
| 实际对象 | 六组原030的KeyGen、Sign、Verify和参数映射；真实联合拒零KeyGen；Rain任意有效原像与找回原生成密钥的区别。 |
| 正确的完整条件论证 | 自己的有效经典EUF-CMA归约及所有模型、误差、PPT资源，不借用已被驳回的参考引理。 |
| 128档原语依据 | 针对真实Rain3/4游戏的独立计算假设及文献/已核攻击依据，明确这是计算假设，未要求无条件证明实际Rain困难性。 |
| 完整协议具体评估 | 对公钥求逆、种子恢复/多目标、承诺与提取、挑战/grinding、多签名/IV等相关路径，说明其工作量、成功率、资源和证明损失的角色；局部组件事件不直接冒充完整伪造。 |
| 可比量尺 | 所用时间/查询、存储、预处理、成功率及签名使用范围写明；异构操作无证据时分别记账。参考未固定的约定标作本项目共同约定。 |
| 结论层级 | 条件设计评估、严格阈值定理和全曲线证书分别报告；相同证据类型不自动推出实际最优攻击复杂度相等。 |

若仅要达到**作者实际交付的论证层级**，普通类型的明示计算假设加完整条件证明和具体设计评估即可成为同层级的条件性交付；无须额外交付一条作者自己没有实例化的全曲线。这里“普通类型”指独立的原语假设，如实际Rain任意原像单向性；它不表示该固定Rain假设已经成为公认定理，也不表示新列表假设自动由普通OWF推出。

但条件性交付仍须有支持128档的具体依据。只有“Rain是OWF”这种渐近前提，通常只支持渐近EUF-CMA；它没有给λ=128实例的具体工作因子。把作者也采用假设作为理由，直接把任意较弱原语或任意大的归约损失接受为128档，同样偏离用户目标。

## 4. 严格具体工作因子可以用阈值证明，无须整条曲线

下面给出一个保持目标工作量、但不强求所有成功率曲线形状的正式充分判据。它只是静态数学说明，本轮未对六组运行或代入新数值。

先公开固定共同成本约定、使用域和目标成功率p*∈(0,1)，以及由参考128档解释得到的目标工作量T*。T*、p*及常数应有来源或明确标为共同分析约定；不要声称R已经逐字规定了它们。以最坏预算为例，定义目标域

\[
\mathcal V_*=
\{v:\ T_A(v)<T_*,\ v\text{满足公开的签名次数、存储、预处理等条件}\}.
\]

采用一个**独立于签名误差余量提出**的真实Rain任意原像假设：对所有完整资源受Γ_R限制的算法C，

\[
\operatorname{Adv}^{AnyOWF}_{Rain,R}(C)\le p_R.
\tag{H}
\]

其中挑战来自真实联合拒零KeyGen；理想预言接口与全部公开Rain计算、存储及预处理均匹配ST2。假设H的资源阈值和p_R来自原语分析或明示的独立原语猜想，未由p*−ε反解后换名得到。

如果对全部v∈V*及全部相应对手A，存在已证明的同一个B_s[A]满足

\[
\Gamma_{B,s}(v)\preceq\Gamma_R,
\qquad \epsilon_s(v)\le\delta_s,
\qquad p_R+\delta_s<p_*,
\tag{F}
\]

则ST2直接给出

\[
T_A<T_*\quad\Longrightarrow\quad
\operatorname{Adv}^{EUF-CMA}_{030,s}(A)<p_*.
\tag{W}
\]

所以在该使用范围内，成功率至少p*的伪造需要工作量至少T*。这是对整个所声称阈值域的条件定理；它没有要求给出低于p*每一种成功概率处的精确曲线，也没有要求在超过目标工作量以后继续逐点支配参考包络。

这条路线保留四个真实限制：

- Γ_B包含完整Source、H_s处理、Verify、公开Rain检查、RO/IC、历史日志、提取、输出与空间；A的费用没有被冒充为B的费用。
- H必须与可执行穷举相容。如果Γ_R已经允许以高于p_R的概率进行普通求逆，H即被已知算法排除。
- 已知“成功率1/2所需工作至少某值”不自动给出更小成功率p_R处的界。平均公钥上可能存在易实例子集，重复攻击同一实例未必实现所需放大。1/4等另一固定成功率假设需独立写明，未由1/2免费推导。
- F仍需覆盖V*内全部对手和预算。24个有限诊断点及有限单调例未代替它。改变目标域以避开不利预算也需有实际使用依据。

因此，要求独立计算假设是常规且必要的；要求“先证明实际Rain的无条件全资源曲线”不是普通计算密码学证明的前提。与此同时，单纯把H写出来，或选一个事后恰好让F成立的H，也没有提供新的128档证据。

## 5. 能否在普通明示假设下条件性完成

答案应分清具体承诺：

| 承诺 | 普通明示假设能够支持到哪里 |
|---|---|
| 与作者同类型的经典EUF-CMA正式证明 | 在真实Rain OWF、所列ROM/IC及其他必要条件下，结合有效归约、可忽略误差和多项式资源，可以条件性完成。已有ST2属于这类成果。 |
| 与作者声称128档相当的条件设计评估 | 原则上可以；须合成真实Rain128依据、完整协议安全论证和实际相关攻击路径的具体评估。它不是λ标签自动通过，也不声称已经数学证明最优工作量相同。 |
| 明确成本/成功率的严格128档工作因子定理 | 可以采用H/F/W或其他正确直接论证；所需是独立的适当阈值假设和完整资源连接，未必是整条优势曲线。普通渐近OWF前提单独不足。 |
| 所有预算点上的作者包络支配 | C3是可选的更强充分证书路线；目前该路线未闭合的状态保留，但不宜将它设为前面所有层级的唯一先决条件。 |
