## 发布处理

- **收录范围**：
  - 三份 Q4 文档直接引用的记录；
  - 这些记录再引用的分稿、审查、脚本和结果；
  - 上表三处核心环节所在目录的全部正文；
  - 已收录正文直接引用的证明稿、脚本和结果。
- **内容**：除下面两项替换和换行统一为 LF 外，与工作区原文件逐字节相同。
  - 本机绝对路径替换为 `<工作区>`、`<旧工作区>` 等占位符；
  - 链接按下面的规则改写。
- **链接改写**：
  - 指向已收录文件的链接，改为本目录内的相对链接；
  - 冻结源码的行号引用，改为 `src/` 中内容相同的行；当前 `src/` 已变动的，改为首个公开提交 `3f8b0f4` 的永久链接；
  - rFAEST 上游源码，改为其公开仓库提交 `7a59c5c` 的链接；
  - 论文改为公开 ePrint 地址。论文原文不随仓库分发。
- **未收录**：管理记录（输入快照、门控、交付清单等）、过程备份、类别 1 候选源码和少量更深层的阶段稿。指向它们的链接保留为文字“（内部记录，未随仓库公开）”，共 24 处。
- 脚本中的路径是作者工作区的路径，在别的机器上直接运行需要相应调整。
