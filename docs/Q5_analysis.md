# Rain 建钥实现说明

本文件保留建钥优化的实现依据；此前的机器相关耗时、估计值和旧性能表已删除。正式测量统一使用[复赛支撑数据](../data/README.md)。

## 实现范围

建钥中的 Rain 正向计算使用 `src/rain_kg.hpp`，入口为 `rain::kg::forward<R>`。它与原有 `rain::forward<R>` 计算同一函数，保持随机字节用量、公私钥格式和零输入拒绝规则。

优化集中在线性层的向量选列、多次平方与求逆加法链、GF(2^64) 乘法的模约化。签名中重算见证的路径及验签路径沿用原实现。

## 核查方式

- `src/q5_kg_test.cpp` 对有限域操作、线性层、求逆和完整正向计算逐项做新旧差分测试，并包含零输入及单位向量等构造输入。
- `verify.sh` 运行差分测试、T1–T8，并与 `KAT/` 的六组公开签名向量逐字节比对。
- 本轮材料中的[建钥差分日志](../data/功能测试/建钥差分测试.log)与[机器码一致性记录](../data/功能测试/机器码一致性.json)按原字节公开。

参数与签名格式保持不变，性能数值按同窗口、同构建口径比较。当前值见[性能统计](../data/原语性能/性能统计.csv)。
