## 2. rFAEST作者交付了什么

依据作者版论文全文（项目副本，SHA见[作者声明复核](Q4_records/Q4_%E5%AE%89%E5%85%A8%E6%96%87%E6%A1%A3/%E5%8E%9F%E8%AF%AD%E4%BE%9D%E6%8D%AE%E5%A4%8D%E6%A0%B8_20261015/%E5%A3%B0%E6%98%8E/01_%E4%BD%9C%E8%80%85%E5%A3%B0%E6%98%8E%E4%B8%8E%E9%AA%8C%E6%94%B6%E5%BF%A0%E5%AE%9E%E6%80%A7%E5%A4%8D%E6%A0%B8.md) §6）：

1. **定理4.3**：经典ROM加理想原语下的条件归约。伪造优势不超过若干统计项，加上 `Adv^owf_KeyGen(B) + Q_sig·Adv^prf_H3(C) + τ(k+2)Adv^prg_F + …`。B、C只说“存在PPT”，没有给出具体资源。

3. **没有交付**具体位数的证明，也没有QROM证明（论文写明留待未来）。

最终形式（ST2）：

```text
Adv_030^EUF-CMA(A) ≤ min{1, Adv_Rain^{OWF,IC}(B_final) + ε_new}
```

ε_new 的每一项都有显式公式和参数（模拟、链、桶、Canon、Parent、AU、Twin、ZHash、挑战根）。经本地模拟引理，原语项还可换成不访问任何预言的普通 Rain 游戏，代价是再加 min(1, P_final·2^-258) 并把模拟费用计入归约者资源（[03 推论 1′](Q4_03_security_proof.md)）。B_final 是给出全部资源的有限可执行算法。这与rFAEST定理4.3的形式同类，但更具体：rFAEST的B只说“存在”。

**状态：有条件地已证明。** 条件为经典ROM、理想密码，以及Rain困难性假设。审查为内部AI独立审查，不是外部同行评审，也没有做机器形式化验证。

## 8. 推荐的对外表述

> 原030（Rain＋rVOLEitH）六个参数组在经典随机预言模型与理想密码模型下，有完整的EUF-CMA条件安全证明。在实际Rain-128单点原像困难性假设下，它支持与rFAEST作者所声称的128位档相当的安全评价，与作者的论证层级一致。该证明不依赖rFAEST论文中已发现有缺陷的引理。Rain-4参数组采用设计者推荐的轮数；Rain-3参数组同样没有已确立的快于穷举的攻击，但其公开分析余量较薄，存在依赖未证假设的接近128档的估计。具体的安全位数与量子随机预言模型下的安全性未经证明；本结论经内部审查，未经外部同行评审。

不要使用以下说法：“已证明128位安全”“与rFAEST安全强度完全相同”“Rain与AES同样可信”“经过同行评审”。
