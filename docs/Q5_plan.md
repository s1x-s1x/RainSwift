## 2. 不变量：Q4 证明不需要改动

Q4 证明的对象是方案本身：建钥取 32 个均匀随机字节（pt‖k），任一轮 S 盒输入为 0 就整体重取，公钥为 (pt, Rain_k(pt))，私钥为打包的 (pt, k)；签发、验签按冻结源码。本阶段只替换建钥中 Rain 正向计算的算法实现，不改所计算的函数。

1. 冻结源码 `源码/rain-voleith` 与 Q2 工作副本 `Q2Q3_落地与实测_20261016/源码/rain-voleith-q2` 都不动。本阶段在 `源码/rain-voleith-q5kg/` 建新工作副本（从 Q2 副本复制），所有修改只在新副本中进行。
2. **建钥是同一个函数。** 对相同的随机字节，(pk, sk) 逐字节相同；随机源调用次数和字节数不变；零输入拒绝规则不变；B1 开关语义不变。依据：有限域中逆元唯一，线性层是固定矩阵，所以对每个输入，新旧实现的结果必须相同。下面第 4 节用测试核实。
3. 签发、验签、承诺层、Fiat–Shamir、参数和签名格式都不改。新代码只接在建钥用的 `faest_pubkey`（Rain 分支）上；签发中重算见证的 `faest_compute_witness` 继续用原实现。
4. 常数时间写法不变：除既有的“零输入则重取”之外，没有依赖秘密的分支，也没有以秘密为下标的访存。

## 3. 工作内容

| 项 | 内容 |
|---|---|
| K1 线性层 | 128×128（及 64×64）GF(2) 矩阵乘：去掉每次迭代在通用寄存器里构造掩码的做法，改为把待测位移到符号位、按符号位做常数时间选择（vpsllvq + vblendvpd），整个过程留在向量寄存器 |
| K2 求逆加法链 | GF(2^64) 求逆改用链 1,2,3,6,12,15,30,60,63（8 次乘法），多次平方 2^3、2^6、2^15、2^30 用编译期生成的线性表；编译期断言生成的 2^15、2^31 表与冻结常数 SQ15、SQ31 完全相同 |
| K3 模约化 | x^64+x^4+x^3+x+1 的约化去掉第二次 clmul：第二次折叠只剩不足 3 位，用寄存器内 16 项 pshufb 表完成 |
| K4 接入 | 新文件 `rain_kg.hpp` 提供 `rain::kg::forward<R>`，与 `rain::forward<R>` 同一函数；`faest_pubkey` 的 Rain 分支改调它，数值全程留在向量寄存器 |
| 不做 | 塔域再降一层；任何随机源改动；签发／验签路径改动 |
