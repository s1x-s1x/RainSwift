## 复算正式原语统计

在仓库根目录运行（Python 3.10+，只需标准库）：

```bash
python -I -X utf8 data/原语性能/核验性能数据.py
```

程序核对原始文件 SHA-256、返回码、有效性、消息与密钥尺寸、实际签名字节以及中位数和四分位数。预期摘要：

```json
{"status": "PASS", "implementations": 38, "nonwarmup_samples": 57114, "raw_files": 342}
```

`原语性能/数据核验结果.json` 是支撑材料附带的核验输出。上述命令复算现有样本；重新采集全套对照还需各对照源码和对应构建环境。

在 Linux/macOS 环境可核对全部快照文件字节：

```bash
cd data
sha256sum -c SHA256SUMS.txt
```

`SHA256SUMS.txt` 对本目录其余所有文件计算 SHA-256，不包含自身。

## 读取口径

- 原语主性能使用 64 字节消息、单线程 CPU 和 `CLOCK_MONOTONIC_RAW`；编译器及优化选项按统计 JSON 中的各实现读取。
- 资源测量采用独立探针构建；其资源值与原语计时分别解释。
- 协议时延中的跨完整运行最佳观察值与同次运行对照分别保存。逐次样本、仅有汇总的批次、进程内时间与握手记账字节保持原定义；不补造缺失的样本和四分位数。
- `实验环境.json` 保留提供方确认的宿主说明；各批次 JSON 亦保留原始工具链和历史环境字段。二者均原样保留，原始日志本身不独立证明宿主平台归属。
- 证书链的完整配置含 36 项通过用例；RainSwift 配置为 29 项通过、7 项未覆盖。功能验收、签发预算及独立端到端时延分别读取。
- `证书链/测试凭据/` 下的 PEM、DER 和测试密钥 JSON 是材料附带的公开测试夹具，仅供复现测试。
