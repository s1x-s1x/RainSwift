# RainSwift 测试数据说明

作品编号：CACR2026RO5FCA。测试数据位于 `03_测试数据/`，与作品设计报告中的参数、统计定义和配置对应。

| 数据目录 | 内容 |
|---|---|
| `原语性能/` | 38 组原语实测样本、性能统计、编译命令记录和数据核验程序 |
| `资源测量/` | 堆、栈、RSS、代码与常量的原始输出、探针和结果表 |
| `协议时延/` | 经典 CA 配置的原语测量、逐次握手测量及配置对比统计 |
| `证书链/` | 完整配置、RainSwift 配置、原生功能测试和测试凭据 |
| `功能测试/` | 协议回归、签发预算、握手成功及签名篡改拒绝的原始输出 |

## 原语性能

正式集合包含 6 组 RainSwift 参数和 32 组对照实现，采用完整窗口对 F3／S3。每组实现具有 1,503 个非预热测量样本，总计 57,114 个样本，保存在 342 份 JSONL 文件中。每条采样记录同时保存建钥、签名和验签时间。

测量使用 64 字节消息、CPU 单线程及 `CLOCK_MONOTONIC_RAW`。编译器、优化选项、样本窗口和尺寸字段见 `原语性能/性能统计.json`。同一配置的建钥、签名和验签采用同一窗口；不按单个表格单元分别挑选最小值。

| 字段 | 含义 |
|---|---|
| `kind` | `metadata`、`validation` 或 `sample` 记录类型 |
| `impl_id`、`algorithm` | 实现编号和算法名称 |
| `warmup` | 是否为预热样本；预热项不计入正式统计 |
| `kg_ns`、`sign_ns`、`verify_ns` | 建钥、签名、验签耗时，单位纳秒 |
| `kg_rc`、`sign_rc`、`verify_rc` | 三项调用的返回码 |
| `valid` | 采样结果有效性 |
| `signature_bytes` | 实际签名长度，单位字节 |

`性能统计.csv` 与 JSON 使用相同数据，给出样本数、密钥与签名尺寸、中位数及四分位数。建钥时间以微秒表示，签名和验签时间以毫秒表示；加速比先用原始精度计算，再按报告精度显示。不满足尺寸和预检条件的实现不纳入正式 38 组集合。

进入 `03_测试数据/原语性能/` 后，可使用 Python 3.10 或更新版本复算：

```sh
python -I -X utf8 核验性能数据.py
```

该程序核对原始文件 SHA-256、返回码、有效性、消息长度、密钥与签名尺寸及统计值。`构建记录/` 保存编译命令归档；重新采集全套对照数据需配置相应对照源码和采样环境。

## 资源测量

资源实验包含 14 组实现，采用独立探针构建，每种测量模式执行 3 次。`raw/` 保存工具输出，`results/` 保存汇总，`scripts/` 保存探针、解析和构建命令。堆峰值、栈涂抹、RSS、目标文件及只读常量分别计量，基线扣除规则以结果字段和探针记录为准。资源测量与原语计时采用不同构建，不将两者拼接成单次实验。

## 协议时延与证书链

协议时延采用经典 CA 配置的真实握手输出。保留逐次样本的配置可直接复算，仅有汇总字段的配置按汇总记录读取。跨完整运行选择的最佳观察值和同次运行的 39 组比较分别解释。

后量子证书链数据用于核查 CA 两条替代签名边、独立根、在线双签名、应用数据和 exporter。完整配置包含 36 项通过用例；RainSwift 配置包含 29 项通过、7 项未覆盖。正常连接、负例和预算检查属于不同用例类型。

证书 DER、Certificate 明文、AEAD 保护载荷及协议驱动前缀是不同计量对象。握手记账字段按其记录定义读取，不作为 TCP/IP 抓包流量；证书链功能结果不替代独立端到端时延测量。

## 运行与测试输出

功能测试日志及 JUnit 文件保留通过、失败和跳过状态。运行结果截图展示正常握手与篡改拒绝；测试结果截图展示对应回归或数据核验输出，数据与同名原始文件一致。截图不改变原始样本、测试计数或覆盖范围。
